4.1

复合选择器

复合选择器是指通过对基本选择器进行组合而形成的更为复杂的选择器。

知识要点

为什么要用复合选择器

教材原文：复合选择器是对基本选择器进行组合而形成的更为复杂的选择器

  • 只用标签选择器，粒度太粗；全部加 class，HTML 又会被类名塞满。
  • 复合选择器让你借结构定位元素：不必给每个元素起名字，也能精确命中。
  • 常用复合选择器共 6 类：交集、并集、后代、子元素、相邻兄弟、属性选择器。
  • 它们的连接符号各不相同：无符号相连、,、空格、>、+、[]——记符号是第一步。
要点分解

六类复合选择器速览

先建立全景图，再逐个击破

交集选择器
div.nav：第一个是标签选择器，第二个是类/id 选择器，中间无空格。又名标签指定式选择器。
并集选择器
div,#main,.nav：用逗号分隔，也叫分组/群组选择器，本质是样式代码的复用。
后代选择器
ul a：用空格分隔，读作「a 作为 ul 的后代」，不限嵌套层级。
子元素选择器
h1>span：用 > 连接，必须是直接父子关系，比后代选择器严格。
相邻兄弟选择器
h1+p：选中后续相邻、且符合条件的兄弟元素；前序相邻不起作用。
属性选择器
a[href][title]：由一对中括号与属性表达式构成，可按属性名或属性值匹配。
代码与要点

4.1.1 交集选择器（标签指定式选择器）

构成规则：标签选择器在前，类/id 选择器在后，直接相连、不能有任何空格

  • 又称标签指定式选择器，可以利用它指定具有特定类或 id 属性的标签。
  • div.blue 选中的 <div> 比一般 <div> 要求更精准，必须同时具备 blue 类。
  • 教材示例：div 统一控制 3 个盒子，div.blue 命中第 1 个，div#nav 命中第 2 个。
  • 写法陷阱：div .blue（有空格）是后代选择器，div.blue（无空格）才是交集选择器——一个空格，两种结果。
HTML 代码4-1 关键片段
<style>
div{                        /* #007-#012 标签选择器统一控制 */
    width: 500px;
    height: 30px;
    background: antiquewhite;
    border: 2px solid darkgray;
}
div.blue{                   /* #013-#015 交集：div 且 class=blue */
    background: aliceblue;
}
div#nav{                    /* #016-#018 交集：div 且 id=nav */
    background: darkgoldenrod;
}
</style>

<div class="blue">交集选择器:div.blue</div>
<div id="nav">交集选择器:div#nav</div>
<div>标签选择器</div>
代码与要点

4.1.2 并集选择器（分组 / 群组选择器）

由两个或两个以上任意选择器组成，用逗号分隔——本质是「集体声明」

  • div,#main,.nav{color:red;} 完全等价于分别书写 div、#main、.nav 三条同内容规则。
  • 作用是样式代码的有效复用：把「共性」抽出来一次声明，后面再用类选择器补充个性。
  • 教材示例用 div,span,.nav 一次性让 div、span、p.nav 三种元素同时变红。
  • 教材疑误提醒：代码4-2 中第 015、016 行原文闭合标签误写为 </div>，正确应为 </span>、</p>，课堂请按正确写法示范。
HTML 代码4-2（按正确写法）
<style>
div,span,.nav{      /* #007-#009 并集选择器 */
    color:red;
}
</style>

<div>并集选择器div</div>
<span>并集选择器span</span>
<p class="nav">并集选择器p</p>
代码与要点

4.1.3 后代选择器

每个空格翻译成「xxxxx 作为 xxx 的后代」，例如 ul a 读作「a 作为 ul 的后代」

  • HTML 元素的嵌套关系可视为父子关系，形成上下文关系，据此可快速定位特定元素。
  • 直接父子关系是一种特殊的后代关系——这句话是理解子元素选择器的关键铺垫。
  • 书写起点无硬性要求：只要上下文关系足够覆盖你要运用规则的元素即可。
  • 良好的编程习惯：在确保选中效果的前提下，以尽可能简单为原则，便于书写和阅读。
  • 本例 ul a 与 ul li a 效果等价，但复杂页面中容易误选，应遵循准确且精简原则。
HTML 代码4-3 关键片段
<style>
ul,li{                  /* #007-#010 用并集选择器做初始化 */
    margin:0px;
    padding:0px;
}
ul li{                  /* #011-#015 后代选择器 */
    height: 30px;
    background-color: lightgrey;
    margin-bottom:2px;
}
ul a{                   /* #016-#018 a 作为 ul 的后代 */
    color:red;
}
</style>

<ul>
    <li><a href="">link1</a></li>
    <li><a href="">link2</a></li>
    ...
</ul>
<a href="">link6</a>     <!-- #029 不在 ul 内，不被选中 -->;
对比辨析

后代选择器 vs 子元素选择器：最大的区别

一个看「祖先」，一个只看「父亲」

后代选择器　ul li a（空格）
  • 是一种较为宽泛的上下文选择器
  • 只要符合上下文关系，不管嵌套层级如何都可以被选中
  • 示例：ul li a 同时命中 ul li a 与 ul li span a
  • 优点：写起来短；风险：复杂页面容易误选
子元素选择器　ul li>a（>）
  • 是一种相对严格的上下文选择器
  • 不仅要符合上下文关系，还要符合一定的父子关系
  • 示例：ul li>a 只命中 li 的直接子元素 a
  • 嵌在 span 里的 a 不会被选中

4.1.5 相邻兄弟选择器

技巧：后续相邻且符合选择器2 条件的那些元素

  • 重点在「后续」二字：前序相邻的兄弟元素不起作用，这是初学者最容易犯错之处。
  • 教材示例 h1+p：只选中「做文明人」这一段。
  • 课堂拓展「考考你」：改为 p+p，会选中「办文明事」和「讲文明话」。
  • 原因：对「办文明事」而言，后续相邻的「讲文明话」同样符合 p+p 条件。
  • MDN 补充：若想选中所有后续兄弟，应使用通用兄弟组合器 ~（CSS3）。
HTML 代码4-5 关键片段
<style>
h1+p{                       /* #007-#012 后续相邻的兄弟 */
    background: lemonchiffon;
    color:#f00;
    height: 30px;
    border:1px solid #ccc;
}
</style>

<h1>争创文明校园</h1>
<p>做文明人</p>      <!-- h1+p 只选中这一段 -->;
<p>办文明事</p>
<p>讲文明话</p>

表4-1 常见的属性选择器

标准 CSS 写法为半角运算符 [attr~=value]、[attr|=value]

类型选择器描述
根据属性选择[属性]选择带有指定属性的元素
根据属性和属性值选择[属性=值]选择带有指定属性和属性值的元素
根据部分属性值选择[属性~=值]选择属性值中包含指定值的元素，该值必须是一个完整的单词
子串匹配属性值[属性|=值]属性值以指定值开头，该值须是完整单词或以 “-” 连接后续内容的字符串，如 en-
子串匹配属性值[属性^=值]选择属性值以指定值开头的元素
子串匹配属性值[属性$=值]选择属性值以指定值结尾的元素
子串匹配属性值[属性*=值]选择属性值中包含指定值的元素

4.1.6 属性选择器

属性选择器由一对中括号和一组属性表达式表示

  • [title] 选中所有带 title 属性的元素，统一设为 #f6f。
  • a[href][title] 两个条件同时满足，只命中「2003 年10 月15 日至16 日」这一条链接。
  • img[alt] 命中 astronaut.png，用 float:left 实现图文混排。
  • 再用 margin-right 调整图文之间的距离——这是外边距的典型用法，项目5 会系统学习。
  • 提示：属性选择器既可单独使用，也可紧跟在标签选择器之后书写，如 a[href]。
HTML 代码4-6 关键片段
<style>
[title]{                    /* #007-#009 */
    color:#f6f;
}
a[href]{                    /* #010-#012 */
    text-decoration: none;
}
a[href][title]{             /* #013-#015 */
    font-size: 18px;
}
img[alt]{                   /* #016-#022 图文混排 */
    border:1px dashed #ccc;
    float:left;
    max-width: 100px;
    padding:5px;
    margin-right:10px;
}
</style>

知识要点

易错大盘点：五个空格/符号级陷阱

写完选择器，先在脑子里过一遍这五条

  • div.blue 与 div .blue：前者是交集，后者是后代——一个空格差之千里。
  • 交集选择器第一个必须是标签选择器，写成 .blue div 就变成后代选择器了。
  • 相邻兄弟选择器找的是后续兄弟，前面的兄弟不会被选中。
  • 后代选择器不是写得越长越好：在确保命中的前提下越简单越好。
  • 属性选择器的运算符是半角：[attr~=value]、[attr|=value]，教材原表印刷为全角，请按标准写法书写。
AI 前沿

AI 前沿：大模型是怎么「读懂」一个页面的

AI 看到的不是一张截图，而是一棵 DOM 树 + 一组选择器规则

AI

你给 AI 一段 HTML，它首先要做的是构建DOM 树；而要改某处样式，它必须像今天的你一样，找出一条能精准命中目标节点的选择器路径。区别在于：AI 倾向于生成又长又稳的路径（如 body > div > ul > li:nth-child(3) > a），而优秀工程师会用最短、最稳定的复合选择器。

  • GitHub Copilot、通义灵码、文心快码都能根据上下文自动补全选择器，但补全结果往往偏啰嗦，需要人工精简。
  • DeepSeek、通义千问等大模型可以直接回答「这段 CSS 为什么没生效」，本质是在做选择器匹配 + 优先级推理。
  • 审查 AI 代码的重点：它写的后代链是否过长、是否过度依赖结构顺序、是否会因为 DOM 微调而失效。
  • 结论：选择器基本功越扎实，你驾驭 AI 的能力就越强——这正是本单元的价值所在。
随堂检测

随堂检测

自编题，覆盖本单元六类复合选择器

共 5 题　·　先独立作答，再点「查看答案」；误点可「重做」
  1. 01 单选下列选择器中，能够选中 class 为 blue 的 div 元素的是（　　）。
    答案B交集选择器：标签选择器与类选择器直接相连，中间无空格。
  2. 02 单选关于 ul a 与 ul>li>a，下列说法正确的是（　　）。
    答案C子元素选择器只认直接父子；后代选择器不限层级。
  3. 03 单选有结构 h1、p、p 依次相邻，使用 h1+p 会选中（　　）。
    答案A相邻兄弟选择器只选中“后续相邻”的那一个；若写 p+p 才会选中第 2 个 p。
  4. 04 多选关于复合选择器，下列说法中正确的有（　　）。
    答案A、B、D相邻兄弟选择器只认后续相邻的那一个；写成 div .blue（有空格）则变成后代选择器。
  5. 05 多选关于后代选择器与属性选择器，下列说法中正确的有（　　）。
    答案A、B、C后代选择器不限嵌套层级，ul li span a 同样会被 ul li a 命中；只认直接父子的是子元素选择器。

本课小结

  • 复合选择器是对基本选择器进行组合形成的更复杂的选择器，共 6 类。
  • 交集div.blue 两选择器直接相连；并集div,p 逗号分组、集体声明。
  • 后代ul a 不限层级；子元素ul>li>a 只认直接父子。
  • 相邻兄弟h1+p 只认「后续相邻」；属性[attr] 用一对中括号表达条件。
  • 书写原则：准确第一，其次精简；写完务必确认不多选、不漏选。
