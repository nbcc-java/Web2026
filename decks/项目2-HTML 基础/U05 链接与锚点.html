2.4.4-1

链接语法与目标窗口

链接的本质很简单：谁被点（源点），跳到哪（目标点）。

代码与要点

链接的基本语法：a 标签与它的三个常用属性

教材：链接的主要功能是实现从一个源点到目标点的跳转

  • 源点：页面中被单击的对象，也就是需要实现跳转的文字或图片——用 a 标签把它包起来即可。
  • 目标点：链接跳转后到达的位置或页面（某个锚点位置，或另一个网址），由 href 属性指定。
  • href：必设属性，用于指定目标点，需要保证路径可达；除资源定位外，还可取 #、JavaScript:… 等值。
  • target：定义目标窗口，即跳转的页面在哪个窗口中打开；title：鼠标悬停时弹出的提示信息。
  • 哑链接：href 值为 # 相当于设置一个空链接，不会发生任何跳转行为。
  • URL（uniform resource locator）：把包含协议和你要访问的资源地址的部分统称为 URL 地址。
HTML 链接的示例语法
<!-- 最基本的链接：源点 + 目标点 -->;
<a href="http://www.nbcc.cn">单击跳转</a>

<!-- 带 target 与 title 属性 -->;
<a href="http://www.nbcc.cn" target="_blank" title="宁波城市职业技术学院">单击跳转</a>

<!-- 哑链接：不会发生跳转行为 -->;
<a href="#">空链接（哑链接）</a>

2.4.4-2

路径与链接类型

路径写错，链接就废：这一页是整个 2.4.4 小节最容易出错的地方。

代码与要点

相对路径与绝对路径

教材：链接能否实现正确的跳转，路径的描述至关重要

  • 相对路径：基于某个参照对象（通常是链接所在的当前文档）的路径，以参照对象所在位置为起点查找目标文件，必须有参照。
  • 链接路径通常分 3 类：① 两个文件同属一个目录；② 目标文件在当前文件的某个下级目录中；③ 目标文件在当前文件的某个上级目录中。
  • 路径符号（表2-6）：. 或 ./ 表示当前目录；.. 表示上一级目录；/ 表示进入下一级目录；../ 表示进入上一级目录。
  • 绝对路径：文件的完整路径，不需要参照对象；既可以是从磁盘根目录出发的完整路径，也可以是一个网页的完整 URL 地址。
  • URL 地址通常由协议头 + 磁盘路径 + 资源名称构成；常见协议头有 https://、files://、http://、ftp://、ed2k:// 等。
  • 所有需要引用资源的地方（图片、字体、音频、视频、文件下载）都会用到这两种路径。
HTML 路径示例
<!-- 示例1：目标文件在当前文件的下级目录 -->;
│  2-4-7.html
└─sub
        target.html
<a href="./sub/target.html">下级目录中的文件</a>

<!-- 示例2：两个文档同属一个目录 -->;
│  2-4-7.html
│  target.html
<a href="./target.html">相同目录下的文件</a>
<!-- 简化写法：同属一个目录时，可直接书写目标文件名 -->;
<a href="target.html">相同目录下的文件</a>

<!-- 绝对路径：磁盘路径形式的完整路径 -->;
files://N:\cn.nbcc.web.book\ch02\sub\target.html

<!-- 绝对路径：一个网页的完整 URL 地址 -->;
<a href="https://www.nbcc.cn/2022/0505/c121a14741/page.htm">城院校训</a>
知识要点

为什么教材推荐使用相对路径

一条重要结论，也是项目部署的基本素养

  • 绝对路径不便于书写，一旦文件或磁盘位置发生变化，将导致工作无法正常运行。
  • 在本地计算机中正常工作的页面，将来要上传到服务器中运行；真正部署的服务器环境跟本地完全不同，甚至操作系统也不同。
  • 只要源文件和目标文件的相对位置不变，把它们整体上传到服务器后同样能够正常工作——这是网站正确部署的关键。
  • 出于安全考虑，很多服务器根本不支持绝对路径的地址访问。
  • 因此：应优先考虑使用相对路径。这也是 1+X 初级考试中的常见考点。

外部链接、URL 协议与 mailto 邮件链接

教材表2-7 常用 URL 协议 + mailto 协议语法

  • 常用 URL 协议（表2-7）：http:// 超文本传输协议；mailto: 邮件发送协议；ftp:// 文件传输协议；telnet:// 远程上机协议；news:// 新闻讨论组协议。
  • mailto 语法中，收件人邮箱地址是必选项；subject 指定邮件主题，cc 设置抄送邮箱，bcc 设置暗抄送邮箱，其余均为可选项。
  • 多个参数之间使用「&」分隔；参数和收件人邮箱地址之间使用「?」分隔。
  • 常见的编程错误：?、& 后面出现空格会导致链接失效，书写后务必检查。
  • 技巧：使用 mailto 协议启用邮件发送程序时，需要在本地计算机中事先安装并配置好邮件收发软件（如 Outlook）。

2.4.4-3

锚点链接

两步操作：先设锚点（建书签），再做跳转。

代码与要点

锚点链接的两步操作

类似 PDF / Word 的书签功能，常用于「回到顶部」与「文档大纲」

  • 第 1 步 · 设置锚点（创建书签）：在 HTML5 中可以使用任意标签的 id 属性设置锚点，其 id 属性值就是锚点名称（书签名）。
  • id 属性犹如身份证，可以唯一标识标签元素，因此同一个页面中要求 id 属性值必须唯一。
  • 第 2 步 · 设置链接跳转：把 href 写成 #锚点名 即可跳转到当前页面的特定位置。
  • 外部锚点链接：如果要跳转到其他页面的特定锚点位置，必须在「#」前面加上该页面的页面路径。
  • 师生问答：能否把 id 加到 section 上？——当然可以。每个 section 正好对应一个章节，网页实现过程中做法往往不是唯一的。
HTML 锚点链接语法
<!-- 设置锚点（创建书签） -->;
<p id="ch02">第二节</p>

<!-- 内部锚点链接：链接到当前页面的特定锚点位置 -->;
<a href="#ch02">跳到第二节</a>

<!-- 外部锚点链接：链接到其他页面的特定锚点位置 -->;
<a href="02.html#ch01">第二章第一节</a>

AI 前沿

AI 前沿：当 AI 帮你「找链接」

路径能自动生成，安全却必须由人来把关

AI

大语言模型可以根据站点目录清单，自动生成导航菜单与锚点目录，也能批量校对链接是否有效。但链接安全、钓鱼与盗链的判断必须由人把关——教材的项目讨论正提醒我们要警惕利用短信链接、盗链实施的电信网络诈骗。AI 负责「写得快」，我们负责「用得正」。

  • 批量生成：把站点文件清单交给 GitHub Copilot、文心快码等，自动生成相对路径链接，减少手写错误。
  • 智能校对：用 DeepSeek、通义千问等国产大模型批量检查锚点名与 id 是否一一对应。
  • 安全提醒：使用 target="_blank" 打开外部链接时，应参照 MDN 建议补充 rel 属性，防范新窗口带来的安全风险。
  • 职业底线：不制作、不传播钓鱼页面，发现盗链、恶意跳转要及时报告——做遵法守规的 Web 前端工程师。

本课小结

五句话，牢牢抓住链接与锚点

  • 链接本质：a 标签包裹源点，href 指定目标点（必设属性）；target 决定目标窗口，title 提供悬停提示。
  • target 取值：_blank 开新窗口（无法后退）、_self 当前窗口（默认）、_parent 上一级窗口、_top 整个窗口、框架名称。
  • 路径：相对路径以当前文件为参照，./ 当前目录、../ 上一级目录、/ 进入下一级目录；绝对路径是完整路径，教材推荐使用相对路径。
  • 链接类型：内部、外部、锚点、脚本、资源链接五类；外部链接常用 http://、mailto:、ftp:// 等协议，mailto 用 ? 起参、& 分隔参数。
  • 锚点两步：任意标签加唯一 id 设置锚点 → href="#锚点名" 跳转；跨页面则写成 页面路径#锚点名。
