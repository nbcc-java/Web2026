2.4

认识更多语义化标签

把「语义、呈现和行为」分开：话由 HTML 说，样子交给 CSS 画。

对比辨析

b / i（呈现） vs strong / em（语义）

教材导言：显示效果一样，表达的意思完全不同

传统写法 b、i —— 只说外观
  • b 表示 bold（加粗），i 表示 italic（倾斜）
  • 只描述文字长什么样，不解释为什么这样
  • 教材：b 与 i 并未被废弃，常被当作行内容器使用（如在内容前加图标）
现代写法 strong、em —— 带有语义
  • em 表示 emphasized text，是强调的局部文字（显示倾斜）
  • strong 表示 strong emphasized text，是特别强调的重要文字（显示加粗）
  • 新规范建议使用 strong、em 代替 b、i，以具有更好的语义
  • 良好习惯：用 strong、em 强调文字；外观交给 CSS

对比辨析

常见编程错误：head 与 header 别搞混

教材明确的初学错误，几乎人人都犯过一次

head 标签
  • 用于设置 HTML 文档头部描述信息
  • 相关内容不在浏览器视口中显示
  • 置于 body 标签之前，并与 body 并列
  • 内部通常放 meta、title、link 等
header 标签
  • 定义文档的头部区域，是浏览器可见部分
  • 必须放在 body 标签内部
  • 内部常嵌套 nav 导航菜单
  • 它描述的是页面内容结构，不是文档元信息

知识要点

块状标签、行内标签与三个易错点

理解了 display 的差异，排版的一半问题就解决了

  • 块状标签（块级元素）：默认情况下占据父容器的一整行，左右不允许其他元素出现；display 属性值为 block。
  • 行内标签（行内元素）：允许其他元素出现在左右并同占一行；display 属性值为 inline。br、span 都是典型的行内标签。
  • 易错一：在 HTML 段落中按 Enter 键换行，浏览器仅显示一个空白字符大小；连按多次也一样——换行请用 <br>。
  • 易错二：<br> 符合 HTML5 规范，<br /> 符合 XHTML 规范，两者都能被正确渲染；新的 HTML5 项目建议直接写成 br。
  • 易错三：段落对齐可用 align 属性或 text-align 样式；按内容与样式分离原则，推荐使用 CSS，不要给 p 加 align 属性。
代码与要点

三种列表：无序、有序与自定义（语法2-3）

常用于制作目录、导航菜单与条目列举

  • 无序列表 ul 与有序列表 ol 都包含若干列表项 li（list item）。
  • 语义区别：无序列表项无顺序要求；有序列表项对顺序有要求；自定义列表 dl 多一个标题 dt 与描述 dd 的功能。
  • type 属性：ol 默认是数字序号，可改为 A、B、C；ul 默认符号样式是黑心实圈 disc，可改为空心圆圈 circle 或方块 square。
  • 技巧：列表中的每个列表项都可以嵌套其他列表，利用这个特性可以实现多级菜单的效果。

AI 前沿

AI 前沿：语义化为什么让机器更懂你的页面

搜索引擎、读屏软件和大模型，都是靠「读结构」来理解网页的

AI

机器不是用眼睛「看」页面，而是解析标签树。标题是否有层级、导航是否用 nav、正文是否用 article，直接决定搜索引擎爬虫、读屏软件与大语言模型能否抓住重点。语义写得规范，SEO 排名与 AI 摘要都会更准确。

  • SEO 优化：合适的 title 与清晰的结构，帮助搜索引擎把网站或文章合理归类。
  • 信息无障碍：nav、main、h1～h6 让读屏软件快速定位内容区块，这是前端工程师的职业底线。
  • AI 摘要：让大模型概括长页面时，它会优先抽取 article 正文与标题层级作为线索。
  • 实操建议：用 DeepSeek、通义千问等国产大模型，把一段「全是 div」的旧代码改写成语义化版本，再对照 MDN 逐条校核。

本课小结

五句话带走上节课的核心能力

  • 语义化思想：HTML5 提供为页面内容添加语义的标签，把语义、呈现和行为三者分离；呈现效果交给 CSS。
  • 文档结构标签：header、nav、section、main（唯一）、article、aside、footer，共 7 个。
  • 易混辨析：head 描述文档信息、不可见、在 body 之前；header 是可见的头部区域、写在 body 内部。
  • 没有对应语义标签的区域（如轮播图）用 div；aside 与 main 是兄弟关系，文档结构没有唯一答案。
  • 文本标签：h1～h6、p 是块状；br、span、strong、em 是行内；列表有 ul / ol / dl 三种，特殊符号用字符实体。
