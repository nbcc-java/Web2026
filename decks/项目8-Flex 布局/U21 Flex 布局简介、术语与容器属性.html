8.1

Flex 布局简介

布局方式很多，为什么现代前端首选 Flex？先搞清楚它到底「弹」在哪里。

知识要点

Flex 是什么：一种一维的弹性布局

教材原文：Flex 是 flexible box 的缩写，意为「弹性布局」

  • Flex 是 flexible box 的缩写，意为弹性布局，是一种对元素进行按行或按列布局的常用布局手法。
  • 常被理解为一种一维布局手法——一次只在一条轴（行或列）上安排元素，而不是同时控制行列。
  • 子项可以用 grow 抓取填充额外的容器空间；也可以用 shrink 在容器收缩时得到合适的收缩效果。
  • 教材结论：能伸能缩、按需分配，这正是弹性布局的要义。
  • 与浮动、定位相比：Flex 是为布局而生的，不脱离文档流，也不需要清除浮动。
8.2

Flex 布局的相关术语

术语不清，属性就永远记不住。这一页请务必跟着图走一遍。

要点分解

四个术语：容器、子项、主轴、交叉轴

教材图 8-3，术语务必讲清

Flex 容器 / Flex 子项
采用 Flex 布局的元素叫Flex 容器（flex container），简称容器；它的所有子元素称为 Flex 子项（flex item），简称子项。
主轴 main axis
默认情况下子项沿主轴横向排列，左侧为主轴起点 main start，右侧为主轴结束点 main end。
交叉轴 cross axis
与主轴正交的那条轴。默认起点 cross start 在上、终点 cross end 在下；主轴一变方向，交叉轴随之改变。
main size / cross size
main size：每个子项占据主轴空间的尺寸；cross size：占据交叉轴空间的尺寸。注意是「尺寸」而非固定的「宽高」。
效果演示

交互演示｜主轴与交叉轴到底长什么样

左边是 row（主轴水平），右边是 column（主轴垂直）——注意交叉轴是如何跟着变的

  • 容器就是写了 display:flex 的那个元素，它的直接子元素才是子项（孙元素不算）。
  • 默认 flex-direction:row：主轴水平自左向右，此时交叉轴竖直。
  • 改成 column：主轴变为竖直，交叉轴随之变成水平。
  • 所有对齐属性（justify-content / align-items）都是相对轴而言的，轴变了，效果也跟着变。
动手试试：想一想：如果想让 3 个子项在竖直方向上「居中」，应该改主轴方向还是改 align-items？
8.3

Flex 容器

一句话启用 Flex，但有三个属性会当场「失效」——这是必考的易错点。

代码示例

启用 Flex 布局：display:flex 与 inline-flex

教材给出的「良好的编程习惯」：为 WebKit 内核浏览器加前缀

CSS style.css
/* 块级元素使用 Flex 布局 */
.box{ display:flex;}

/* 行内元素使用 Flex 布局 */
.box{ display:inline-flex;}

/* 良好的编程习惯：兼顾 WebKit 内核浏览器 */
.box{
    display:-webkit-flex;  /* Safari */
    display:flex;}
易错点（教材原文）：当设置了 Flex 布局之后，子元素的 float、clear、vertical-align 等样式属性将失效。也就是说，Flex 与浮动布局不要混用。

Flex 容器常见的 6 个属性（教材表 8-1）

容器属性写在「父元素」上，控制的是子项整体的排列方式

属性名描述

flex-wrap控制是否换行
flex-flow综合样式属性，是 flex-direction 属性和 flex-wrap 属性的组合
justify-content定义主轴对齐方式

align-content定义多根轴线的对齐方式，如果只有一根轴线，则该属性不起作用

flex-wrap：空间不够时，换行还是压缩？（教材表 8-2）

实验条件：6 个 50px×50px 子项。容器宽度不足时，默认行为是「压缩」而不是「换行」

属性值描述
nowrap默认值，不换行。容器装不下时弹性地缩小子项的水平尺寸（教材图 8-5）
wrap换行，当子项在父容器中宽度不足时自动换行，保持原有尺寸（图 8-6）
wrap-reverse逆向换行，换行方向与轴方向相反，即自下而上（图 8-7）
代码与要点

flex-direction 与 flex-flow：方向与换行的写法

语法 8-1 与语法 8-2；flex-flow 默认值为 row nowrap

  • row：默认值，主轴水平自左向右；row-reverse 自右向左。
  • column：主轴垂直自上而下；column-reverse 自下而上。加了 -reverse 就产生逆向布局（图 8-4）。
  • flex-flow 是 flex-direction 与 flex-wrap 的组合简写：flex-flow: [flex-direction] || [flex-wrap]。
  • 两个值之间用空格分隔、顺序可交换；只写一个时，另一个取默认值。
  • 默认值 row nowrap 意味着横向排列且永不换行——这正是初学时「子项被压扁」的根本原因。
CSS style.css
/* 语法 8-1：指定主轴方向，默认值 row */
.box{ flex-direction: row | row-reverse | column | column-reverse;}

/* 语法 8-2：方向与换行的简写 */
flex-flow: [flex-direction] || [flex-wrap];

/* 示例：纵向排列 + 逆向换行 */
.wrap{ flex-flow: column wrap-reverse;}

/* 等价于 */
.wrap{
    flex-direction: column;
    flex-wrap: wrap-reverse;}

justify-content：主轴上的对齐（教材表 8-3）

教材表中后两项写作 flex-around / flex-between，属排版笔误；标准写法为 space-around / space-between

属性值描述
flex-start子项在主轴上对齐起点（main-start）
flex-end子项在主轴上对齐结束点（main-end）
center子项沿主轴朝容器的中心对齐
space-around子项在主轴上平均分布，首、尾两项与父容器两侧也留间隔（记为 A），子项之间的间隔（记为 B）通常是 A 的两倍
space-between子项在主轴上平均分布，首、尾两项紧贴父容器，中间的间隔均分

对比辨析

align-items 与 align-content：到底该用哪一个

教材启发式问答 + 常见的编程错误

align-items（针对单行）
  • 针对每一根交叉轴进行设置，作用对象是「行内的子项」
  • 例如 5 个子项构成两行：align-items:flex-start 是让每一行的元素都对齐到该行交叉轴空间的起始位置
  • 两行会先平均分配交叉轴空间，再各自对齐（图 8-12）
  • 单行时它就能生效，是日常用得最多的一个
align-content（针对多轴整体）
  • 针对多轴的内容进行整体设置，作用对象是「整组轴线」
  • align-content:flex-start 是把多轴整体对齐到交叉轴空间的起始位置
  • 必须配合 flex-wrap 换行，产生多轴内容才会起作用
  • 常见的编程错误（教材原文）：仅使用 align-content 而不配合 flex-wrap，往往达不到预期效果
AI 前沿

AI 前沿：让 AI 写布局，但先自己画出两条轴

AI 能秒出代码，但「轴的方向」必须由你来定义

AI

Flex 布局是最适合 AI 生成的 CSS 之一：你只要说「三个卡片横向均分、垂直居中」，GitHub Copilot、通义灵码、文心快码就能给出 display:flex; justify-content:space-between; align-items:center;。但 AI 并不理解你的设计意图，它需要你先说清主轴方向、是否换行、谁吃掉剩余空间——这些恰恰是本单元的核心知识。

  • 提示词示例：「一个 540px 宽的容器，4 个 91px 子项，横向两端对齐、垂直居中」——需求越具体，代码越准。
  • AI 常见错误：忘记写 flex-wrap:wrap（小屏挤成一团）、把 align-items 与 align-content 混用。
  • 国产工具：DeepSeek、通义千问、文心一言等均可用自然语言生成并解释 Flex 代码，适合当「随堂助教」。
  • 职业提醒：把 AI 生成的代码逐行读懂并验证，才是 1+X 考试与真实岗位上真正值钱的能力。

本课小结

  • Flex = flexible box，一种一维的弹性布局：用 grow 抓取额外空间、用 shrink 合理收缩，这是弹性的要义。
  • 术语四件套：容器（写了 display:flex 的元素）、子项（其直接子元素）、主轴（子项排列方向）、交叉轴（与主轴正交）。
  • 启用方式：display:flex（块级）/ inline-flex（行内）；一旦启用，子元素的 float、clear、vertical-align 全部失效。
  • 主轴对齐用 justify-content，交叉轴对齐用 align-items，多轴整体用 align-content（必须配 flex-wrap）。
  • 默认值要记牢：flex-direction:row、flex-wrap:nowrap、flex-flow:row nowrap、align-items:stretch。
