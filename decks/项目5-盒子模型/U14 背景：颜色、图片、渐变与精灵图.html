5.4

背景

在盒子模型中，content 盒不仅可以呈现主体内容，还可以添加背景颜色或图片。

代码与要点

5.4.1 背景颜色 与 5.4.2 背景图片

语法5-3：background-color；语法5-4：background-image

  • background-color 的取值：颜色预设值、十六进制值、RGB 值，以及 transparent（透明）、inherit（继承）。
  • background-image:url(image_file_path) 把指定图片作为盒子的背景。
  • 教材比喻：就像计算机桌面——背景图不够大时，桌面上只会显示它的局部。
  • 局限：单纯使用该语法时，必须保证图片大小与盒子尺寸恰好匹配才能达到理想效果。
  • 属性 vs 标签：background-image 是装饰性内容，可被背景色覆盖；<img> 是内容本身，可被搜索引擎与读屏软件识别。
CSS 语法5-3 / 5-4
background-color:颜色预设值 | 十六进制值 | RGB 值 | transparent | inherit;
background-color:#ccc;

background-image:url(image_file_path) | inherit;
background-image:url(images/01.jpg);
代码与要点

background-repeat：让贴图铺起来

语法5-5：repeat | repeat-x | repeat-y | no-repeat | inherit

  • 素材：容器 300px×300px，背景图 hotel-wallpaper.png 尺寸仅 29px×40px。
  • repeat：x、y 双向平铺（默认值）；no-repeat：只显示一张。
  • repeat-x：只在水平方向平铺；repeat-y：只在垂直方向平铺。
  • 配合 float:left + margin-right 可把四个盒子并排，横向对比四种效果。
  • 典型用途：小图案平铺做页面底纹，能显著减小图片体积。

对照表

表5-11 background-position 属性值

引出问题：为什么 no-repeat 时背景图默认出现在左上角？因为容器左上角为原点 (0,0)

属性值描述
表示位置的预设关键字left top（默认值，左上角）、center top、right top、left center、center center、right center、left bottom、center bottom、right bottom。
第一个值表示水平位置，第二个值表示垂直位置；只规定一个值时另一个值默认为 center
偏移量 xpos ypos第一个值水平、第二个值垂直，默认值为 0 0，单位为 px 或 em。xpos 为正从左向右移动，ypos 为正从上向下移动；只规定一个值时另一个值是 50%（或 center）
x% y%第一个值水平、第二个值垂直，偏移量为相对于元素宽度与背景图片宽度之差的百分数。默认值 0% 0%，右下角为 100% 100%；只规定一个值时另一个值是 50%
知识要点

定位其实很好理解：移动的是背景图本身

配合代码5-12 的五个位置类名一起看

  • 五个对比值：left top、100% 0%、100% 100%、left bottom、50% 50%。
  • 记住：正数表示向右 / 向下移动图片；想要显示右侧部分，就要写负值——这是精灵图的理论基础。
  • 素材说明：HTML5-LOGO.png 实际 2048px×2048px，容器 300px×300px，故先用 background-size:50% 缩小一半便于观察。
  • 口诀：background-position 描述的不是「图放哪儿」，而是「图的哪一点对准哪里」。
对照表

表5-12 background-size 属性值（CSS3 新特性）

为什么需要它？高分屏时代普遍使用 2 倍图甚至 3 倍图

属性值描述
length设置背景图片的高度和宽度。第一个值表示宽度，第二个值表示高度；只给出一个值时第二个值为 auto
percentage计算相对于背景定位区域的百分比。以空格隔开宽度和高度，以逗号隔开多重背景；只给出一个值时第二个值为 auto
cover保持图片纵横比，缩放成能完全覆盖背景定位区域的最小大小
contain保持图片纵横比，缩放成适合背景定位区域的最大大小
对比辨析

contain 与 cover，到底差在哪

教材对比结论（图5-26）

background-size:contain
  • contain 有包含的意思
  • 把背景图尽可能包含在容器中
  • 没有任何裁剪
  • 代价：容器多余的地方会留出大量空白
  • 适合：logo、图表、必须完整展示的图
background-size:cover
  • cover 意为覆盖
  • 用背景图尽可能覆盖当前容器
  • 必要时裁剪背景图
  • 优点：不留任何空白
  • 适合：banner、卡片封面、全屏背景
对比辨析

background-attachment：墙纸与窗帘

教材比喻：scroll 时背景与文字像一个整体；fixed 时背景像墙纸不动，文字像窗帘照常滚动

scroll（默认值）
  • 背景图片随元素内容一起滚动
  • 背景与前景文字像一个整体
  • 素材同为 hotel-wallpaper.png
  • 图5-29 为 scroll 的对照效果
fixed
  • 背景图片相对于视口固定，不随内容滚动
  • 背景像墙纸固定不动，文字像窗帘照常拉动
  • 常用于整页背景、视差效果的简单实现
  • 图5-30 为 fixed 的对照效果
对比辨析

background-clip 与 background-origin：画到哪 vs 从哪起

两者取值都是 border-box / padding-box / content-box，极易混淆

background-clip：背景<strong>裁剪</strong>
  • border-box：背景覆盖 border 盒（默认值）
  • padding-box：背景覆盖整个 padding 盒，不含边框线
  • content-box：背景仅覆盖 content 盒
  • 作用于背景颜色与背景图片，回答「画到哪为止」
background-origin：背景<strong>起始定位</strong>
  • border-box：背景图起始于 border 盒左上角
  • padding-box：起始于 padding 盒左上角（默认值）
  • content-box：起始于 content 盒左上角
  • 两者区别：origin 需要有背景图片的参与，回答「从哪开始画」
代码与要点

5.4.3 背景综合样式

语法5-12：一条 background 写完所有背景相关声明

  • 书写顺序：bg-color bg-image position/bg-size bg-repeat bg-origin bg-clip bg-attachment。
  • 各属性值之间使用空格分隔；后续参数有需要时才添加，否则使用默认值。
  • 必须设置背景颜色或背景图片，两者都不指定是常见的编程错误。
  • 技巧一：bg-size 只能紧接着 position 出现，两者以「/」分隔，如 center/80%。
  • 技巧二：origin 与 clip 取值同为 <box> 类型，出现 1 次时同时设置两者，出现 2 次时依次设置。
CSS 语法5-12 示例
background:bg-color bg-image position/bg-size bg-repeat bg-origin bg-clip bg-attachment initial|inherit;

background:red url(";images/bg.png";) repeat-y;
background:#fff center/80% no-repeat;
background:url(";images/bg.png";) left top/cover no-repeat content-box;

任务5-7｜制作健康打卡功能的渐变背景

目标：根据图5-27 健康 App 打卡卡片效果，用渐变函数实现（图5-28）

任务目标掌握 linear-gradient() 的语法与三条常见编程错误
  1. linear-gradient() 是一个函数，参数 direction 表示渐变的角度和方向，其后接若干 CSS 颜色作为过渡起止色。
  2. 示例：background-image: linear-gradient(45deg,#7ca9f0,#82d695);，配 border-radius:5px 做圆角卡片。
  3. 常见编程错误①：想在网页中显示「>」字符，却不使用实体引用，应写成 &gt;。
  4. 常见编程错误②：缺少函数括号，或参数之间没有用逗号分隔。
  5. 常见编程错误③：把渐变函数错误地应用到 background-color 属性中——渐变是图片，应写在 background-image 里。
<style>
.box{                       /* #007-#016 */
    width: 200px;
    height: 150px;
    background-image: linear-gradient(45deg,#7ca9f0,#82d695);
    border-radius: 5px;
    line-height: 150px;
    color:white;
    font-size: 30px;
    text-align: center;
}
</style>

<div class="box">
    &gt;7 天跳绳打卡      <!-- #021 注意 > 需用实体引用 -->;
</div>

任务5-8｜用背景属性制作图标

目标：icon-dot（实心圆）与 icon-menu（三横图标）两个移动应用常见图标

任务目标掌握 currentColor 与 background-clip 的组合用法
  1. 技巧：currentColor 是 CSS3 中的变量，表示当前标签所继承的文字颜色，可与 color 保持同步。
  2. 共同思路：把前景色设为 lightgrey，用 currentColor 让背景色同步，再用 background-clip:content-box 把绘制区域限定为 content 盒。
  3. icon-dot：content 盒 100×100，配 border-radius:50% 成为实心圆，padding 10px 留白，最外是 10px 边框。
  4. icon-menu：content 盒高 10px，与上、下边框宽度相等，自然形成「三」字形。
  5. 关键：别忘了 display:inline-block，否则空的 div 无法体现宽高。
.icon-dot{                  /* #007-#017 */
    display: inline-block;
    width: 100px;
    height: 100px;
    padding:10px;
    border:10px solid;
    background-color: currentColor;
    background-clip:content-box;
    color:lightgrey;
    border-radius: 50%;}
.icon-menu{                 /* #018-#028 */
    display: inline-block;
    width: 140px;
    height: 10px;
    padding:35px 0;
    border-top:10px solid;
    border-bottom:10px solid;
    color:lightgrey;
    background-color: currentColor;
    background-clip: content-box;}

任务5-9｜使用精灵图

素材：某水果企业为北京奥运会提供新鲜水果产品的展示框，精灵图 image/bdd.png

任务目标用一张精灵图制作多个产品展示框，每个框显示一种水果
  1. 容器 .box：宽 172px、高 200px、border:1px solid #ccc、float:left，并统一写 background:url("image/bdd.png") no-repeat;。
  2. 每个水果只需改一行 background-position：.bdd1{background-position:0 0;}、.bdd2{background-position:-172px 0;}。

    float: left;
    margin-right: 10px;

.bdd2{background-position: -172px 0;}       /* #016 */

知识要点

精灵图专题问答

教材问答中的五个关键知识点

  • 什么是精灵图：取自英文 Sprite 的翻译；因为「雪碧」英文也是 Sprite，有些书上也叫雪碧图。
  • 为什么用一张大图：①加快网页加载速度——10 张图要发 10 次请求，合成 1 张只需 1 次；②便于后期维护。
  • 怎么用：配合 background-image、background-repeat、background-position，类似于放大镜的使用——看到的是局部，移动靠 background-position 精准定位。
  • 怎么取坐标：① 用 Photoshop 等绘图软件打开原稿，用测量工具取坐标；② 用浏览器开发者工具调试，满意后回填代码。
  • 技巧：绘图软件与开发者工具配合，可以高效获取背景图片的坐标信息。
AI 前沿

AI 前沿：当图标不再需要「手量坐标」

精灵图解决的是请求数问题，AI 正在改变的是「做图」这件事本身

AI

过去做一张精灵图，需要设计师排版、开发者量坐标；现在图标可以直接以 SVG 内联或用 icon font 引入，请求数与维护成本同时下降。AI 则进一步参与进来：给它一句话，就能生成成套 SVG 图标，甚至按品牌色自动生成渐变，替代本单元手写的 linear-gradient。

  • 图标方案演进：精灵图 → icon font（如 iconfont.cn）→ 内联 SVG symbol；现代项目更推荐 SVG symbol 雪碧（sprite）。
  • GitHub Copilot、通义灵码可根据 background-position 的取值规律，自动推算下一排图标的坐标。
  • DeepSeek、通义千问可以直接生成满足设计规范的 linear-gradient 色值与色标位置。
  • 提醒：AI 生成的 SVG/渐变要检查体积、对比度与无障碍色值，好看不等于可用。

本课小结

  • 背景八件套：color、image、repeat、position、size、attachment、clip、origin。
  • 平铺四值：repeat（默认）、no-repeat、repeat-x、repeat-y。
  • 尺寸两策略：contain 完整无损但留白，cover 铺满无白但会裁剪。
  • 渐变是图片：linear-gradient(角度, 色1, 色2) 必须写在 background-image 中。
  • 精灵图：一张图 + 负值位移，把多次请求压成一次，坐标可用 Photoshop 或开发者工具量取。
