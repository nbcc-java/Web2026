知识要点

必须记住的 3 点（教材原文）

外加教材启发问答：要用定位属性定位，至少需要几个定位属性？

  • ① 常用的定位有 static 静态定位、fixed 固定定位、absolute 绝对定位、relative 相对定位 4 种。
  • ② left、right、bottom、top 是 4 个 CSS 属性，也被称为定位属性，可以和 relative、absolute、fixed 配合使用，实现坐标定位的效果。
  • ③ 如果定位的元素发生空间上的重叠，则可以通过 z-index 实现层级的切换，数值越大，层级越高——如同 PPT「排列」选项中「前移一层」的效果。
  • 启发问答：要用定位属性定位，至少需要几个定位属性？——由于元素基于盒子模型，在水平方向和垂直方向上至少各需要一个定位属性。
  • 教材引子：如果说浮动解决了平面空间的排版问题，那么定位则可以让元素向纵深方向（z 轴）发展，形成层级叠加，支撑弹窗、对话框等交互效果。
要点分解

四种定位速览

一句话分清：谁动、谁来定、动完还占不占位置

static · 静态定位
position:static 或不设置 position 时的默认状态。块级元素从上往下依次排列，行内元素与行内块元素从左往右依次排列，各元素没有任何移动效果——之前课程中的示例代码都使用静态定位。
fixed · 固定定位
相对于浏览器视口（可视窗口）定位，位置固定，不会随着网页滚动条的滚动而移动。典型应用：京东商城的固定侧边栏、回到顶部按钮。
absolute · 绝对定位
相对于距离最近的已定位祖先元素定位；没有已定位祖先元素时，相对于浏览器定位。完全脱离标准流，并提升层级。
relative · 相对定位
相对于自身原始位置偏移，偏移量由 top、right、bottom、left 实现，未指定时默认值为 0。不脱离标准流，仍占据原有空间。

7.2.4

绝对定位

找最近的「已定位祖先」，找不到就找浏览器——这是绝对定位的核心规则。

代码与要点

绝对定位：就近找「坐标系」

教材代码7-11：不存在已定位祖先元素的情况

  • 定义：绝对定位是指相对于距离最近的已定位祖先元素进行的定位。如果元素没有已定位祖先元素，那么它的位置相对于浏览器进行定位。
  • 本例中 div.outer 与 body 均未加定位，属于「不存在已定位祖先元素」的情况：div2 被定位到距离浏览器左边界 20px、上边界 40px 的位置。
  • 特性①：脱离原来的标准流，并提升层级。
  • 特性②：祖先中有已定位元素则就近绝对定位，否则根据浏览器定位。
  • 特性③：可以使行内元素支持宽度、高度和内边距、外边距等样式效果。
  • 特性④：当块级元素不设置宽度时，其宽度由内容撑开。
  • 特性⑤：可以触发 BFC（呼应上一单元）。
  • 补充实验：如果只设置绝对定位而没有 left、top 配合，元素会在原来的位置上，但会脱离标准流。
CSS 代码7-11（教材原文）
.outer{ background-color:#01FFFF;}
.box{ width:100px; height:50px; background-color:#FFE4C4;
      border:1px dashed #518F93;}
.box2{ position:absolute; left:20px; top:40px;}

对比辨析

fixed 与 absolute，滚动条一拉就见分晓

教材技巧原文：这是初学者最容易混淆的一对

fixed · 固定定位
  • 相对于浏览器视口进行定位
  • 即使滚动页面，元素也会固定保持在同一个位置上
  • 常用于固定侧边栏、回到顶部、悬浮客服
  • 偏移参照物永远是视口，与祖先是否定位无关
absolute · 绝对定位
  • 相对于最近的已定位祖先元素（没有则相对浏览器窗口）
  • 拖动滚动条时，绝对定位元素会随着文档一起滚动
  • 常用于弹窗、角标、局部坐标系内的精确定位
  • 教材判定口诀：页面垂直方向超过一个屏幕时，两者差别最明显
7.2.5

相对定位

它不脱离标准流，却悄悄给自己建立了一套「局部坐标系」。

代码与要点

相对定位：以自己为原点

教材代码7-12：不设置偏移量时，和静态定位似乎没区别（图7-26）

  • 定义：相对定位是指元素相对于自身原始位置进行偏移的定位，偏移量由 top、right、bottom、left 实现；未指定时默认值为 0。
  • 特性①：如果只设置相对定位，不设置偏移量，则元素的位置不会有任何变化。
  • 特性②：元素设置相对定位后仍然占据其原有空间，不会脱离标准流——这是它与绝对定位最大的区别。
  • 特性③：元素设置相对定位后会提升其层级，与原有标准流元素形成遮挡关系（div2 会遮住 div3）。
  • 特性④：在配合定位属性时，元素的偏移位置相对于原来元素在标准中的位置。
CSS 代码7-12（教材原文）
.outer{ background-color:#01FFFF;}
.box{ width:100px; height:50px; display:inline-block; margin:5px;
      background-color:#FFE4C4; border:1px dashed #518F93;}
.box2{
    position:relative;
    /* left:20px;
       top:40px; */
}
知识要点

「已定位元素」与「父相子绝」

教材技巧原文：利用「父元素的相对定位 + 子元素的绝对定位」实现局部坐标系内的快速定位

  • 相对定位不脱离标准流，其他元素不受影响，仍按原位置排列；同时它会提升一个层级，并具有由自身偏移量计算的参考系。
  • 这就使它成为一个「已定位元素」——教材比喻：就好像拥有一个局部坐标系来定义它的子元素，其所有子元素在定位时将参考这个局部坐标系。
  • 启发问答：除了相对定位，还有哪些元素属于已定位元素？——除了默认的静态定位，父元素使用绝对定位、相对定位、固定定位都属于已定位情况。
  • 此时子元素使用绝对定位，使用的是父元素的局部坐标系——这就是「父相子绝」：父元素 relative 建系，子元素 absolute 落点。
  • 记忆口诀：子绝父相。父级不设定位，子级就会一路找到浏览器去。

本课小结

五句话，把定位这件事彻底说清楚

  • 四种定位：static（默认，按标准流排）、fixed（跟视口，不随滚动）、absolute（跟最近的已定位祖先，脱离标准流）、relative（跟自己，不脱离标准流）。
  • 四个偏移属性 left、right、top、bottom 均可取负值；由于元素基于盒子模型，水平与垂直方向至少各需要一个定位属性。
  • 重叠时用 z-index 切换层级，数值越大层级越高，如同 PPT 的「前移一层」。
  • 绝对定位五特性：脱离标准流并提升层级、就近找已定位祖先、行内元素可变块级化、不设宽度时由内容撑开、可触发 BFC。
  • 相对定位四特性：不设偏移量则位置不变、仍占原空间不脱离标准流、提升层级形成遮挡、相对自身原位置偏移——它是建立「局部坐标系」的关键，于是有了「父相子绝」。
