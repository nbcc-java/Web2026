任务驱动

任务 8-1｜块级元素居中布局（方案 1：Flex）

某在线商城发布了一款智能绘图产品，要求图片在容器中水平垂直居中（图 8-13）

任务目标用 300px×300px 的容器把一张图片水平且垂直居中显示，并掌握三种实现方案。
  1. 新建页面，引入素材 ./images/AI_01.png。
  2. 容器 div 设置 display:flex，把它变成 Flex 容器。
  3. 用 justify-content:center 控制主轴（水平）居中。
  4. 用 align-items:center 控制交叉轴（垂直）居中。
  5. 子项 div>img 设置 height:90%，留出呼吸空间。
/* 代码 8-1：方案 1 —— Flex 布局 */
div{ display:flex; border:1px solid #ccc; background-color:#eee;
     align-items:center; justify-content:center; width:300px; height:300px;}
div>;img{ height:90%;}
代码示例

任务 8-1｜另外两种居中方案（代码 8-2 / 8-3）

表格单元格法与「定位 + translate()」法

CSS style.css
/* 代码 8-2：方案 2 —— 表格单元格 */
div{ display:table-cell; border:1px solid #ccc; background-color:#eee;
     vertical-align:middle; text-align:center; width:300px; height:300px;}
div>;img{ height:90%;}

/* 代码 8-3：方案 3 —— 定位 + translate() */
div{ position:relative; border:1px solid #ccc; background-color:#eee;
     width:300px; height:300px;}
div>;img{ position:absolute; left:50%; top:50%; height:90%;
         transform:translate(-50%,-50%);}
教材类比：方案 2 就像 Word 中的单元格对齐方式（图 8-14）——配合 text-align 实现水平居中，配合 vertical-align 实现垂直居中。translate(-50%,-50%) 的含义是「向左、向上各移动自身宽高的一半」。
对比辨析

三种居中方案怎么选

方案 1 · Flex 布局
  • 两句代码搞定：justify-content:center + align-items:center
  • 不需要知道子项尺寸，也不需要脱离文档流
  • 可同时处理多个子项，扩展性好
  • 推荐作为首选方案（现代浏览器的标准做法）
方案 2 / 方案 3
  • 方案 2 表格单元格：语义上把容器变成单元格，会改变盒子的排版特性
  • 方案 3 定位 + translate：子项脱离文档流，容易影响其他元素
  • 两者在老项目、老浏览器中仍大量存在，必须能读懂
  • 结论：新项目优先 Flex；维护旧代码时要认得另外两种

任务 8-2｜不定项居中布局

轮播图底部的导航按钮：3 张图 3 个按钮，5 张图 5 个按钮，却始终底部居中（图 8-15）

任务目标让个数不确定的一组按钮，始终作为一个整体水平居中、贴住底部。
  1. 把若干个 li 放进 ul.wrap，让 ul 成为 Flex 容器。
  2. justify-content:center：让这一组按钮整体居中。
  3. align-items:flex-end：把它们放到交叉轴的结束位置（底部）。
  4. 每个 li 用 border-radius:50% 画成圆形，用 margin 控制间距。
  5. 增删 li 的个数，居中效果依然成立——这就是「不定项」。
/* 代码 8-4 */
.wrap{ width:500px; height:200px; background-color:antiquewhite; border:1px solid #eee;
       display:flex; justify-content:center; align-items:flex-end;}
.wrap>;li{ justify-content:center; background-color:#999; width:20px; height:20px;
          line-height:20px; text-align:center; border-radius:50%; color:white;
          list-style:none; margin:5px 10px;}

任务 8-3｜均分列布局

城市学院网站：4 列均匀横向分布在主轴空间，每列一个图标 + 一段说明文字（图 8-16）

任务目标把「图标 + 说明文字」看成一个整体，用 justify-content:space-between 实现两端对齐的均分。
  1. 容器 .wrap：540px×153px，白底、padding:0 30px、border-radius:6px、margin:0 auto。
  2. 容器加 display:flex + justify-content:space-between + align-items:center。

任务 8-4｜组合嵌套布局

大美新疆首页的导航栏：logo、导航、分享、登录、注册（图 8-17）

任务目标用「组合思想」把复杂导航栏拆成两个熟悉的整体，再用 space-between 分开。
  1. 教材方法：把不熟悉的页面布局转换为熟悉的基本页面布局。
  2. 左侧「logo + 导航」看成一个整体 .lft；右侧「分享 + 登录注册」看成另一个整体 .rt（图 8-18）。
  3. 外层 .wrap 用 justify-content:space-between，把两个整体推向两端。
  4. .lft、.rt 内部再次使用 Flex——这就是「嵌套」。

.share{ display:flex; margin-right:20px; align-items:center; justify-content:space-between;}

8.4

Flex 子项

容器管「整体怎么排」，子项管「我自己占多少、排第几」。

对照表

Flex 子项样式属性（教材表 8-6）

子项属性写在「子元素」上，控制的是单个子项自身

属性名描述
order定义子项的排列顺序。数值越小，顺序越靠前，默认值为 0
flex-grow定义子项的放大比例。默认值为 0，表示如果存在剩余空间，则子项不放大
flex-shrink定义子项的缩小比例。默认值为 1，表示如果空间不足，则子项将缩小
flex-basis定义在分配剩余空间之前子项在主轴中的空间大小。浏览器据此计算主轴是否有剩余空间。默认值为 auto，即子项的本来大小
flex综合样式属性，是 flex-grow、flex-shrink 和 flex-basis 的简写，默认值为 0 1 auto
align-self允许单个子项有与其他子项不一样的对齐方式，可覆盖 align-items。默认值为 auto，表示继承父元素的 align-items；如果没有父元素，则等同于 stretch

拖动窗口宽度，观察 grow / shrink / align-self 的实际效果

  • 宽度 601px：空间充足。因 align-items 默认 stretch，前两个子项占满父容器高度；带 align-self:flex-end 的子项底部对齐（图 8-19）。

  • align-self 是「个体对抗集体」的钥匙：只让某一个子项与众不同。

知识要点

为什么 Flex 里常用 flex-basis，而不是 width？

教材启发问答：二者同时出现时，谁说了算？

  • width 通常用来描述固定宽度；flex-basis 描述的是子项在主轴中的空间大小。
  • 如果父容器宽度超过所有子项 flex-basis 之和，说明有额外空间，浏览器会按 flex-grow 分配这些空间。
  • 因此在 Flex 布局中常使用 flex-basis 而非 width。
  • 同时使用会怎样？.item 指定 width:200px、.base 指定 flex-basis:300px，最终显示 300px（图 8-22）。
  • 结论：flex-basis 的优先级高于 width；图中显示 302px，是子项 300px 加上左右各 1px 的边框。

任务 8-5｜Flex 布局案例：轮播图的制作

将 3 张图片显示在指定区域，底部 3 个分页指示器，左右各一个控制器按钮（图 8-23～8-25）

任务目标教材整体思路：轮播图由 3 部分构成——幻灯片容器、分页指示器、控制器按钮。本任务不要求实现播放效果与按钮触发事件。
  1. 先构造幻灯片容器结构：外层 .swiper-container 定位参照，内层 .swiper-wrapper 承载 3 个 .swiper-slide（图 8-26）。
  2. 再构造分页指示器：3 个行内元素，用 Flex 放在底部中间（图 8-27）。
  3. 最后用 a 标签实现控制器按钮，绝对定位到左右两侧（图 8-28）。
  4. 用 flex-wrap 不换行 + flex-shrink:0 让 3 张图溢出到父容器外。
  5. 用 @keyframes move-slide 横向平移实现自动播放（动画细节在项目 9 详讲）。
/* 代码 8-9：溢出布局（重点） */
.swiper-container{ position:relative; background-color:#FFE4C4;}
.swiper-wrapper{ display:flex;}
.swiper-slide{ width:100%; flex-shrink:0; /*不收缩，溢出布局*/ }
代码示例

轮播图核心代码（代码 8-8）

结构、分页指示器、控制器按钮与自动播放关键帧

CSS style.css
.swiper-container{ position:relative; background-color:#FFE4C4;}
.swiper-wrapper{ display:flex; transition:0.5s; transform:translateX(0px);
                 animation: move-slide 10s ease-in-out infinite;}
.swiper-slide{ width:100%; flex-shrink:0; /*不收缩，溢出布局*/ }
.swiper-slide img{ width:100%;}

.swiper-pagination{ position:absolute; height:28px; width:100%; bottom:40px;
                    display:flex; justify-content:center; align-items:center;}
.swiper-pagination-bullet{ width:12px; height:12px; border-radius:50%;
                           background-color:#c6bcaf; margin:0 4px;}
.swiper-pagination-bullet-active{ background-color:#fff;}

.swiper-button-prev,.swiper-button-next{ position:absolute; top:0%; height:100%;
                                         display:flex; align-items:center;}
.swiper-button-prev{ left:10px;}
.swiper-button-next{ right:10px;}

@keyframes move-slide {
  0%,10%,100%{ transform: translateX(0px);}
  20%,40%   { transform: translateX(-500px);}
  60%,80%   { transform: translateX(-1000px);}}
教材说明：对 .swiper-wrapper 使用 Flex 布局后，子元素需要溢出到父容器外，靠 width:100% + flex-shrink:0 实现，这种布局形式被称为「溢出布局」。

  4. 04 多选关于本单元的几个 Flex 布局技巧，下列说法正确的有（　　）。
    答案A、B、C组合嵌套靠的是外层 space-between + 内层再 Flex，与绝对定位无关，故 D 错。

本课小结

  • 居中三方案：Flex（首选）、表格单元格（table-cell + vertical-align）、定位 + translate(-50%,-50%)。
  • 不定项居中：justify-content:center + align-items:flex-end，子项个数变化也不影响居中。
  • 均分列用 space-between；复杂导航栏用组合嵌套——把不熟悉拆成熟悉的两团。
  • 子项六大属性：order、flex-grow、flex-shrink、flex-basis、flex、align-self；flex-basis 优先级高于 width。
  • 轮播图三件套：溢出布局（width:100% + flex-shrink:0）、分页指示器（Flex 底部居中）、控制器按钮（绝对定位 + Flex 垂直居中）。
