9.4

过渡

没有过渡，状态切换就是「跳变」；有了过渡，就有了丝滑。

知识要点

什么是过渡（transition）

教材定义：让你定义元素在两种状态之间切换的过渡效果

  • 过渡（transition）样式规则能够让你定义元素在两种状态之间切换的过渡效果。
  • 常用做法：给同一个元素应用 :hover 伪类和 :active 伪类，并分别定义不同的样式。
  • 学了 JavaScript 之后，也可以通过脚本来切换状态，同样会触发过渡。
  • 一句话记忆：过渡需要一个「触发」——鼠标悬停、点击、获得焦点或类名变化。
对照表

常用的过渡样式属性（教材表 9-3）

四个子属性，决定「变什么、变多久、怎么变、何时开始」

样式属性名描述
transition-property指定 CSS 属性的 name、transition 效果（即哪些属性参与过渡）
transition-duration指定 transition 效果需要多少秒或毫秒才能完成
transition-timing-function指定 transition 效果的转速曲线（即速度如何变化）
transition-delay定义 transition 效果开始的时间（延迟多久才启动）
代码与要点

transition 综合语法与初始值

写简写时四个值的顺序是固定的：属性、时长、曲线、延迟

  • 综合语法：transition: property duration timing-function delay;
  • 教材给出的初始值：transition-delay: 0s、transition-duration: 0s、transition-property: all、transition-timing-function: ease。
  • 注意：duration 默认为 0s——不写时长就看不到任何过渡，这是初学最常见的失误。
  • 两个时间值同时出现时，第一个是 duration，第二个是 delay。
  • 小技巧：可以在浏览器开发者工具中查看所有预设的动画函数效果，甚至可以自定义动画函数（图 9-16）。
CSS style.css
/* 综合语法 */
transition: property duration timing-function delay;

/* 示例：宽度在 1s 内以 ease-in-out 曲线过渡，延迟 0.3s 开始 */
div{ transition: width 1s ease-in-out 0.3s;}

/* 初始值（教材给出） */
transition-delay: 0s
transition-duration: 0s
transition-property: all
transition-timing-function: ease

任务 9-2｜制作简单过渡效果

创建 div，宽度 100px；鼠标悬停时宽度 300px；实现 2s 的宽度过渡效果（使用默认动画函数）

任务目标用 :hover 制造两个明显不同的状态，再用 transition 让变化在 2 秒内慢慢发生。
  1. 新建 div，设置 background-color:#FFE4C4、width:100px、padding:20px。
  2. 写 div:hover{ width:300px; }，让两个状态有明显区别（图 9-12 → 图 9-13）。
  3. 最关键的一步：在 div 上写 transition: width 2s;。
  4. 补充 -webkit-transition: width 2s;——这是兼容性写法，为让 Safari 支持。
  5. 把鼠标移上去，观察宽度是「跳变」还是「平滑增长」。
/* 代码 9-4 */
div{
    background-color:#FFE4C4;
    width:100px;
    padding:20px;
    transition: width 2s;
    -webkit-transition: width 2s;  /* Safari */
}
div:hover { width:300px;}
代码示例

多属性过渡与 all 技巧（代码 9-5）

多个属性同时过渡时用逗号分隔；属性太多就用 all 代替

CSS style.css
/* 代码 9-5：多属性过渡（图 9-14 → 图 9-15） */
div{
    background-color:#FFE4C4; width:100px; padding:20px;
    transition: width ease-in-out 2s, background-color ease-in-out 2s;
    -webkit-transition: width ease-in-out 2s, background-color ease-in-out 2s; /* Safari */
}
div:hover{ width:300px; background-color:#f00;}

/* 技巧：用 all 代替所有要实现过渡变化的样式属性 */
transition: all ease-in-out 2s;
-webkit-transition: all ease-in-out 2s; /* Safari */
技巧（教材原文）：使用 all 代替所有要实现过渡变化的样式属性，是一种常用的技巧。
常见的编程错误（教材原文）：把 transition 错拼成 transform——两者一个管「过渡」、一个管「变换」，切勿混淆。
效果演示

交互演示｜把鼠标移到卡片上，感受过渡与动画

上行三张卡是 hover 触发的过渡；下行是 @keyframes 自动播放的动画

  • 卡片 1：transition: width 2s——宽度从 60px 平滑长到满格。
  • 卡片 2：transition: all ease-in-out .6s——颜色、位移、阴影一起变。
  • 卡片 3：transition: transform 1s——旋转 180 度并放大 1.2 倍。
  • 下行：圆点是 animation: bounce 1.6s ease-in-out infinite，进度条是 animation: fill 3s ease-in-out infinite——不需要任何触发。
动手试试：过渡必须有「触发」（这里是 :hover），动画只要写一次就会自动循环——这就是两者最直观的区别。
9.5

动画

过渡只能描述「从 A 到 B」，动画则可以写出 A→B→C→D 的整条时间线。

知识要点

动画与过渡：最大的区别是什么

教材结论：动画支持自定义关键帧规则，可控性更高

  • CSS3 中一些样式属性除了可用于过渡，还可以用于创建动画，以此取代许多通过动画图像、Flash 动画和 JavaScript 实现的效果。
  • 原理与过渡非常类似，主要实现从一个值变化到另一个值（尺寸大小、数量、百分比和颜色变化等）。
  • 最大区别：动画支持自定义关键帧规则。关键帧规则通过 @keyframes 定义。
  • 通过在动画序列中定义关键帧（waypoints）的样式，来控制 CSS 动画序列的中间步骤。
  • 因此，动画的可控性要比过渡的可控性高；而且动画不需要触发，页面加载后即可自行播放。
代码与要点

@keyframes 与 animation 的语法

教材示例：让骰子沿 y 轴从 0 度转到 359 度

  • @keyframes 语法：@keyframes animationname { keyframes-selector { css-styles; } }
  • 教材解析：按顺序列出关键帧百分比——0% 对应起始帧，50% 对应中间帧，100% 对应结束帧。
  • 技巧（教材原文）：0% 可以用预设值 from 替代，100% 可以用 to 替代。
  • animation 综合语法：animation: name duration timing-function delay iteration-count direction fill-mode;
  • 示例中的 rotate3d(0,1,0,0deg) 表示绕 y 轴旋转 0 度；中间转到 180 度，结束转到 359 度。
CSS style.css
/* 定义关键帧 */
@keyframes rotateDice {
  0%   { transform: rotate3d(0, 1, 0, 0deg);}
  50%  { transform: rotate3d(0, 1, 0, 180deg);}
  100% { transform: rotate3d(0, 1, 0, 359deg);}}

/* 启用动画：2s 一个周期，匀速，无限循环 */
#dice{ animation: rotateDice 2s linear infinite;}

/* 综合语法 */
animation: name duration timing-function delay iteration-count direction fill-mode;
对照表

常用的 animation 样式属性（教材表 9-4）

一个简写属性 + 八个子属性

样式属性名描述
animation所有动画属性的简写样式属性
animation-name规定动画的名称
animation-duration规定动画完成一个周期所花费的时间，单位为秒或毫秒。默认值是 0
animation-timing-function规定动画的速度曲线。默认值是 ease
animation-fill-mode规定当不播放动画时（动画完成播放时，或动画有延迟未开始播放时），要应用的元素样式
animation-delay规定动画何时开始播放。默认值是 0
animation-iteration-count规定动画的播放次数。默认值是 1
animation-direction规定动画是否在下一个周期逆向播放。默认值是 normal
animation-play-state规定动画是否正在播放或暂停。默认值是 running
知识要点

使用 animation 的三条注意事项

教材原文要点

  • animation-name 所规定的动画名称，必须和前面定义的 @keyframes 动画名称保持一致——名字对不上，动画完全不会执行。
  • animation-duration、animation-timing-function、animation-delay 的用法和过渡样式属性非常类似。
  • animation-duration 默认值为 0，和上节课的 transition 一样——不写时长就没有动画。
  • 想做循环动画：animation-iteration-count: infinite;（或直接写进简写里）。

任务 9-3｜制作旋转骰子

在任务 9-1 基础上创建自定义动画 rotateDice，让骰子沿 y 轴旋转，2s 一个周期循环播放（图 9-17）

任务目标用 @keyframes 描述「0° → 180° → 359°」的时间线，再用 animation 简写启用并无限循环。
  1. 沿用任务 9-1 的结构与 .face 样式（6 个面保持不变）。
  2. 定义动画：013～023 行由 3 部分构成——0% 起始帧、50% 中间帧、100% 结束帧。
  3. 注意这里的 perspective-origin 改为 center center（任务 9-1 中是 bottom center）。
  4. 用 animation: rotateDice 2s linear infinite; 启用动画，周期为 2s 且无限循环。
  5. 保存后刷新页面，骰子应无需任何交互就开始旋转。
/* 代码 9-6 */
@keyframes rotateDice {
  0%   { transform: rotate3d(0, 1, 0, 0deg);}
  50%  { transform: rotate3d(0, 1, 0, 180deg);}
  100% { transform: rotate3d(0, 1, 0, 359deg);}}
#dice{
    width:100px; height:100px; margin:0 auto;
    transform-style:preserve-3d;
    perspective:800px;
    perspective-origin:center center;      /* 与任务9-1 的 bottom center 不同 */
    animation: rotateDice 2s linear infinite;}
/* .face / .front / .back / .right / .left / .top / .bottom 与代码9-3 相同 */
AI 前沿

AI 前沿：让 AI 帮你「编舞」

关键帧是最适合交给 AI 的重复性劳动

AI

写 @keyframes 本质上是编舞：把一段动作拆成若干百分比节点，再逐帧给出样式。这恰好是 AI 最擅长的模式化工作——你描述「一个按钮被 hover 时先放大 1.1 倍再回弹，同时阴影扩散」，GitHub Copilot、通义灵码、文心快码就能给出完整的过渡与动画代码。你的价值在于判断这段舞好不好看、性能可不可接受。

  • 提示词示例：「用 CSS 写一个 2s 的循环呼吸灯动画，两个圆交替缩放，用 animation-delay 错开」。
  • 性能提醒：优先对 transform 与 opacity 做动画，尽量少对 width、top、left 做动画（会触发布局重排）。
  • 无障碍提醒：应尊重用户的系统偏好，必要时为减弱动效偏好提供降级方案。
  • 职业提醒：AI 很容易写出「能跑但性能差」的动画，能用开发者工具的性能面板验证，才是真本事。

本课小结

  • 过渡 transition：定义元素在两种状态之间切换的效果，常用 :hover 触发，必须有触发。
  • 简写顺序：transition: property duration timing-function delay;；属性值太多时可用 all 代替。
  • 动画 animation：通过 @keyframes 自定义关键帧，可控制中间步骤，可控性高于过渡。
  • animation: name duration timing-function delay iteration-count direction fill-mode;——name 必须与 @keyframes 名称一致。
  • 循环动画用 infinite；duration 默认值为 0，不写时长就看不到任何效果。
