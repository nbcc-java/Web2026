# 《网页制作（HTML5+CSS3）》2026 学年课程教学计划

> 依据教材：《网页制作（HTML5+CSS3）》，郑哲、傅冬 主编，电子工业出版社，2025 年 1 月第 1 版
> 课程定位：职业教育国家在线精品课程配套教材 · 对接 1+X《Web 前端开发职业技能等级标准》（初级）
> 适用专业：高职计算机类、电子信息类、电子商务类等专业

## 一、课程总体设计

| 项目 | 内容 |
|---|---|
| 课程性质 | 专业基础课（理实一体） |
| 建议总学时 | 48 学时（混合式教学，含线上自主学习） |
| 课堂组织 | 以「教学单元」为基本授课单位，1 单元 = 40 分钟 = 1 个课件 |
| 单元数量 | 26 个教学单元（覆盖教材 10 个项目） |
| 教学模式 | 项目引领、任务驱动、师生结对；每单元含「目标—导览—知识—演示—检测—小结—作业」完整闭环 |
| 对接证书 | 1+X Web 前端开发（初级）：静态网页设计开发能力 |
| 课程思政 | 每单元设「思政课堂」页，内容取自教材项目扉页原文 |

## 二、能力主线

```
项目1-2  认识 Web、会写 HTML        →  能搭出「有结构的页面」
项目3-4  用选择器与字体属性美化     →  能做出「有样式的页面」
项目5    盒子模型                   →  能理解「页面是怎么占位的」
项目6    表格与表单                 →  能做出「能交互的页面」
项目7-8  浮动/定位/Flex             →  能排出「有布局的页面」
项目9    过渡和动画                 →  能做出「会动的页面」
项目10   多媒体                     →  能做出「有声有色的页面」
```

## 四、40 分钟单元的标准节奏

| 时段 | 环节 | 对应课件页 |
|---|---|---|
| 0–3 min | 复习导入 + 学习目标 | objectives |
| 3–6 min | 思政课堂 / 案例导入 | ideology |
| 6–28 min | 新知讲解 + 效果演示 + 任务驱动 | section / bullets / cards / table / compare / demo / task |
| 28–31 min | AI 前沿拓展 | ai |
| 31–35 min | 随堂检测 | quiz |
| 35–38 min | 本课小结 | summary |
| 38–40 min | 布置作业 + 预习 | homework / refs |

## 五、考核评价建议

| 环节 | 占比 | 说明 |
|---|---|---|
| 过程性考核 | 40% | 每单元「随堂检测」成绩 + 课堂任务完成度 |
| 实训作业 | 30% | 各项目课后操作题（如创建站点、制作登录表单、圣杯布局等） |
| 期末综合项目 | 20% | 综合运用 10 个项目知识，完成一个静态网站（建议含首页、列表页、详情页、表单页） |
| 素养表现 | 10% | 课堂讨论（思政话题）、代码规范、文件管理习惯 |

## 七、教材使用与课件的关系

- 课件内容**逐小节对应教材**，页面上标注了教材小节号与任务编号（如「任务 5-4」），学生可对照教材复习。
- 教材中的表格（字体属性表、优先级权重表、input 取值表、Flex 属性表等）已在课件中完整还原。
- 教材个别印刷疑误（如端口号「0～216」）已在课件中按标准表述更正，并加注说明。
