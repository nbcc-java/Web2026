7.1.1

标准流

一切布局的起点：盒子按默认方式排，谁都别抢谁的位置。

知识要点

标准流：像河流一样向下流淌的默认排版

教材原文：标准流亦称文档流、普通流，是元素的默认排版方式

  • 网页布局要解决的问题：一个网页如何排列分布这些盒子，从而达到美观的排版。
  • CSS2 提供 3 种盒子排版模型：标准流排版、浮动排版、定位排版；CSS3 又新增了 Flex 排版、网格排版 等。
  • 定义：元素在排版布局过程中，会默认按照自左而右、自上而下的方式流式排列；当前面的内容位置发生变化时，后面的内容位置也会随之发生变化。
  • 具体表现：多个元素根据定义顺序形成盒子序列，同级块级盒子自上而下排列，同级行内元素自左而右排列；对于子元素亦是如此。
  • 整个页面犹如河流一样不断分支，并向同一个方向流动，故而称其为「标准流」。
  • 关键结论：浮动排版和定位排版，都是通过更改元素的默认排版方式实现的。
7.1.2

浮动排版

浮动靠 CSS2 的 float 属性实现，它让盒子「浮」起来，也带走了父容器的高度。

表7-1 float 属性值（教材完整还原）

当 float 值为 left 或 right 时，元素变成浮动元素，同时脱离标准流

属性值描述
none默认值，不浮动，按照标准流排列元素

任务7-1｜浮动特性1：脱离标准流

目标：使用 float 属性将「框1」盒子向右浮动，比较浮动前、后的效果（图7-2、图7-3）

任务目标观察浮动前后盒子的位置变化，理解「浮动元素不在标准流中，标准流中的块框表现得就像浮动框不存在一样」。
  1. 准备一个带虚线边框的父容器 .outer，内部放三个 50px×50px 的 .box。
  2. 浮动前：div 作为块级元素占据父容器的一整行，三个框自上而下排列。
  3. 给「框1」加上 .box1{ float:right; }，它向右移动，直到外边框碰到父容器的边框为止。
  4. 依次给「框2」「框3」也加上 .box1：三个框向右排列成一行。
  5. 由于子元素全部脱离标准流，父容器最终塌陷成了一条线（图7-4、图7-5）。
.outer{ border:1px dashed #969696;}
.box{
    background-color:#FAFAF1;
    border:1px dashed #373734;
    width:50px; height:50px; margin:10px;}
.box1{ float:right;}
知识要点

浮动的四大特性（教材归纳，务必照讲）

这四条，是理解后续所有浮动布局的地基

  • ① 浮动可以让块级元素显示在同一行中。
  • ② 当浮动元素向指定方向移动时，直到它碰到父容器的边框或另一个浮动框为止。
  • ③ 浮动元素会脱离原来的标准流，且不占据原来标准流中的位置和空间。
  • ④ 子元素全部浮动后，如果父容器中没有其他内容撑开高度，则会发生高度塌陷。
  • 补充：浮动框向左/右移动，直到它的外边缘碰到父容器（包含框）的边框或另一个浮动框的边框为止。

任务7-2｜浮动特性2：图文环绕（浮动的本质）

目标：验证浮动元素浮于标准流之上/之下，并利用浮动实现图文环绕效果

任务目标用新疆简介素材，把图片向左浮动，观察文字如何绕开图片重新排列。
  1. 实验：把 .box1 改成 float:left 后，「框1」似乎把顶替上来的「框2」遮挡了（图7-6）。
  2. 用开发者工具选中「框2」可见：它隐藏在「框1」之下，但「框2」中的文字仍在原来的位置上（第二行），并与「框3」重叠（图7-7）。
  3. 核心原理——元素立体两层模型：HTML 元素在构造时由两层构成，底层是元素层，其上方是内容层（文字、图片、视频等）。
  4. 设置浮动后，该元素脱离标准流、提升层级，「浮」到内容层；后面的元素上移占据浮动元素原有的元素层位置。
  5. 此时标准流元素的内容层被挤出来，形成环绕效果（图7-9）——这正是有些书把浮动称为「提升半个层级」的原因。
  6. 图文环绕是浮动的本质。
.outer{ width:500px; background-color:#F8F4E7; color:#666; padding:5px 10px;}
.outer>;img{ width:250px; float:left; padding:5px;}
.outer>;p{ text-indent:2em;}
.outer>;p.intro::first-letter{ font-size:2em;}

任务7-3｜浮动特性3：浮动对行内元素的影响

目标：把研究对象从 div 换成 span，观察浮动对行内元素的特性

任务目标验证「浮动会使行内元素具有块级元素的特征」这一结论。
  1. 准备两个 span，并设置 width:50px; height:50px。
  2. 浮动前：width、height 对行内元素不起作用，宽高由文字内容决定（图7-11）。
  3. 给「行内2」加上 .fl{ float:left; }：它突然变大，width / height 起作用了（图7-12）。
  4. 同时，排在后面的「行内2」向左浮动后被排到左边，原本在前面的「行内1」被挤到了右边。
  5. 结论一：浮动会使行内元素具有块级元素的特征，又称「块级格式化上下文」。
  6. 结论二：行内元素在立体空间中与文字同属内容层，会受到浮动影响被挤出原有位置。
.outer{ border:1px dashed #969696;}
.outer span{ border:1px dashed #373734; background-color:#FAFAF1;
    width:50px; height:50px;}
.fl{ float:left;}

任务7-4｜使用清除浮动解决父容器高度塌陷

目标：用清除浮动的样式属性和规则，解决父容器高度塌陷的问题（图7-16、图7-17）

任务目标在浮动元素之后添加一个承担清除浮动工作的元素，让父容器重新被撑开。
  1. 先记住清除浮动的三个前提条件和要点（教材原文）：① 具有 clear 属性的元素必须是块级元素。
  2. ② 具有 clear 属性的元素必须与浮动元素是同级元素（兄弟关系）。
  3. ③ 设置 clear 属性的目的是清除标准流元素上方的浮动元素对自身的影响。
  4. 方案一（加空 div）：在浮动元素之后添加 <div class='clr'></div>，样式为 .clr{ clear:right; }——能达成目的，但在 HTML 中添加了不具有语义功能的空 div。
  5. 方案二（推荐，::after 伪元素）：给父容器加一个类，用伪元素在内容末尾插入一个清除浮动的块级盒子。
  6. 易错点（教材原话）：因为 ::after 伪元素默认是行内元素，根据前提条件，必须将其 display 设置为 block；同时需要满足添加的内容为空，可通过 content:"" 实现。
/* 代码7-6 方案二：使用 ::after 伪元素（推荐） */
.clr::after{
    content:";";;
    display:block;
    clear:right;}

/* 举一反三：清除其他方向或两侧浮动，
   只需修改 clear 的属性值即可 */

/*   <div class="box box1">框2</div> */
/*   <div class="box box1">框3</div> */
/* </div> */
7.1.4

使用 BFC 解决高度塌陷

如果说 clear 是「事后补救」，BFC 就是「提前围一堵墙」。

知识要点

BFC：给浮动元素围一堵「围墙」

教材比喻：「如同围墙，围墙内的东西出不去，围墙外的东西进不来。」

  • BFC（Block Formatting Context，块级格式上下文）：使用浮动的元素将生成 BFC，它为元素提供了一个独立的布局环境。
  • 该环境中的内容不会影响外部的布局，外部的布局同样也不会影响该环境中的内容。
  • 解决高度塌陷的第二个思路：给父容器加上一堵围墙（BFC），围墙能包含浮动元素，使之无法脱离父容器区域，从而达到清除浮动的效果。
  • 教材补充：目前看到的 3 种触发 BFC 的方式之外，还可以通过绝对定位等其他方式触发 BFC。
任务驱动

任务7-5｜触发 BFC 的 3 种常用方式

目标：用 inline-block、父元素浮动、overflow 三种方式触发 BFC，解决高度塌陷

任务目标比较三种触发方式的原理与副作用，学会「根据具体情况选择合适的方法」。
  1. 方式1：设置 display:inline-block——触发 BFC 后，每个行内块元素都具有「包裹性」，当其中存在浮动元素时，能包裹住内部的浮动元素（图7-18）。
  2. 方式2：设置父元素浮动——父元素具有 BFC，可以包裹住浮动的子元素。
  3. 注意事项（教材原文）：给父元素设置浮动属性后，同样也会影响自身和其他元素。所以每种方法都有其自身的特点和优缺点，需要根据具体情况来选择（图7-19）。
  4. 方式3：设置 overflow 属性值（最常用）——当把父元素的 overflow 设置为除默认值之外的值时，就会触发该元素的 BFC，故可设为 scroll、hidden 或 auto（图7-20）。
  5. overflow 取值速记：visible 默认不裁剪、hidden 溢出隐藏、scroll 始终显示滚动条、auto 由浏览器决定是否显示滚动条、inherit 继承父元素。
/* 方式1：inline-block 触发 BFC */
.outer{ border:1px dashed #969696; display:inline-block;}

/* 方式2：父元素浮动触发 BFC */
.outer{ border:1px dashed #969696; float:left;}

/* 方式3：overflow 触发 BFC（最常用） */
.outer{ border:1px dashed #969696; overflow:hidden;}

/* 三种方式的 .box / .fr / .fl 均相同 */
.box{ background-color:#FAFAF1; border:1px dashed #373734;
      width:50px; height:50px; margin:10px;}
.fr{ float:right;}
.fl{ float:left;}

本课小结

五句话，把「标准流—浮动—修补」这条线串起来

  • 标准流是元素的默认排版方式：自左而右、自上而下，块级自上而下、行内自左而右；浮动与定位都是更改默认排版方式实现的。
  • float 取 left/right 时元素脱离标准流；四大特性：同行显示、碰到边框或浮动框为止、不占原空间、子元素全浮动导致高度塌陷。
  • 元素立体两层模型：底层是元素层、上方是内容层；浮动元素浮到内容层，后面元素上移占元素层，其内容层被挤出形成环绕——所以浮动被叫做「提升半个层级」。
  • 清除浮动用 clear；三个前提：必须是块级元素、必须是浮动元素的兄弟、目的是清除上方浮动的影响；::after 伪元素方案须设 display:block 且 content:""。
  • BFC 是独立布局环境，像一堵围墙；三种常用触发方式：display:inline-block、父元素浮动、overflow 取非 visible 值。
