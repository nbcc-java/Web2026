font-size 属性值与常用单位（教材表3-3 及单位对比）

为什么需要这么多数值类型？为的是兼容不同浏览器与移动设备尺寸

取值 / 单位描述
medium如果不设置，则为浏览器的默认字体大小，通常为 16px
length某个固定值，常用单位为像素（px）、em、点（pt）、rem；使用最频繁，数值越大字体越大
百分比基于父元素或默认值的百分比（%），是一个相对值
inherit继承父元素的字体大小；当前元素未设置字体大小时，会自动继承父元素
px主要用于计算机屏幕，一个像素对应屏幕上的一个像素点；固定大小、不具伸缩性，在种类繁多的移动设备上不太可行
pt英文 point 的缩写，主要用于印刷媒体，是 Photoshop、AI 中默认字体大小单位；1 点 = 1 英寸的 1/72，同样不具伸缩性，现在网页中已很少使用
em相对长度单位，相对于当前元素的字体大小；未设置时相对浏览器默认字体大小，具有伸缩性。教材换算：默认时 1em = 12pt = 16px
rem全称 root em（根 em），CSS3 新增，总是相对于 HTML 根元素；既可只改根元素就成比例调整所有字体，又能避免字体大小逐层复合的连锁反应；除 IE8 及更早版本外，主流浏览器均支持
%与 em 一样相对于父元素或默认值，100% = 1em；同样具有伸缩性，适合移动设备

font-family 属性控制字体族（语法3-5）

为什么不是一个字体名，而是一长串候选列表？

  • 用户的计算机可能没有安装设计师指定的字体，因此需要一个候选的字体族列表，让浏览器决定最佳的显示效果。
  • 字体族分通用字体与具体字体两大类；浏览器按 font-family 列表从左到右的优先顺序查找并显示。
  • 排列原则：最佳字体置于优先顺位，相近字体置于候选顺位，通用字体作为最后保障。
  • 引号规则：字体名称中包含空格（如 Times New Roman）时须加双引号；为兼容性考虑，建议对所有中文字体加双引号。
  • 中文字体的英文名：Microsoft YaHei 微软雅黑、SimSun 宋体、SimHei 黑体；某些版本的 Firefox 与 Opera 不支持 SimSun，宋体甚至写成 Unicode 形式 "\5b8b\4f53"。
  • 中西文混排：通常把西文字体靠前放——西文字体不含汉字，若中文字体优先级更高，会导致指定的西文字体不显示。
CSS 语法3-5

font-family:字体族1,字体族2,…,通用字体族|inherit

/* 宋体的 Unicode 写法（兼容 Firefox / Opera） */

任务3-3｜单行文字的垂直居中

行距 = 行高 − 字体高度；把行高设为容器高度，文字就垂直居中了

  • 行高是两行文字基线之间的距离；行距是上一行底线与下一行顶线之间的距离，即 行距 = 行高 − 字体高度。
  • 把行距再分成相等的上间距和下间距：行高 = 上间距 + 字体高度 + 下间距，默认情况下字体高度垂直居中。
  • 要实现元素在容器中垂直居中，只需把行高设置为元素容器的高度——这就是本任务的核心。
  • 教师补充：为保证阅读舒适性，通常把行高设为当前字体大小的 1.4～1.5 倍。
  • 常见的编程错误：行高是非负的正整数，使用负数是错误的。
动手试试：把容器的 height 与 p 的 line-height 同时改成 200px，观察居中效果是否依然成立。

font 简写属性（语法3-9）

一次性定义多种字体样式，也叫综合样式属性

  • 写法顺序：font: font-style | font-variant | font-weight | font-size/line-height | font-family;
  • 常见的编程错误：line-height 在 font 简写属性中必须和 font-size 连用，并写成「font-size/line-height」的形式。
  • 技巧：font 简写属性中至少包含 font-size 和 font-family 两个值，不设置的其他值使用默认值。
  • 教材示例 font: italic bold 12px/2em "SimSun",sans-serif 等价于分别书写 5 条独立声明。

3.3.5 自定义字体：@font-face

除了系统字体，还可以引入个性化字体文件，实现特定的艺术效果

  • 通过 CSS 的 at 规则（at-rule）@font-face 指定一个用于显示的自定义字体，字体通过 src 属性加载。
  • src 属性值可以是相对路径或 URL 地址，分别从用户本地或远程服务器加载字体文件。
  • 使用分两步：① 定义自定义字体（@font-face）；② 引用自定义字体（像普通字体一样用 font-family 使用）。
  • 注意事项：自定义字体的名称要符合标识符的定义规则；引用时须与定义的名称完全一致。
  • 常见的编程错误：引用的字体名称与自定义的字体名称不一致，是自定义字体不起作用的常见原因。
CSS 自定义字体语法
@font-face{
  font-family:自定义字体的名称;
  src: url(';fontfile_url';);}

/* 示例：定义 */
@font-face{
  font-family:qigong;
  src: url(';assets/qigong.ttf';);}

/* 引用：名称必须完全一致 */
font-family:qigong;

  1. 01 单选关于文字的样式排版，说法错误的是（　　）。
    答案D设置字体颜色使用的是 color 属性，CSS 中并没有 font-color 这个属性。
  2. 02 单选下列单位中，总是相对于 HTML 根元素、可避免字体大小逐层复合的是（　　）。
    答案Drem 即 root em，CSS3 新增，始终相对于 HTML 根元素；em 相对于当前元素（或父元素）。
  3. 03 单选要用 @font-face 引入自定义字体，下列说法正确的是（　　）。
    答案B名称不一致是自定义字体不起作用的常见原因；src 既可用相对路径，也可用 URL。
  4. 04 多选关于 font-family 属性，下列说法中正确的有（　　）。
    答案A、B、C中西文混排应把西文字体靠前：中文字体优先级更高时，指定的西文字体将无法显示。
  5. 05 多选关于 font 简写属性与 line-height，下列说法中正确的有（　　）。
    答案A、B、D行高是非负的，使用负数是错误的；单行居中靠「行高 = 容器高度」。

本课小结

  • 字体三件套：font-size（medium/length/百分比/inherit，px·pt·em·rem·%）、font-family（候选列表＋通用字体兜底）、font-weight 与 font-style。
  • 字体族要点：中文字体建议加双引号并优先使用英文名，中英混排时西文字体靠前；衬线字体有边角装饰，宋体即典型中文衬线字体。
  • 行高：默认约为字体大小的 110%～120%，行距 = 行高 − 字体高度；把行高设为容器高度即可实现单行文字垂直居中。
  • 排版五件套：text-align、text-indent、text-decoration、letter-spacing、word-spacing；font 简写时 line-height 必须与 font-size 连用。
  • 自定义字体：@font-face 定义（src 加载）＋font-family 引用，两处字体名必须完全一致。

课后作业

  • 选择题：完成教材 3.5 作业「一、选择题」第 2 题，并说明其余三个选项为什么正确。
  • 操作题（教材原题）：请使用 @font-face 自定义字体语法、引用规则和思源黑体，以《沁园春·雪》这首词为主题，实现个性化的图文创作。
  • 验证题：在中文段落上分别使用 letter-spacing 与 word-spacing，记录两者的效果差异并解释原因。
  • 项目讨论（教材原题）：简述自定义字体的基本步骤和实现要点，并在下次课做 2 分钟分享。
