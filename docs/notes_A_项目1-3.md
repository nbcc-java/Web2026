## 1.1 Web 前端技术简介

**小节号+标题**：1.1 Web 前端技术简介（含 1.1.1 ～ 1.1.4）
**PDF 页**：11 ～ 13

### 技术要点

- **开篇引子（"Web 前端技术难学吗？"）**
  - Web 前端技术主要包括**静态网页设计**和**动态交互**两大部分。
    - 静态网页设计：主要通过 **HTML5 和 CSS3** 等相关技术实现。
    - 动态交互：主要通过 **JavaScript、jQuery** 等动态交互技术实现。
  - 教学比喻：**使用 PPT 软件，软件本身功能不多、学着不难，但要通过它制作一件"艺术品"是另一回事**。如果没有艺术修养、缺乏配色理论知识、不投入足够时间精力实践，要制作出专业的网页并不容易。

- **1.1.1 Web 前端开发职业技能等级标准**
  - 2019 年，为贯彻落实《**国家职业教育改革实施方案**》，积极推动"**学历证书+若干职业技能等级证书**"制度（即 1+X 制度）。
  - 进一步完善计算机软件行业技术技能专业标准体系，为技术技能人才教育和培训提供科学、规范的依据。
  - **工业和信息化部教育与考试中心**依据当前计算机软件行业发展的实际情况，在实施工业和信息化人才培养工程 Web 前端开发专业技术技能人才培养项目的基础上，并在**教育部的指导下**，组织有关专家编写了《**Web 前端开发职业技能等级标准**》（简称"标准"）。
  - 标准将 Web 前端开发职业技能分为 **初、中、高 3 个等级**：

| 等级 | 能力要求 |
|---|---|
| 初级 | 具有**静态网页设计开发**能力 |
| 中级 | 具有**动态网页设计开发**能力 |
| 高级 | 具有**复杂网页设计开发**能力和**网站架构设计规划**能力 |

- **1.1.2 什么是全栈工程师**
  - "全栈"翻译自英文 **full-stack**，表示为了完成一个项目所需要的一系列技术的集合；"**栈**"是指一系列**子模块**的集合。
  - 全栈工程师（full-stack engineer）也叫**全端工程师**：掌握多种技能、对前端知识和后端架构都有深入了解，拥有足够学习能力，能利用多种技能解决问题、**独立完成产品**的人。
  - 熟悉多种开发语言，同时具备前端和后端开发能力；对从需求分析、原型设计到产品开发、测试、部署、发布的**全流程**都十分熟悉。
  - **前端**需熟悉：HTML、CSS、JavaScript、H5，以及 **Bootstrap、EasyUI** 等各种前端框架。
  - **后端**需熟悉：**Java、ASP.NET、PHP、Node.js 或 Go** 等。
  - 判定标准（教材原话）：既能开发前端又能开发后端，同时可以**独立完成一个简单的电子商务网站的制作**，就算全栈工程师。
  - 一句话概括：**全栈工程师就是可以独立开发产品的人**；思维方式更开阔、更新颖、更综合，不局限于特定的知识或技能。

- **1.1.3 哪些人适合学 Web 前端（6 类人群）**

| 序号 | 人群 | 教材要点 |
|---|---|---|
| 1 | 大学毕业生 | 就业面宽；Web 前端工程师**技术门槛相对较低、需求量大、薪资待遇良好、发展空间广阔**；校园储备的知识量适合继续深造 |
| 2 | 设计师 | 常见情况；通常已多少了解一些 Web 前端知识，可能对**样式和数据分离**的特性产生兴趣；优势是**能更好地把握设计稿的表现重点** |
| 3 | 电商推广从业者 | 移动互联网普及造就商业运营新模式；线上线下电商促销活动需要大量**应用推广和活动促销页面**的策划与制作，通过移动端、PC 端快速分发，形成**高流量、高频**的商业新模式；电商平台提供者与线上店铺商家都需要雇佣大量熟悉 Web 前端页面设计与制作的员工 |
| 4 | 网虫 | 青少年很早接触互联网（玩 3D 游戏、做网站等），想学与互联网相关内容首选 Web 前端 |
| 5 | 策划编辑 | 不仅要熟悉文字和图形创作，还要顺应时代潮流，需要对常见代码有一定认识 |
| 6 | 后端工程师 | 思维方式相似，常因业务需求或能力倾向被推到前端工作，实现基于 **AJAX** 和各种复杂架构的 Web 应用 |

- **1.1.4 W3C 组织与 W3C 标准**
  - W3C = **万维网联盟**（world wide web consortium），创建于 **1994 年**，国际上最著名的标准化组织之一，主要致力于 Web 技术的标准化。
  - 目的：解决 Web 应用中不同平台、技术和开发者带来的**不兼容问题**，保障 Web 信息的顺利和完整流通。
  - 制定标准并督促 Web 应用开发者和内容提供者遵循；标准内容包括**使用语言的规范、开发中使用的导则和解释引擎的行为**等。
  - 制定了对互联网技术起基础性与根本性支撑作用的标准，包括 **XML 和 CSS** 等众多影响深远的标准规范。

### 教材中的关键解释 / 易错点

- 静态网页（HTML5+CSS3）与动态交互（JavaScript/jQuery）的**分工**是本课程的入门框架。
- "全栈"的"栈"是**子模块的集合**，不是数据结构意义上的"栈"。
- 1+X 等级标准由**工业和信息化部教育与考试中心**编写（教育部指导），不是教育部单独发布。

## 1.2 认识网页

**小节号+标题**：1.2 认识网页（含 1.2.1、1.2.2）
**PDF 页**：13 ～ 14

### 技术要点

- **开篇**：不管 Web 前端开发技术如何发展，其核心就在于 **HTML、CSS、JavaScript 这 3 种技术**。
  - 提到的技术与框架：HTML、CSS、JavaScript、jQuery、AJAX、React、Angular、Vue、Node.js。
  - 教材观点：框架层出不穷、更新又快，有些**昙花一现只流行一时**；只有牢固掌握核心技术（HTML/CSS/JS）才能顺利学习 React、Vue、Angular 这类前端框架。**掌握基础的原生语言是网页开发技能初学者的基本功**。

- **1.2.1 网页与网站**
  - **网页（web page）**：用户通过浏览器看到的包含表单、文字、图片、链接，有时还包含动画、音频、视频等内容的页面。
  - **网站（website）**：各种各样内容的网页及其相关资源的集合。
    - 信息内容繁多的网站：如**腾讯、网易**这样的**门户网站**。
    - 只有几个产品页面的网站：如**小型公司的产品网站**。
    - 但它们**都是由多个基本网页构成的**。
  - **主页（homepage）**：浏览者输入某网站的域名后看到的**第一个网页**，通常也被称为"**首页**"。
  - 正因为主页是浏览一个网站的**起始网页**，主页有时也就成了网站的**代名词**。
    - 例：日常讲的"**个人主页**"，本质上是分享个人爱好、日志的**网站**，而不是具体的某个页面。

- **1.2.2 网页的构成要素**（对应图1-1 网页的构成要素）

| 构成要素 | 教材解释 |
|---|---|
| **文字和图片** | 网页的**基本构成要素**，早期的网页主要通过文字或图片来表达内容 |
| **链接** | 分为"**文字链接**"和"**图片链接**"；单击带链接的文字或图片，网页可自动跳转到对应的文件或网址；让不计其数的网页链接交错在一起，使网络成为一个整体，**这正是网页的魅力所在** |
| **动画** | 常见类型：**Flash 动画、GIF 动画、CSS3 动画、使用 JS 控制的脚本动画**；通常运动的内容比静止的内容更吸引注意力 |
| **表单** | 一种可以在浏览者与服务器之间进行数据信息"**交互**"的控件集合体；实现信息搜索、数据提交等交互功能 |
| **音/视频** | 网页不再局限于播放单调的 **MIDI** 音乐，已发展为能够展示**视频、直播和游戏**的新兴平台 |

## 1.3 网站工作原理

**小节号+标题**：1.3 网站工作原理
**PDF 页**：14 ～ 17

### 技术要点

- **请求—响应流程**（对应图1-2 网站工作原理）
  1. 用户打开浏览器输入网址（如输入**教育部的网址**），按"Enter"键。
  2. 意味着**客户端（client）**向**互联网（internet）**发送了一个**请求（request）**。
  3. 该请求通过互联网的**不同设备路由**被转发到 **Web 服务器（web server）**上。
  4. Web 服务器是**驻留在互联网上的计算机程序**，处理浏览器等 Web 客户端的请求并返回相应响应。
  5. 将放置在其上的网站文件提供给用户浏览，最终通过**浏览器呈现**出用户能够直观查看的页面。
- 这些处理过程非常快速（通常都是**毫秒级**的）；后台技术处理了所有复杂细节，对前台用户而言**只需打开浏览器、输入网址、查看页面**。

### 任务1-1 使用浏览器访问课程网站

- **任务目标**：使用浏览器打开课程网站，并查看页面显示效果。
- **核心步骤**：
  1. 在计算机设备中选取任意一款主流浏览器工具（**推荐 Google Chrome 浏览器**）。
  2. 在地址栏中输入：`www.moe.gov.cn`（教育部网站）。
  3. 按"Enter"键，查看页面显示结果。
  4. **观察地址栏发生的变化**。
- **关键发现**：在地址栏中，**自动添加了 `http://`**。

### 关键解释 / 易错点（HTTP 与 HTTPS）

| 协议 | 全名 | 教材解释 |
|---|---|---|
| **HTTP** | hypertext transfer protocol，**超文本传输协议** | 一种用于**分布式、协作式和超媒体信息系统**的**应用层协议**；简单来说，就是一种**发布和接收 HTML 页面的方法**，用于在 Web 浏览器和网站服务器之间传递信息 |
| **HTTPS** | hypertext transfer protocol secure，**超文本传输安全协议** | 一种通过计算机网络进行**安全通信**的传输协议；**经由 HTTP 进行通信，但利用 SSL/TLS 来加密数据包**；开发的主要目的是**提供对网站服务器的身份认证，确保交换数据的私密性与完整性** |

- **端口**：HTTP 默认工作在 **TCP 的 80 端口**，HTTPS 默认工作在 **TCP 的 443 端口**。
- 出于安全考虑，现在很多主流网站都采用 HTTPS。

### 端口与域名的关键解释

- **端口比喻**：把服务器地址比作**一间房子**，端口就是**出入这间房子的门**，它是一个 **0～2^16 之间的整数**。
  - ⚠️ 存疑提示：教材原文写作"0～216 之间"，按常识应为 **0～65535（即 2^16）**，课件建议表述为"0～65535"。
- **默认端口可以不用书写出来**；如果访问的不是默认端口，则需要在地址栏中**明确书写出来，并使用冒号分隔**。
  - 示例：`http://localhost:8081` 使用 8081 端口访问对应资源。

**表1-1 常用协议及其默认端口**（完整还原）

| 协议 | 端口 | 说明 |
|---|---|---|
| FTP | 21 | FTP 服务器所开放的默认端口 |
| HTTP | 80 | 超文本传输协议 |
| HTTPS | 443 | 使用 SSL/TLS 对数据包进行加密，HTTP 传输 |
| SMTP | 25 | 简单邮件传送协议，用于发送邮件 |
| POP3 | 110 | 邮件接收协议 |

- **域名（domain name）**：互联网基础架构的重要组成部分，为人们提供**可理解的网络地址**。
- **IP 地址**：
  - **IPv4**：32 位，通常写成 4 个范围在 **0～255** 并由点分隔的数字，例：`223.252.199.73`。
  - **IPv6**：128 位，通常写成 8 组由冒号分隔的 4 个十六进制数，例：`2027:0da8:8b73:0000:0000:8a2e:0370:1337`。
  - 计算机容易处理 IP 地址，但人们**很难记忆和书写**；且 **IP 地址可能会随时间的推移而发生改变**。
  - 解决方式：**使用域名来对应 IP 地址**，例：`http://www.moe.gov.cn/` 对应 `223.252.199.73`。

### 任务1-2 使用域名访问课程网站

- **任务目标**：使用 `moe.gov.cn` 作为请求地址，再次通过浏览器访问课程网站，并查看结果。
- **关键问题**：本任务中的请求地址与任务1-1 相比**少了 www**，但显示的页面结果还是一样的，为什么？

### 域名结构（对应图1-3 域名结构）

- 域名拥有一个**固定的结构**，通常由点分隔成几个部分；**理解域名时，需要从右往左阅读**。
- **顶级域名**（图1-3 中的 ④）：表示用户域名所提供的**服务类型**。

| 顶级域名 | 含义 / 使用限制 |
|---|---|
| `.cn`、`.us` | 分别代表中国和美国；表示必须提供指定语言的服务器或托管在指定国家 |
| `.gov` | 通常只能被**政府部门**使用 |
| `.edu` | 只能被**教育或研究机构**使用 |
| `.org` | 主要适用于各种类型的组织机构，包括**非营利组织**等 |
| `.com` | 一般表示**企业性质**的网站 |

- 以 `www.moe.gov.cn` 为例：
  - `gov.cn` 是一个**一级域名**（`.gov` 是政府机构的顶级域名，`.cn` 是中国国家顶级域名）。
  - 位于一级域名之前的 **`moe` 是一个二级域名**，通常用来表示某个特定的机构或部门，这里是**教育部**的英文简称。
  - 图1-3 中的 ① 对应的 **`www`** 与它们构成了一个**三级域名**。
  - 工程实践中解析域名时，默认情况下，**三级域名 `www.moe.gov.cn` 会指向它的二级域名 `moe.gov.cn`**，因此在地址栏输入 `moe.gov.cn` 会被解析成对应的 `www.moe.gov.cn`。
- **技巧**：同样地，`www.do**in.com` 这样的二级域名会指向它的一级域名 `do**in.com`，从而在实际访问时**可以省略 www**。

### 站点的概念（关键解释）

- 在创建第一个 HTML 页面之前，还需要创建一个**站点**。
- 在 Dreamweaver 中，站点**专门用于存放某个网站的所有相关文档的本地或远程存储位置**。
- 利用站点，可以**组织和管理所有页面文档与资源**。
- 开发完成后，可将站点**整体上传到 Web 服务器**中，确保页面之间的**链接引用关系不变**。
- **良好的编程习惯**：确保新建的每个页面文件都放置在指定的站点（或项目）中。

| 模式 | 说明 |
|---|---|
| **服务器模式**（默认） | Dreamweaver 自带 **Node.js 服务器**，在浏览器窗口中以服务器模式提供页面显示（图1-29）；地址栏内容以 **`127.0.0.1`** 开始；目的是**模拟 Web 服务器交付页面的真实效果**，用户看到的页面就是将来上传到服务器后的效果；页面中具有**服务端执行的动态脚本**时，该模式下具有**正确的交互反馈** |
| **静态浏览器模式** | 在"首选项"→"实时预览"中**勾选"默认为静态浏览器中预览"**（图1-30）；地址栏内容**类似文件资源管理器的文件路径**（图1-31）；与在本地文件夹中直接用浏览器打开该文件的效果一样，**无法执行那些需要服务器执行的动态脚本** |

- **技巧（回送地址）**：**`127.0.0.1`** 是一个特殊的 IP 地址，被称为"**回送地址**"（loopback address），指向本地主机，通常用于测试；它与系统保留的域名 **`localhost`** 对应。
  - `http://127.0.0.1/index.html` 与 `http://localhost/index.html` 是**等价**的。

## 2.1 HTML 简介

### 技术要点

- HTML 是一种"**超文本标记语言**"，由它构成的页面有一个非常大的特点：由许多 **HTML 标签（也叫元素）**组成。
- 不管多么复杂、多么精美的页面，都是通过这些 HTML 标签**相互嵌套或并列**组合而成的；**HTML 标签是定义页面内容的核心**。

**代码2-1 第一个HTML 页面（原样摘录）**

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>第一个HTML 页面</title>
  </head>
  <body>
    欢迎一起学习Web 前端技术
  </body>
</html>
```

- **教学比喻（图2-1 HTML、CSS 与 JavaScript 的关系）**：

| 技术 | 比喻 | 作用 |
|---|---|---|
| **HTML** | 人的"**骨架**" | 页面的内容和布局靠它支撑 |
| **CSS** | 给人**穿搭和化妆** | 用于美化内容和布局，让用户愉快地浏览和阅读网页 |
| **JavaScript** | 赋予人**动作和行为** | 主要用于实现网页交互 |

- 学生提问式比喻：HTML 标签可以理解成**乐高组件**，就像乐高组件可以搭建物体一样，通过 HTML 标签就可以搭建出各种复杂的页面。

## 2.2 HTML 页面的基本结构

**小节号+标题**：2.2 HTML 页面的基本结构
**PDF 页**：31 ～ 34（对应图2-2 HTML 页面的基本结构）

### 技术要点

#### 1．文档类型声明（DOCTYPE）

- DOCTYPE 是 **document type** 的缩写，用来告诉浏览器 **HTML 文档的类型**（是 HTML 或 XHTML），以及**如何来解析该网页**。
- HTML5 之前，必须通过 **DTD（文档类型定义）**指定文档的解析规范，它规定了使用通用标签语言的网页语法。
- **完整的 XHTML 过渡类型的文档声明**（教材原文）：

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
"http://www.w3.o**/TR/xhtml1/DTD/xhtml1-transitional.dtd">
```

- **HTML5 以后**采用相对宽松的规则，没有要求指定 DTD 的描述，可统一简写为：

```html
<!DOCTYPE html>
```

- **良好的编程习惯**：尽管 DOCTYPE **不区分大小写**，但**统一写成大写形式**是良好的编程习惯。

- **两种渲染模式（重要考点）**

| 模式 | 说明 |
|---|---|
| **怪异模式** | 浏览器使用**自己的模式**解析渲染页面 |
| **标准模式** | 浏览器使用 **W3C 官方标准**解析渲染页面 |

  - 不同的渲染模式会影响浏览器对 **CSS 代码，甚至是对 JavaScript 脚本**的解析。
  - **如果使用 DOCTYPE，则浏览器将按标准模式解析渲染页面；否则将按怪异模式解析渲染页面**。
  - 使用怪异模式对运行在**低版本 IE 浏览器**下的页面影响很大。
  - **技巧**：由于两种渲染模式有时会有很大差异，因此**正确使用 DOCTYPE 对一个页面的渲染来说很重要**。

#### 2．`<html>` 标签

- `<html>` 标签是 HTML 页面中所有标签的**顶层标签（也叫根标签）**，页面中的所有标签都必须放在 `<html>` 标签内部。

#### 3．`<head>` 标签

- 位于 `<html>` 标签内部，用于标识 HTML 页面的**头部区域**。
- 包裹在 `<head>` 和 `</head>` 之间的内容都属于头部区域定义部分。
- 主要用来设置一些与网页相关的信息，如**网页标题、字符集、网页描述**等。
- 这里设置的相关内容**一般不会直接显示在浏览器窗口的内容区域中**。

#### 4．`<meta>` 标签

- 位于 `<head>` 标签内部，**不包含任何文字内容**，主要用来定义文档的**元数据**。
- 元数据以**属性形式**呈现，使用"**名称=值**"的方式进行书写。
- 该标签可以设置**页面字符集、关键字、网页描述信息、作者**等内容。

**（1）使用 `<meta>` 标签设置页面字符集**

- 浏览器会据此**调用相应的字符编码以正确显示页面内容**。
- 如果当前页面没有设置字符集，浏览器会使用**默认的字符编码**显示：
  - 在**简体中文操作系统**下，浏览器的默认字符编码是 **GB2312**。
  - **Google Chrome 浏览器的默认字符编码是 GBK**。
- 当字符集设置不正确或没有设置，造成**文档的编码和页面内容的编码不一致**时，会导致**页面显示乱码**。
- **UTF-8**：又叫"**万国码**"，涵盖地球上几乎所有地区的文字，包括英文、繁体中文、简体中文、日文、韩文等，是最常用的文字编码之一。
- **技巧**：要想保持页面内容的编码和浏览器的编码一致，通常需要使用 **UTF-8**，以确保页面正常显示而不出现乱码。

**两种写法（重要）**

```html
<!-- （1）HTML5 的写法 -->
<meta charset="UTF-8">

<!-- （2）HTML4/XHTML 的写法 -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
```

- `<meta>` 开始标签中的 **`charset` 是字符集属性的名**，包裹在双引号之间的 **`UTF-8` 是该属性的值**。
- 像 `<meta>` 这样**只有开始标签、没有结束标签**的特殊标签被称为"**单标签**"，可以写成 `<meta />` 形式。
- **良好的编程习惯**：**根据 HTML5 规范，单标签的"/"建议省略。**
- **一个标签可以有多个属性，属性之间使用空格分隔**（如 http-equiv 和 content 两个属性）。
- **对一个属性而言，如果有多个取值，则使用分号进行分隔**（如 content 属性有两个值：`text/html` 和 `UTF-8`）。

**（2）使用 `<meta>` 标签设置关键字**

- `<meta>` 标签中的关键字主要用于**帮助搜索引擎理解当前页面的主要特征**。
- 对终端用户而言，这些关键字是**不可见**的；作用主要体现在**搜索引擎优化（SEO）**上，使用合适的关键字可以提高网页在搜索引擎中被搜索到的概率。

```html
<meta keyword="keyword1,keyword2,keyword3…">
```

- **技巧**：关键字一般在 **10 个以内**比较合理，多了会**分散关键字权重**，反而影响排名。
- ⚠️ 存疑提示：教材此处写作 `keyword` 属性；W3C/业界通用写法为 `<meta name="keywords" content="...">`。课件按教材摘录时请注明。

#### 5．`<title>` 标签

- 作用一：用于**设置网页的标题**，告诉浏览器当前网页的标题是什么；设置的标题将出现在**浏览器的标签栏**中。
- 作用二：用于**搜索引擎索引**，作为搜索关键字及搜索结果的标题来使用。
- 搜索引擎会根据 `<title>` 设置的标题将网站或文章**合理归类**；它是搜索引擎优化（SEO）中**十分关键的优化项目**，合适的标题可以使网站获得更好的搜索排名。
- 通常，每个网页都可以使用一个**简短的、含有关键字的描述文字**来命名标题，并且该标题在页面中是**唯一**的。

#### 6．`<body>` 标签

- 指定了浏览器显示的**主体部分**，是程序员呈现页面、放置内容的主要位置。
- 所有需要显示的内容都需要放置在 `<body>` 和 `</body>` 之间。

## 2.3 HTML 语法规则

**小节号+标题**：2.3 HTML 语法规则
**PDF 页**：34 ～ 36

### 技术要点

**语法2-1 单标签和双标签语法**

```html
<!-- 定义语法：单标签 -->
<标签名 属性1="属性值1" 属性2="属性值2" … />
<!-- 示例 -->
<img src="../images/pic01.png" />

<!-- 定义语法：双标签 -->
<标签名 属性1="属性值1" 属性2="属性值2" …>
[内容元素]…
</标签名>
<!-- 示例 -->
<h1>
   欢迎一起学习<strong>Web 前端技术</strong>
</h1>
```

### HTML 标签语法的书写规则（6 条，教材原序）

1. HTML 标签通常是由**一组尖括号包围的关键字词**，如 `<html>`、`<body>`、`<title>` 等。这些字词**具有特定语义，需要严格书写，不能自行更改和创作**。例如，**`<book>` 不是合法的 HTML 标签**。
2. HTML 标签通常是**成对出现**的，如 `<body>` 和 `</body>`。第一个标签称为**开始标签**（表示标签作用的开始位置），第二个称为**结束标签**（表示标签作用的结束位置）。为加以区别，**结束标签中有一个正斜杠"/"**。
3. 开始标签和结束标签之间的内容被称为**内容元素**。它可以是**要呈现的文字，也可以是其他元素**。
   - 例 1：`<body>欢迎一起学习Web 前端技术</body>` → 文字"欢迎一起学习Web 前端技术"是 `<body>` 的内容元素。
   - 例 2：`<body><h2>欢迎一起学习Web 前端技术</h2></body>` → `<h2>` 标签就是 `<body>` 的内容元素。
4. 并不是所有标签都有开始和结束标签（即双标签），有些特殊标签只有开始标签、没有结束标签（也就没有内容元素），这样的标签被称为**单标签（也叫空标签）**，如 **`<meta>`、`<hr>`、`<br>`** 等。
5. 标签组合有时可以是**嵌套**的，可理解成"**父子关系**"：被嵌套的标签为**子标签**，包裹其他标签的标签为**父标签**（图2-3 中 `<head>` 与 `<meta>` 就是父子关系）。**嵌套时不能使用交叉嵌套**（图2-4 演示了 `<head>` 与 `<title>` 的交叉嵌套错误）。
6. 标签组合有时也可以是**并列**的，可理解成"**兄弟关系**"（图2-3 中的 `<meta>` 和 `<title>` 就是并列的兄弟关系）。

### 易错点

**常见的编程错误（教材原文 3 条）**

1. 标签名**误拼错拼、多字少字、包含空格**等。
2. 在嵌套标签时，进行**交叉嵌套**。
3. 在书写双标签或嵌套子标签时，**双标签或嵌套子标签未成对**。

- **良好的编程习惯**：尽管标签**不区分大小写**，但在书写时使用**全小写**的形式是良好的编程习惯。

## 2.4 认识更多语义化标签

### 本节导言（关键思想）

- HTML5 中提供了许多**为页面内容添加语义**的标签。
- 传统 HTML 中，常用 `<b>` 代表加粗（bold），`<i>` 代表倾斜（italic）。
- 现代 HTML 会将页面的**语义、呈现和行为进行分离**，更多地使用 **CSS** 实现页面的呈现效果，而不是由 `<b>`、`<i>` 等标签实现。
- 理解 HTML5 中的**语义化标签**对页面的构建有非常重要的意义，也深刻影响着 CSS 的实现。

#### 常见编程错误（重要）

> 将 `<header>` 标签和 `<head>` 标签搞混是初学者的常见错误。需要特别注意：
> - **头部区域是浏览器可见部分**，`<header>` 标签放在 `<body>` 标签内部；
> - 而 `<head>` 标签用于**设置 HTML 文档头部描述信息**，相关内容**并不在浏览器视口中显示**，该标签置于 `<body>` 标签之前，并与 `<body>` 标签并列。

### 2.4.2 `<div>` 标签

- **div 是 division 的缩写**，表示一个**区块或小节**。

- 它可以包含**除 `<body>`、`<html>`、`<head>` 等标签之外的几乎所有主要标签**。
- `<div>` 标签**出现由来已久**，在 HTML5 文档结构标签出现之前，人们经常使用它进行页面布局。
- 保留 `<div>` 的主要原因：**满足那些不确定的结构需求**（如轮播图区域没有特定 HTML5 文档结构标签与之对应，就用 `<div>` 包裹整个轮播图区域）。

### 2.4.3 常用的文本标签

**PDF 页**：40 ～ 48

> 导言：文本是网页中十分重要的组成部分，它所包含的文字是用户和页面进行信息传递的一种重要表现形式。HTML 中提供了一些**常用的文本标签和字符实体**。

#### 1．标题标签

- 可以在描述**段落标题**时使用，也可以作为页面区域模块 div 的**局部标题**使用。
- HTML 自带 **`<h1>`、`<h2>`、`<h3>`、`<h4>`、`<h5>`、`<h6>`** 共 6 个不同级别的标题标签。
- 默认情况下，**数字越小，层级越高，字体也相应越大**（图2-7 标题标签及使用效果）。
- 与 Word 的标题样式非常相似：通常标题**加粗显示**，一级标题字体较大，二级次之，以此类推；语义也极为类似（一级标题级别最高，通常作为**整个页面的大标题**，二级次之作为次级标题）。
- **重要特性**：标题标签是一种**块状标签（block tag）**，有一个特性，即在默认情况下**占据父容器的一整行，不允许其他元素出现在它的左右**。
- **技巧**：块状标签又被称为**块级元素（block-level elements）**，其 **display 样式属性值为 block**。

#### 2．段落标签

- 段落标签（`<p>` 标签）用于定义页面正文的段落文字。
- 同样是**块状标签**，占据父容器的一整行。
- 默认自带样式中，段落文字是**左对齐**的；段落中行与行之间有一定间隔。
- **对齐方式的实现（两种做法）**：
  1. 使用标签的 **`align` 属性**（图2-8 使用 align 属性控制段落文字的对齐方式）；
  2. 使用 **`text-align` 样式属性**来进行对齐控制。
- **`align` 属性的不同取值**：**`left` 对应左对齐、`center` 对应居中、`right` 对应右对齐**。
- **教材观点（易错点）**：使用 align 属性有一个明显缺点——虽然目的是控制段落文字的对齐方式，但是**增加了 HTML 标签的内容**。根据**页面内容和样式分离**的原则，这样的做法**并不推荐**。
  - **良好的编程习惯**：厘清 HTML 和 CSS 的职责与分工，**使用 HTML 描述内容，使用 CSS 控制显示样式**是良好的编程习惯。

#### 3．换行标签

- 如果段落文字较多，可以通过输入 **`<br />`** 标签进行换行，该标签是一种典型的**行内标签**。
- **技巧**：行内标签也被称为"**行内元素**"，其 **display 样式属性值为 inline**。与块状标签相反，行内标签具有**允许其他元素出现在它的左右，并同占一行**的特性。
- 图2-9 演示了换行标签的使用方法。
- **易错点**：在 HTML 段落中，如果使用"**Enter**"键换行，浏览器在渲染时**将仅显示一个空白字符大小**。即使连续按"Enter"键，也**仅显示一个空白字符大小**。
- **`<br>` 还是 `<br />` 的写法之争**：
  - HTML5 之前的一段时间里，人们曾使用 **XHTML**，它要求所有的标签都有闭合标签；单标签需在开始标签部分写上"/"，因此 **`<br />` 符合 XHTML 的语法规范**。
  - HTML5 并没有严格要求这点，**`<br>` 的写法符合 HTML5 的语法规范**。
  - 两种写法**都可以被浏览器正确渲染**；如果是**新开发的基于 HTML5 的项目，建议直接写成 `<br>`**。
  - **特别注意**：与标题标签、段落标签不同，**`<br>` 标签是一个典型的行内标签**。
- **技巧**：在 Dreamweaver 的**设计视图**中，使用快捷键"**Shift+Enter**"可以快速插入一个 `<br>` 标签。
- **良好的编程习惯**：在 HTML5 项目中，**单标签的开始标签部分不需要写上"/"**。

#### 4．强调标签

- **规范建议**：尽管 `<b>` 和 `<i>` 标签**未被废弃**，但在新的规范中**建议使用 `<strong>` 和 `<em>` 标签代替 `<b>` 和 `<i>` 标签**，以具有**更好的语义**。
- **良好的编程习惯**：使用 `<strong>` 和 `<em>` 标签来强调文字。
- **技巧**：

#### 1．链接语法

- 链接的主要功能是实现从一个**源点**到**目标点**的跳转。
  - **源点**：页面中被单击的对象，也就是需要实现跳转的**文字或图片**；
  - **目标点**：链接跳转后到达的**位置或页面**，如页面中的某个特定**锚点位置**，或者**另一个网址**等。
- **链接的示例语法**：

```html
<a href="http://www.nb**.cn">单击跳转</a>
```

- 使用 `<a>` 标签包裹文字"单击跳转"，从而实现源点的制作；目标点需要通过 **`href` 属性**指定（上述示例将跳转到**宁波城市职业技术学院的首页**）。

**表2-4 链接的常用属性**（完整还原）

| 属性 | 描述 |
|---|---|
| `href` | **必设属性**。用于指定目标点，需要保证**路径可达** |
| `target` | 定义目标窗口。指定跳转的页面在哪个目标窗口中打开 |
| `title` | 定义链接提示信息。当**鼠标悬停**时弹出该提示信息 |

- **URL（uniform resource locator）**：把**包含协议和你要访问的资源地址**的部分统称为 URL 地址。
- `href` 属性除了使用资源定位，还可以取 **`#`**、**`JavaScript:…`** 这样的值。
- **哑链接**：如果 `href` 属性值为 **`#`**，相当于设置了一个**空链接**，则**不会发生任何跳转行为**，这种链接被称为"**哑链接**"。

#### 2．定义目标窗口

- 默认情况下，单击链接后**当前的页面会发生跳转**。有时为了某种目的，需要**开启一个新窗口**用于打开目标内容，这时就需要指定 **`target` 属性值**。

**表2-5 target 属性值及其描述**（完整还原）

| 属性值 | 描述 |
|---|---|
| `_blank` | 开启一个**新窗口**，显示目标内容 |
| `_self` | **默认属性值**，在链接所在的**当前窗口**中打开目标内容 |
| `_parent` | 在**上一级窗口**中打开目标内容，一般用在**框架结构**中 |
| `_top` | 在浏览器的**整个窗口**中打开目标内容，**忽略任何框架** |
| 框架名称 | 在**指定的框架窗口**中打开目标内容 |

- **target 属性的应用示例**：

```html
<a href="http://www.nb**.cn" target="_blank">单击跳转</a>
```

**代码2-6 链接和目标窗口（原样摘录）**

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>链接和目标窗口</title>
  </head>
  <body>
        <p><a href="http://www.nb**.cn">默认打开目标窗口</a></p>
        <p><a href="http://www.nb**.cn" target="_blank">_blank 打开目标窗口</a></p>
        <p><a href="http://www.nb**.cn" target="_self">_self 打开目标窗口</a></p>
  </body>
</html>
```

- **易错点**：使用"**_blank**"打开目标窗口后，当前浏览器**无法使用"后退"按钮进行返回**。

#### 3．相对路径和绝对路径

- 链接能否实现正确的跳转，**路径的描述至关重要**。
- 在网页中**所有需要引用资源的地方**（如**图片、字体、音频、视频、文件下载**等），都会用到相对路径和绝对路径。

**（1）相对路径**

- **相对路径**是指基于**某个参照对象**的路径，以这个参照对象的路径所在位置为起点查找目标文件的路径。通常，这个参照对象就是**当前文件**，即**链接所在的文档页面**。
- **链接路径一般可以分成以下 3 类**：
  1. 两个文件**同属一个目录**。
  2. 目标文件在当前文件的**某个下级目录**中。
  3. 目标文件在当前文件的**某个上级目录**中。

**表2-6 常用的路径符号及其描述**（完整还原）

| 路径符号 | 描述 |
|---|---|
| `.` 或 `./` | **当前目录** |
| `..` | **上一级目录** |
| `/` | **进入下一级目录** |
| `../` | **进入上一级目录** |

**示例 1：目标文件在下级目录（教材原场景）**

```
│  2-4-7.html
└─sub
        target.html
```

```html
<a href="./sub/target.html"> </a>
```

> 讲解要点：以当前页面作为参考，使用 `./sub` 在当前目录中找到 sub 文件夹，进而通过"/"找到 sub 文件夹中的 target.html 文档。

**示例 2：两个文档同属一个目录**

```
│  2-4-7.html
│  target.html
```

```html
<a href="./target.html"></a>
<!-- 简化写法：同属一个目录时，可直接将目标文件名作为链接文件名 -->
<a href="target.html"></a>
```

**（2）绝对路径**

- **绝对路径**是指文件的**完整路径**。绝对路径**不需要参照对象**，可以是**从磁盘根目录出发的完整路径**，也可以是**一个网页的完整 URL 地址**。
- 两个重要概念：
  - **磁盘路径**：文件或资源在磁盘中的路径。通过文件资源管理器可以查看 target.html 文档在磁盘中的完整路径（图2-14）：
    `N:\360 安全云盘\03 本周工作\教材教案\网页制作\cn.nbcc.web.book\ch02\sub\target.html`
  - **URL 地址**：也被称为**统一资源定位器**，它是因特网的万维网服务程序中用于指定信息位置的表示方法。

```html
<a href=" https://www.nb**.cn/2022/0505/c121a14741/page.htm">城院校训</a>
```

- 在上述示例中，`https://` 是一个**协议头**，类似的协议头还有 **`files://`、`http://`、`ftp://`、`ed2k://`** 等。
- **URL 地址通常由协议头、磁盘路径、资源名称构成**，它们共同构成了绝对路径。
  - 例：`https://www.nb**.cn/2022/0505/c121a14741/page.htm` 就是一个绝对路径；
  - `https://www.nb**.cn` 通常指定了 **Web 服务器中网站根文件夹的位置**；
  - `2022/0505/c121a14741/page.htm` 是**相对于该网站根文件夹的路径**。
- 通过指定服务器的协议头，加上磁盘路径也可以构成绝对路径：

```
files://N:\360 安全云盘\03 本周工作\教材教案\网页制作\cn.nbcc.web.book\ch02\sub\target.html
```

  - 如果将上述路径设置为链接的目标路径，则**不管从哪个页面的链接进行跳转，最终指向的目标文件都将是 target.html**。

- **推荐使用相对路径（重要结论）**：
  - 使用绝对路径不仅**不便于书写**，而且一旦文件或磁盘位置发生变化，将导致**工作无法正常运行**。
  - 更重要的是，在本地计算机中正常工作的页面**将来要上传到服务器中运行**，而真正部署的**服务器环境跟本地计算机的环境完全不同，甚至操作系统也完全不同**。
  - 因此，要实现网站的**正确部署，应该优先考虑使用相对路径**。只要源文件和目标文件的**相对位置不变**，将它们整体上传到服务器中也同样能够正常工作。
  - **出于安全考虑，很多服务器根本不支持绝对路径的地址访问**。

#### 4．链接的类型（5 种）

| 类型 | 定义 |
|---|---|
| **内部链接** | 同一个网站内部，不同页面之间的链接关系 |
| **外部链接** | 跳转到网站外部，和其他网站元素之间的链接关系 |
| **锚点链接** | 在当前或外部页面的特定位置进行跳转 |
| **脚本链接** | 将脚本作为链接目标，实现 HTML 无法完成的功能 |
| **资源链接** | 实现站点资源、文件的下载 |

**（1）内部链接**

```html
<a href="file_url">文本/图片</a>
```

- 其中 `file_url` 是由**相对路径**表达的内部链接路径，如 `<a href="./sub/target.html">跳转</a>`。

**（2）外部链接**

```html
<a href="URL">文本/图片</a>
```

- 其中 `URL` 表示外部链接文件的路径，该路径通常是**以网址形式表示的绝对路径**。

**表2-7 常用的 URL 协议**（完整还原）

| URL 协议 | 描述 |
|---|---|
| `http://` | 超文本传输协议 |
| `mailto:` | 邮件发送协议 |
| `ftp://` | 文件传输协议 |
| `telnet://` | 远程上机协议 |
| `news://` | 新闻讨论组协议 |

**mailto 协议语法**

```html
<a href="mailto:邮箱地址1?subject=主题&cc=抄送邮箱地址&bcc=暗抄送邮箱地址">文本/图片</a>
```

- **邮箱地址1** 为**收件人邮箱地址**（**必选项**）。
- **`subject`** 用于指定**邮件的主题**；**`cc`** 用于设置**抄送邮箱地址**；**`bcc`** 用于设置**暗抄送邮箱地址**（其余均是可选项）。
- **多个参数之间使用"&"分隔，参数和收件人邮箱地址之间使用"?"分隔**。

```html
<a href="mailto:nb**_support@126.com?subject=help">请求课程帮助</a>
```

- **技巧**：在使用 mailto 协议启用邮件发送程序时，需要在本地计算机中**事先安装并配置好邮件收发软件，如 Outlook**。
- **常见的编程错误**：**"?""&"后面出现空格**是一种常见的编程错误，要确保其后面不能出现空格。

#### （3）锚点链接

- `<a>` 标签不仅可以实现在 `target` 属性指定的窗口中加载目标页面，还可以实现**页面不同位置的跳转**，类似于 **PDF/Word 中的书签功能**。因此，锚点链接通常也被称为"**书签**"链接。
- **图2-15** 演示了锚点链接的**快速回到顶部**功能；**图2-16** 演示了锚点链接的**文档大纲**功能（单击文档大纲中的章节进行快速定位）。
- **实现锚点链接需要进行两个操作**：
  1. **设置锚点**（也被称为**创建书签**）；
  2. **设置链接跳转**。
- **设置锚点**：在 HTML5 中，可以使用**任意标签的 `id` 属性**设置锚点，其 `id` 属性值就是**锚点名称（也称书签名）**。

```html

```

- **`id` 属性**：是 HTML 标签的一个常见属性，该属性可以**唯一标识标签元素**，犹如**身份证可以唯一标识每个人**一样。因此，**在同一个页面中要求 id 属性值必须是唯一的**。利用这个特性进行锚点定位标识，其所对应的位置也是唯一的。

**锚点链接语法**

```html

<a href="#锚点名">源点名</a>

<!-- 外部锚点链接：链接到其他页面的特定锚点位置 -->
<a href="file_url#锚点名">源点名</a>

<!-- 如果要跳转到其他页面的特定锚点位置，必须在"#"前面添加该页面的页面路径 -->

```

## 3.1 CSS 简介

**小节号+标题**：3.1 CSS 简介（含 3.1.1 ～ 3.1.3）
**PDF 页**：61 ～ 63

### 技术要点

- CSS 全称为 **cascading style sheet**，中文译为**层叠样式表**或**串联样式表**。
- 它是一门为**结构化文档**（如 HTML 文档或 XML 文档）**添加样式，实现美化效果**的计算机语言，其**文件扩展名为 `.css`**。
- **核心分工**：如果说 **HTML 定义了网页中要显示哪些内容**，则 **CSS 定义了这些内容如何显示**。
- 正是因为 CSS 允许**内容和样式分离**，所以使用 CSS 大大提高了网页开发的**协同性和代码复用性**，进而提高了工作效率。

### 3.1.1 CSS 的来源

- 早期的网页中**没有 CSS**，完全以文字、链接、图片为主，网页的表现形式并没有得到特别的关注。
- 对于特殊网页效果的显示，常常需要借助一些 HTML 标签或标签属性来实现。
- 随着 Web 技术发展，为解决网页表现形式的问题，**HTML 标签添加了越来越多的显示属性**；同时 W3C 也把许多用于表现样式的标签加入 HTML 规范，如 **`<font>`、`<b>`、`<strong>` 标签**等，甚至 **`<table>` 标签也脱离了原本的用意，常被用于进行网页布局**。
- 人们发现这些大量用于显示设置的属性和标签将**页面的显示与内容混杂在一起，无法阅读**，给开发造成巨大困扰，也给**后期维护**带来困难。
- 为了解决这个问题，**W3C 在 Web 标准中引入了 CSS 规范**。

### 3.1.2 CSS 的发展历程（6 个阶段，教材原序）

| 序号 | 时间 | 事件 |
|---|---|---|
| 1 | 1994 年 | CSS 被提出，并在 **1995 年**获得了浏览器的支持 |
| 2 | 1996 年 12 月 | W3C 发布了 **CSS1.0** 规范 |
| 3 | 1998 年 5 月 | W3C 发布了 **CSS2.0** 规范 |
| 4 | 2004 年 2 月 | W3C 发布了 **CSS2.1** 规范 |
| 5 | 2001 年 5 月 | W3C 开始进行 **CSS3** 标准的制定 |
| 6 | — | **CSS3 的开发朝着模块化发展**，以前的规范在 CSS3 中被分解为一些小的模块，同时 CSS3 中加入了许多新的模块；自 2001 年以来不断有 CSS3 模块的标准发布，但**到目前为止，有关 CSS3 的部分标准还没有最终定稿** |

### 3.1.3 CSS 的优点（4 点）

1. **实现格式和结构分离**：CSS 和 HTML 各司其职，分工合作，分别负责格式和结构。格式和结构的分离有利于**格式的复用及网页的修改与维护**。
2. **精确控制页面布局**：CSS 扩展了 HTML 的功能，能够对网页的**布局、字体、颜色、背景**等图文效果实现更加精确的控制。
3. **可制作体积更小、加载速度更快的网页**：可以在同一个网页中**重用样式信息**；将 CSS 样式信息制作为一个样式文件后，也可以**在不同的网页中重用**。此外还可以**减少表格布局标签、表现标签，以及许多用于设置格式的标签属性**的使用次数，极大地减小网页的体积，从而使网页的加载速度更快。
4. **可实现多个网页同时更新**：使用 CSS 可以使**站点上的多个网页指向同一个 CSS 文件**，从而在更新这个 CSS 文件时，实现对多个网页的同时更新。

## 3.3 基本选择器

**小节号+标题**：3.3 基本选择器（3.3.1 ～ 3.3.8）
**PDF 页**：64 ～ 91

> **基本选择器是指结构单一的选择器**，主要包括：**标签选择器、id 选择器、类选择器、伪类选择器和伪元素选择器**。

### 3.3.1 标签选择器

**PDF 页**：64 ～ 67

- 标签选择器也被称为**元素选择器（element selectors）**。利用 **HTML 固有标签**进行选择，样式将作用于**页面中所有该标签出现的地方**。

```css
h1 {color: purple;}
h2 {color: purple;}
```

- 第 1 行指定**一级标题元素（h1）的颜色为紫色（purple）**；第 2 行指定**二级标题元素（h2）的颜色为紫色**。
- 在 CSS 中，使用 **`color` 属性用于指定文本颜色**；**purple、black、white、red 等都是 CSS 的预设颜色值**。

**语法3-1 color 属性的语法**

```css
/* 定义语法 */
color:预设颜色值 |RGB 值 |十六进制值 | inherit;
/* 示例 */
color:red;
color:rgb(255,0,0);
color:#ff0000;
```

- **易错点/读法**：在 CSS 样式属性的语法中，通常会看到使用"**|**"分隔的形式，它表示**属性值可取其中一种形式**，这里的"|"也可以理解成"**或者**"。

**表3-1 color 属性值**（完整还原）

| 属性值 | 描述 |
|---|---|
| 预设颜色值 | 使用 CSS 预设的颜色的**英文单词**表示颜色，如 red 表示红色，white 表示白色等 |
| RGB 值 | 使用 RGB 的**十进制值**表示颜色，如红色对应 `rgb(255,0,0)` |
| 十六进制值 | 使用"**#**"和一组**十六进制值**表示颜色，如红色对应的十六进制值为 `#ff0000` |
| inherit | **继承父元素的颜色** |

- 虽然写法不同，但它们都表示将文本颜色设置为红色的样式效果。**对于常用的颜色，都可以使用预设颜色值**；但颜色有多种，都使用预设颜色值不现实。因此，**对于个性化的颜色，需要使用十六进制值或 RGB 值进行更精准的描述**。

#### 1．颜色的 RGB 值表示法

```css
rgb(num,num,num);
```

- `rgb()` 的括号内部被**逗号分成 3 个部分**，分别对应 **r、g 和 b**：**r 表示红色，g 表示绿色，b 表示蓝色**；每个部分都使用一个 **0～255 范围内的整数值**来描述。
- 要想确切地**拾取某种颜色的 RGB 值**，可以借助 **Dreamweaver、Photoshop** 等辅助工具。
- **图3-2 Photoshop 的拾色器界面**：用户可通过 ① 和 ② 标识的区域拾取某种颜色；每种颜色都提供了 4 种色彩模式，分别是 ③ **HSB 模式**、④ **Lab 模式**、⑤ **RGB 模式**和 ⑥ **CMYK 模式**。

**表3-2 Photoshop 的 4 种色彩模式**（完整还原）

| 色彩模式 | 描述 |
|---|---|
| **HSB 模式** | 以**人类对颜色的感觉**为基础，描述了颜色的 3 种基本特性。通过**色相、饱和度和亮度**来表示颜色。使用**角度（0°～360°）表示色相**，使用**百分比（0%～100%）来表示饱和度和亮度** |
| **Lab 模式** | 使用一个**明度通道 L** 和**两个色彩通道 a、b** 来表示颜色。Lab 模式产生的色彩是比较明亮的，可以弥补 RGB 模式和 CMYK 模式的不足 |
| **RGB 模式** | 使用**红、绿、蓝 3 种颜色的混合色**来表示颜色，其中 R 表示红色、G 表示绿色、B 表示蓝色，**各值均为 0～255 范围内的整数**。不同的取值将产生不同的颜色，除了红、绿、蓝 3 种颜色为纯色，其他颜色都是由这 3 种颜色通过取不同的颜色值混合而成的。例如，`rgb(255,0,0)` 表示红色，`rgb(0,255,0)` 表示绿色，`rgb(0,0,255)` 表示蓝色，而 `rgb(255,255,255)` 表示白色 |
| **CMYK 模式** | CMYK 也被称为**印刷色**，常用于**彩色打印**。它使用**青色、洋红色、黄色和黑色**来表示颜色。其中 C 表示青色，M 表示洋红色，Y 表示黄色，K 表示黑色 |

- 对于特定的颜色，**Photoshop 拾色器中 R、G、B 通道上的数值可以直接对应 CSS 的 rgb 语法中的数值**。

#### 2．颜色的十六进制值表示法

- 十六进制值表示法其实是 **RGB 值表示法的一种变形**。
- **两位十六进制值恰好能表示 256 种颜色**；分别使用两位十六进制值来表示 r、g 和 b 三种颜色，因此一个完整的颜色值需要 **2×3 共 6 位十六进制值**来表示。
- 为了区别于一般的十六进制值，特别**添加了"#"作为标识符**，因而格式是"**#＋6 位数字或字母**"。
  - **数字的取值范围是 0～9，字母的取值范围是 A～F（分别表示 10～15）**。
  - 例：`#ff0000` 表示红色，`#00ff00` 表示绿色。
- 在图3-2 中，**⑦ 标识的区域显示的是该颜色的十六进制值**；将该值复制后粘贴到代码中，并在该值前面加上"#"就可以表示所选颜色。
- **常见的编程错误**：在书写十六进制值时，**遗漏"#"标识符**是初学者常见的编程错误。

#### 3．颜色的十六进制值简化表示法

- 在完整写法中总共需要 6 位，**每两位对应一个颜色通道**。例：`#ff0000` 两两分组，r 对应 `ff`，g 对应 `00`，b 对应 `00`。
- **简化规则**：**将相同的两位十六进制值使用一位十六进制值简化。**
  - 例：`#ff0000` 可以简化为 `#f00`（f 等价于 ff，中间的 0 等价于 00，最后的 0 等价于 00）。
  - 例：`#ffbbcc` 可简写为 `#fbc`；`#336699` 可简写为 `#369`。
  - **反例**：遇到类似 `#ffbb23` 的值时，这里的 **`23` 就无法使用 1 位来表示，也就不能使用简化表示法**。
- **良好的编程习惯**：尽管 CSS 没有强制要求十六进制值使用大写还是小写（**大小写均可**），但是，**在项目中保持一致的代码风格**是良好的编程习惯。

### 3.3.2 id 选择器

**PDF 页**：67 ～ 69

- **应用场景**：有些时候，需要对网页中**某些唯一的元素**应用特定样式。例如，给**导航区域**应用一个**固定的大小**，给**页面顶部区域**应用一个**特定的背景颜色**等。
- **id 选择器（id selectors）可以针对某个元素进行样式设定**，使用时分成**两个步骤**：
  1. 为该元素**添加一个 `id` 属性**，并赋予其**唯一的值**；
  2. 使用 id 选择器语法**选中该元素**，并设置相应的样式。

**语法3-2 id 选择器语法**

```css
/* 定义语法 */
#id 选择器{
  属性1:属性值1;
  属性2:属性值2;
  …
}
/* 示例 */
#hd1{
  color:blue;
}
```

- **第一步（HTML 部分）**：找到第一个标签的位置并添加一个 id 属性，将其值设置为唯一的 id 名称。

```html

```

**代码3-2 id 选择器（原样摘录）**

```html
    }

        color:blue;
    }

</head>
```

### 3.3.3 类选择器

- **定位对比**：如果说 id 选择器解决了**为某个特定元素**设定样式的问题，那么**类选择器（class selectors）主要用于解决为某些元素设定样式的问题**。
- 这些元素**可以同属于一种标签类型，也可以属于不同的标签类型**。
- 定义、使用类选择器的方法和 id 选择器的非常类似，使用时分成**两个步骤**：
  1. 为该元素添加一个 **`class` 属性**，并赋予其一个值，即**类名**；

```css
/* 定义语法 */

  属性2:属性值2;
  …

```

### 3.3.4 字体属性

**PDF 页**：71 ～ 84

> 导言：3.3.1 节介绍了 `color` 属性，用于控制文本颜色。除此之外，在日常文本处理过程中，经常需要将字体**加粗、变大**。通过使用 CSS 字体属性，可以指定使用的**字体大小、字体族、字体粗细、字体风格**等。

#### 1．font-size 属性控制字体大小

**语法3-4 font-size 属性语法**

```css
/* 定义语法 */
font-size:medium | length |百分比 |inherit;
/* 示例 */
font-size:2em;
font-size:200%;
font-size:14px;
```

**表3-3 font-size 属性值**（完整还原）

| 属性值 | 描述 |
|---|---|
| **medium** | 如果不设置，则为**浏览器的默认字体大小**，通常为 **16px** |
| **length** | 某个**固定值**，常用单位为**像素（px）、em、点（pt）、rem** |
| **百分比** | 基于**父元素或默认值**的百分比（%），是一个**相对值** |
| **inherit** | **继承父元素的字体大小** |

- **为什么需要这么多不同的数值类型**：考虑到 CSS 的**层叠样式特性**，同时为了**兼容不同的浏览器、移动设备的尺寸**，因此需要使用不同的数值类型来表示字体大小。
- 使用最频繁的是 **length**，通常也被称为**固定大小**，其特性是**数值越大，字体就越大**。
- **百分比**也被称为**比例大小**，通常**根据父元素来计算自身的大小**。如果父元素没有设置字体大小，则**基于浏览器的默认字体大小（通常为 16px）来计算**。
- **如果当前元素没有设置字体大小，但它的父元素设置了字体大小**：此时，当前元素的字体大小**自动继承父元素的字体大小**。

**px、pt、em、rem 和 % 的区别（教材原文要点）**

| 单位 | 说明 |
|---|---|
| **px** | 主要用于**计算机屏幕**。一个像素描述的是计算机屏幕上的一个**像素点**。它是一个**固定大小的单元，不具有伸缩性**；在传统网页制作时通常习惯使用单位 px 做到**所见即所得**。但在**显示种类繁多的移动设备**中，使用像素固定大小的方式来定义显得**不太可行** |
| **pt** | 英文 **point** 的缩写，主要用于**印刷媒体**，是 **Photoshop、AI 等设计软件中默认字体大小的单位**。**一个点等于一英寸的 1/72**，因此也是**固定大小的单位，不具有伸缩性**；同样不适用移动设备，**现在网页中已经很少使用** |
| **em** | **相对长度单位**。它是**相对于当前元素的字体大小**；如果当前元素的字体大小未被设置，则字体大小会**相对于浏览器的默认字体大小**。因此它**具有伸缩性** |
| **rem** | 英文全称为 **root em（即根 em）**，是 **CSS3 新增的一个相对单位**，它**总是相对于 HTML 根元素**。相比 em，它更强大，可谓**集相对大小和绝对大小的优点于一身**：既可以做到**只修改根元素就成比例地调整所有字体大小**，又可以**避免字体大小逐层复合的连锁反应**。目前，**除了 IE8 及更早版本的浏览器，所有主流浏览器均支持 rem** |
| **%** | 和 em 一样，**相对于父元素或默认值**。当父元素设置了字体大小时，将基于父元素的字体大小，否则将基于浏览器的默认字体大小（16px）。不管该百分比相对于谁，都有 **100%=1em**。百分比同样**具有伸缩性，也适合移动设备** |

- **em 的换算（教材给出的两组数值）**：
  - 如果某元素**未指定字体大小**，则参考浏览器的默认字体大小（16px），此时 **1em = 12pt = 16px**。
  - 如果将**该元素的字体大小设置为 8px**，则此时 **1em = 8px = 6pt**。
- em 会根据当前文本或父元素的字体大小**自动重新计算值**，因而具有伸缩性，**适合移动设备**，在**响应式页面、移动应用**中越来越受欢迎。

#### 2．font-family 属性控制字体族

**语法3-5 font-family 属性语法**

```css
/* 定义语法 */
font-family:字体族1,字体族2,…,通用字体族|inherit
/* 示例 */
font-family:Tahoma,"Microsoft YaHei","SimSun",Sans-Serif;
```

- 通常，当 `font-family` 属性使用**两个或两个以上的字体族名**时，需要使用**逗号分隔**。
- **为什么要提供这么多字体族列表**：设计师一般会选择一种特定的字体以达到理想效果，但更多情况下，**用户的计算机可能没有安装该字体**，因此需要**一个候选的字体族列表，让浏览器决定最佳的显示效果**。
- **字体族分成通用字体和具体字体两大类**。
- 当浏览器显示文字时，会根据 `font-family` 属性指定的字体族列表，**按照从左到右的优先顺序进行显示**。

**表3-4 6 种通用字体**（完整还原）

| 字体 | 含义 |
|---|---|
| **Serif** | **衬线字体**，衬线是指除字母结构笔画之外的装饰性笔画。Serif 是典型的衬线字体 |
| **Sans-serif** | **非衬线字体** |
| **Monospace** | **等宽字体** |
| **Cursive** | **手写字体** |
| **Fantasy** | **奇幻字体** |
| **System UI** | **系统 UI 字体** |

- 以语法3-5 的示例为例：浏览器会检查系统是否支持 **Tahoma** 字体，如果支持则选择该字体，否则检查第二个字体，以此类推；**通常列表中的最后一个字体选用通用字体**（如这里的 **Sans-serif**），如果前面的具体字体系统都不支持，则使用 Sans-serif 这种通用字体。
- **为什么需要通用字体**：出于**字体版权**考虑，不同的系统安装的字体各不相同。
  - **微软雅黑（Microsoft YaHei）** 是 **Windows 系统**下的一款深受欢迎的中文字体。
  - **苹方（PingFang SC）** 是**苹果公司为中国用户打造**的一款全新中文字体。
  - 通常，设计师会将**最佳的字体作为优先选用的字体**，将**相近的字体作为候选字体**。对于某个系统的浏览器，如果**前面的所有候选字体都未安装，则使用通用字体**。通用字体作为**所有系统安装的基础字体**而存在，**避免客户端没有安装指定字体的问题**。
- **技巧（字体族列表排列原则）**：按照**从左到右的优先顺序**，将**最佳备选字体置于优先顺位**，**候选字体置于候选顺位**，**通用字体作为最后保障**。
- **引号规则（易错点）**：当**字体名称中包含空格**时，如"**Times New Roman**"，就需要使用**双引号**将字体名称引起来作为一个整体。有时候，为了更好的兼容性，**建议对所有的中文字体使用双引号**。例：微软雅黑写成 `"Microsoft YaHei"`，宋体写成 `"SimSun"`。
- **中文字体的英文名称（兼容性）**：一般情况下使用中文名称没什么问题，但有些时候这些由中文命名的**字体会被声明无效**。所以为了更好的兼容性，更多采用这些字体的**英文名称**：
  - **Microsoft YaHei** 表示微软雅黑；
  - **SimSun** 表示宋体；
  - **SimHei** 表示黑体。
  - 由于**某些版本的 Firefox 浏览器和 Opera 浏览器不支持 SimSun**，因此为了保证兼容性，甚至会将**宋体写成 Unicode 编码形式**：

```css
font-family:tahoma,"microsoft yahei","\5b8b\4f53",sans-serif
```

- **中、西文混排的顺序（易错点）**：当遇到中、西文字体需要分别制定的情况时，通常**把西文字体靠前放**。因为**西文字体只包含字母和数字而不包含汉字**。如果将**中文字体的优先级设置较高，则会导致不显示指定的西文字体**。
- **衬线字体 vs 非衬线字体**：
  - **衬线字体**是指那些**有边角装饰**的字体，Serif 是它的典型代表。它非常容易识别，**强调了每个字母笔画的开始和结束**。
  - 这种装饰线的笔画设计多认为源于**古罗马纪念碑上的拉丁字母**：最初在字母被雕刻到石碑上之前，要先用**方头笔刷**写好字母的样子，再照样雕凿；由于直接用方头笔刷书写会导致**笔画的起始处和结尾处出现毛糙**，因此在**笔画开始、结束和转角时增加了收尾的笔画**，自然就形成了衬线（**图3-6 衬线字体**）。
  - 对中文而言同样有衬线字体，**常用的宋体就是一种典型的衬线字体**（**图3-7 中文衬线字体**）。
  - 相应地，**非衬线字体没有边角的装饰**。教材示例：**Google 首页中的文字就是典型的非衬线字体**（**图3-8 非衬线字体**）。

#### 3．font-weight 属性控制字体粗细

**语法3-6 font-weight 属性语法**

```css
/* 定义语法 */
font-weight:normal|bold|bolder|number|lighter|inherit;
/* 示例 */
font-weight:bold;
font-weight:800;
```

- 在默认情况下，字体粗细为 **normal**，其对应的数值是 **400**，也被称为**标准字体**。
- 如果想让字体凸显，可以使用 `font-weight` 属性并指定其属性值为 **bold（粗体）或 bolder（更粗的字体）**。
- 如果想让文字比标准字体细，则可以指定其属性值为 **lighter 或 400 以下的数值**。

**表3-5 font-weight 属性值**（完整还原）

| 属性值 | 描述 |
|---|---|
| normal | **默认值**，标准字体粗细 |
| bold | 粗体 |
| bolder | 更粗的字体 |
| 100 / 200 / 300 / … / 800 / 900 | **由细到粗的数值**，**400 相当于 normal，700 相当于 bold** |
| lighter | 更细的字体 |
| inherit | 继承父元素的字体粗细 |

- **易错点**：在使用数值来控制字体粗细时，**只能整百调整**，即 100、200、300、…、700、800、900。**相近的数值在字体表现上不是很明显**。
- **师生问答**：对于 `<h1>` 标签，默认有加粗效果，是否可以通过 `font-weight:normal` 去除其默认的加粗效果？——**当然可以，这就是 CSS 样式神奇的地方。**

- **italic 和 oblique 非常相近**，在实际使用时，**多使用 italic 表示倾斜**。

#### 5．line-height 属性控制文字行高

- 大段密密麻麻的文字会让人阅读起来枯燥无味，段落文字过于松散也会影响美观。**适当地调整文字行高有助于提升阅读体验**。
- **图3-9 字母在一行中显示**：通常，英文字母的书写以**四线三格**为规范，字母在一行中显示。如果将一行中的文字高度进行垂直划分，则可以分成**顶线、中线、基线、底线**。
- **行高（line-height）通常是指两行文字的基线之间的距离**。这里的**基线是大部分字母"坐落"的一条看不见的线**。
- **默认的行高大约是当前字体大小的 110%～120%**。

**语法3-8 line-height 属性语法**

```css
/* 定义语法 */
line-height:normal|number|length|百分比|inherit
/* 示例 */
line-height:24px;
line-height:200%;
line-height:1.5;
```

**表3-7 line-height 属性值**（完整还原）

| 属性值 | 描述 |
|---|---|
| normal | **默认值**，通常为**当前字体大小的 110%～120%** |
| number | **不带任何单位的数值**，行距为**当前字体大小乘该数值**，效果**类似于 em** |
| length | 以 **px、em、pt** 为单位的**固定值** |
| 百分比 | 相对于**当前字体大小的百分比** |
| inherit | 继承父元素的文字行高 |

- **行高与行距的关系（教材公式）**：
  - **行高**是**两行文字的基线之间的距离**；**行距**是**上一行文字的底线与下一行文字的顶线之间的距离**。
  - 学生结论（教材原话）：**行距 = 行高 − 字体高度**。
  - 教师补充：为了更好地控制行距，保证阅读的舒适性，**通常将行高设置为当前字体大小的 1.4～1.5 倍**。
- **第二种表示法（图3-10）**：如果我们将行距再分成相等的**上间距**和**下间距**，则当每行文字都具有自身的上间距和下间距时，**行高 = 行距 + 字体高度 = 上间距 + 字体高度 + 下间距**。
- **重要应用**：在默认情况下，**上间距和下间距相等，字体高度是垂直居中的**。如果要**实现元素在容器中垂直居中，则只需要将其行高设置为元素容器的高度**（实现原理见图3-11）。
- **常见的编程错误**：**行高是一个非负的正整数，使用负数是一种常见编程错误**。

### 3.3.5 自定义字体

**PDF 页**：85 ～ 87

- 网页中除了可以使用现有的**系统字体**，还可以通过**自定义字体**的方式引用个性化的字体文件，从而实现特定的艺术效果。
- 通常分为**两个步骤**：① **定义自定义字体**；② **引用自定义字体**。

**自定义字体的语法（at 规则 @font-face）**

```css
@font-face{
  font-family:自定义字体的名称;
  src: url('fontfile_url');
}
```

- 在上述语法中，通过 CSS 的 **at 规则（at-rule）`@font-face`** 指定了一个用于显示的自定义字体。
- 字体通过 **`src` 属性加载**，`src` 属性值可以是**相对路径或 URL 地址**，分别从**用户本地或远程服务器**进行字体加载。

```css
@font-face{
  font-family:qigong;
  src: url('assets/qigong.ttf');
}
```

- 上述代码中定义了一个叫 **qigong** 的自定义字体，并从项目的 **assets 文件夹**中加载该字体文件。
- **引用自定义字体**（像普通字体一样通过 CSS 的字体样式属性使用）：

```css
font-family:qigong;
```

- **注意事项**：**自定义字体的名称要符合标识符的定义规则**；在引用自定义字体时，需要**保持引用的字体名称和自定义的字体名称完全一致**。
- **常见的编程错误**：**引用的字体名称与自定义的字体名称不一致**，往往是造成自定义字体不起作用的常见原因。

### 3.3.7 伪元素选择器

**PDF 页**：89 ～ 91

- 与伪类不同，**伪元素不是一个状态类名，而是一个"幽灵"元素**，是一个**逻辑上的存在**，它**在文档树中并不存在**。

**语法3-16 伪元素语法**

```css
/* 定义语法 */
选择器::伪元素{
  属性1:属性值1;
  属性2:属性值2;
}
/* 示例 */
div::before{
  background:#ccc;
}
```

**表3-14 常见的伪元素**（完整还原）

| 伪元素 | 描述 |
|---|---|
| `::first-letter` | 选中文本的**第一个字符** |
| `::first-line` | 选中文本的**第一行** |
| `::before` | 在选择器选择的元素**之前添加内容**，并可以为其添加样式 |
| `::after` | 在选择器选择的元素**之后添加内容**，并可以为其添加样式 |

- **为什么要有伪类和伪元素**：因为 **HTML 其实就是一个文档树**，CSS 引入这两个概念，是因为要**格式化并处理文档树之外的信息**。例如，要处理**一个段落的首字母**以实现下沉的效果；又如，要在**一组列表中选择第一个元素**。
- **伪类与伪元素的主要区别（教学重点）**：
  - **伪类**的典型代表就是链接，它有**不同的状态**，可以使用伪类针对不同的状态设置它的样式，这样链接就会**根据用户的行为变化（如未访问、悬停、访问过等）而动态变化**。这些**状态在普通的文档树中是无法描述的**，因此 CSS 就引入了伪类来实现。
  - **伪元素**则是那些**具有元素性质，又不存在于文档树中的"幽灵"元素**。
- **从"如何实现"的角度区分（教材对话）**：
  - 在没有伪元素的情况下如何实现首字母下沉？学生答：可以使用 `<span>` 标签来包裹这个开始字符，并对它进行样式处理，例如 `<p><span>中</span>国是一个地大物博的国家</p>`。
  - 教师答：**伪元素 `::first-letter` 就是用来代替 `<span>` 标签的**，它同样可以用来实现首字母的下沉效果。可见，**伪元素是一种简化的做法**，其应用示例可以参考**任务3-4**。
  - 学生补充：在列表中如果要对第一个列表元素添加样式，可以添加一个自定义类，如 `<li class="first-one">列表项1</li>`；另外，可以使用 **`:first-child` 伪类**来代替这种做法。
- **良好的编程习惯**：尽管伪类和伪元素前面都使用单冒号，但为了在代码中更好地区别伪类和伪元素，**建议在写伪元素时使用两个单冒号**。例如，写成 **`::before`** 的形式。

### 3.3.8 通用选择器

**PDF 页**：91 ～ 92

- **问题背景**：HTML 标签在浏览器中有**默认的样式**，如 `<p>` 标签有**上、下边距样式**，`<strong>` 标签有**字体加粗样式**，`<em>` 标签有**字体倾斜样式**。
- **不同浏览器的默认样式之间也会有差别**：如 `<ul>` 标签默认带有**缩进样式**，在 **IE 浏览器**中，它的缩进是通过 **`margin`** 实现的；而在 **Firefox 浏览器**中，它的缩进是通过 **`padding`** 实现的。在切换页面时，浏览器的默认样式往往会带来麻烦，影响开发效率。
- **解决方法**：先将浏览器的默认样式全部删除，更准确地说就是通过**重新定义标签样式"覆盖"浏览器的 CSS 默认样式**。简单的做法是利用**通用选择器**将浏览器提供的默认样式覆盖。
- **通用选择器**也被称为"**通配符**"选择器，即使用通配符"**\***"选择**文档中的所有标签元素**。

**语法3-17 通用选择器语法**

```css
/* 定义语法 */
*{
  属性1:属性值1;
  属性2:属性值2;
}
/* 示例 */
*{
  margin:0px;
  padding:0px;
}
```

- **正如上文所说，标签浏览器都有自身默认的显示样式，不同浏览器的默认显示样式会有所不同。为了更好的兼容性，通常需要使用通用选择器实现元素默认样式的重置。**
- **学生类比**：类似于程序中的**初始化**，上述示例的意思就是**将所有标签自带的 margin 和 padding 都初始化为 0px**。教师回应："非常正确，关于 margin、padding 的部分，在**项目5** 中会有进一步的介绍。"
- **技巧**：在实际开发过程中，有时**并不会完全重置 CSS 默认样式**，而会采取一种**可定制的 CSS 方案**。例如，**Normalize.css** 保留了有用的默认样式，并通过标准化样式纠正常见错误和浏览器的不一致性。关于它的具体使用方法，可以参考 **Normalize.css 官网**了解更多内容。

## 备课提示（基于本范围的 6 个高频易错点）

1. **`<header>` 与 `<head>` 混淆**——教材明确列为"常见的编程错误"，是本项目2 的头号考点。
2. **`<br>` 与 `<br />`**——XHTML 与 HTML5 的历史差异，容易在课堂被追问。
3. **align 属性 vs `text-align` 样式**——内容与样式分离原则的最佳教学切入点。
4. **相对路径 vs 绝对路径**——教材给出 4 条理由明确"优先使用相对路径"，含部署与安全视角。
5. **十六进制颜色遗漏"#"、简化写法的前提（两两相同）**——可当堂做 `#ffbb23` 反例练习。
6. **id 选择器与标签选择器顺序交换仍以 id 为准**——样式冲突的引子，为后续优先级（项目4）铺垫。
