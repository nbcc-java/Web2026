6.1

表格的两个作用

表格最初是用来「摆数据」的，中间被借去做布局，如今又回到了原点。

要点分解

表格在网页制作历史进程中的两个作用

教材原文：① 实现网页内容的布局　② 呈现相关的数据

作用一：实现网页内容的布局
通过单元格的分割和合并，生成具有 ①～⑦ 七个不同板块的复杂界面（图6-1）。这是 2008 年以前表格的重要用途。
作用二：呈现相关的数据
以行列形式把数据罗列出来，结构紧凑、清晰直观（图6-2 为汽车详细参数）。目前表格的主要用途已回归到呈现数据。
生活中的表格
财务报表、课程表、问卷调查表……表格的结构化特征，使它成为日常工作中最常见的信息组织方式。
知识要点

表格的发展脉络：从布局回到数据

教材观点：CSS 出现后，使用表格布局网页的方式已逐渐被抛弃

  • 表格初衷是以行列形式将数据罗列出来，结构紧凑、清晰直观，日常生活中被大量使用。
  • 由于表格可灵活合并单元格，2008 年以前表格的一个用途是实现网页内容布局。
  • 随着前端技术发展，CSS 出现后，使用表格布局网页的方式已逐渐被抛弃。
  • 目前表格的主要用途回归到它的初衷——呈现数据。
  • 本项目的学习目标因此聚焦两件事：与表格相关的结构化标签，以及与美化表格相关的 CSS 样式属性。
6.2

表格标签

行、列、单元格，加上三个分区与一个标题——这就是表格的全部骨架。

对照表

表6-1 表格标签（教材完整还原）

一个表格通常包括行、列和单元格 3 个部分，也可划分为页眉、主体、页脚 3 个区域

标签名描述
<table>定义表格
<tr>定义表格行（table row）
<th>定义表格字段的标题（table heading）
<td>定义表格的数据（table data）
<thead>定义表格页眉
<tbody>定义表格主体
<tfoot>定义表格页脚

对比辨析

标题单元格与数据单元格，别混用

教材问答要点：样式上有区别，语义上区别更明显

th · 标题单元格
  • 自带加粗样式，在默认情况下内容是居中的
  • 语义上用来存放标题信息
  • 教材并未规定它的位置：既可以出现在第一行，也可以出现在第一列或其他位置
td · 数据单元格
  • 默认不加粗、居左显示
  • 语义上用来承载数据
  • 与 th 一样，都是 tr 的子元素；整行单元格数量决定列数
知识要点

表格的三个分区与表格标题

thead / tbody / tfoot 不能单独使用，需要配合使用

  • <thead> 是表格的表头分组，<tbody> 是主体内容分组，<tfoot> 是页脚（表注）分组，常用来放汇总数据。
  • 划分意义一：使浏览器有能力支持独立于表格表头和页脚的表格正文滚动。
  • 划分意义二：长表格打印时，表头和页脚可打印在包含表格数据的每个页面上。
  • 划分意义三：可用 CSS 对这些区域分别设置样式，配合项目4 的后代选择器非常好用。
  • <caption> 定义表格标题，默认在表格中居中显示；其 align 属性可取 left、center、right（默认 center），valign 可取 top、bottom（默认 top）。

单元格的 9 种对齐方式

教材问答要点：和 Word 中表格的单元格对齐方式一样，共 3×3 = 9 种

  • 对齐方式分为：左上、中上、右上、左中、中中、右中、左底、中底、右底，共 9 种。
  • 水平方向仍使用 text-align：left、center、right。
  • 垂直方向使用针对表格专门提供的 vertical-align：top、middle、bottom。
  • 两者配合使用便有 3×3 = 9 种；单元格的默认对齐方式是「左中」，即 text-align:left、vertical-align:middle。
  • 技巧：valign 是标签属性、vertical-align 是样式属性，功能相同——写法上一个用缩写、一个用「烤肉串」式全拼，别写混。
TEXT 9 宫格对齐
             text-align:left   center   right
vertical-align:top     左上      中上     右上
vertical-align:middle  左中      中中     右中   ← 默认值在「左中」
vertical-align:bottom  左底      中底     右底

写法：
  tr td, tr th{ text-align:center; vertical-align:middle; }

任务目标使用 Dreamweaver 的 Import → Tabular Data 功能把 Tab 分隔的文本数据直接变成表格，再用 CSS 完成美化（图6-11）。

AI 前沿

AI 前沿：让 AI 帮你「读懂」并重构一张表格

表格是结构化数据，也是大模型最擅长处理的内容形态之一

AI

表格天生就是「键值对 + 行列关系」的结构化数据，大语言模型对它的理解能力远强于对一段散文的理解。把一张乱糟糟的 Excel 或网页表格丢给 DeepSeek、通义千问、文心一言 这类国产大模型，它可以立刻帮你整理字段、补全表头、甚至直接生成语义化的 HTML 表格代码。但请记住：AI 生成的表格未必语义正确——它经常用一堆 div 冒充表格，导致屏幕阅读器读不出数据关系。

  • AI 辅助编码：在 HBuilderX / VSCode 中使用 通义灵码、文心快码、GitHub Copilot，输入「生成 7 行 4 列的金牌榜表格」即可秒出骨架。
  • AI 数据清洗：把 Tab 分隔或 CSV 文本交给大模型，让它批量转成 tr / td 结构，比逐行手敲快得多。
  • AI 无障碍审查：让 AI 检查表格是否缺少 caption、thead、th，这正是容易被忽略的语义规范。
  • 职业提醒：AI 输出的代码需要人工校核语义是否规范、数据是否对齐、无障碍是否达标——这正是本单元要训练的基本功。

本课小结

抓住这五句话，表格就真正属于你了

  • 两个作用：布局（已被 CSS 取代）与呈现数据（已回归初衷）——今天做表格，为的是把数据讲清楚。
  • 结构化标签：table 定整体、tr 定行、th/td 定单元格；caption、thead、tbody、tfoot 让表格更有语义、更好维护。
  • th 默认加粗居中、td 默认不加粗居左；colspan 跨列、rowspan 跨行，是 HTML5 唯二保留的结构属性。
  • CSS 四件套：border-collapse 折叠边框、border-spacing 控间距、caption-side 定标题位置、table-layout 定列宽算法。
  • 单元格对齐共 3×3 = 9 种：text-align 管水平、vertical-align 管垂直，默认值是「左中」。
