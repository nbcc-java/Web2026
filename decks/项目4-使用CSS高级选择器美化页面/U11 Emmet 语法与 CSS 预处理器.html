4.4

使用 Emmet 语法

Emmet 前身叫 Zen Coding，是提高 HTML/CSS 编写速度的便利工具。

知识要点

Emmet 能干什么

使用类似于 CSS 选择器的语法，描述 HTML 文档树结构及属性

  • 前身叫 Zen Coding，是提高 HTML / CSS 编写速度的便利工具。
  • 主流工具均已支持：Dreamweaver、VSCode、Atom、Sublime、Eclipse、IDEA 等。
  • 三个关系符号：> 父子、+ 兄弟、^ 父级（向上爬一层）。
  • 课堂提示：不写标签名时默认生成 div；多个 .class 连写生成多个类；属性省略值时生成空串。
对照表

语法4-8 Emmet 的基本使用语法

id 用 #，class 用 .，属性用 []，文本用 {}

定义语法示例
id 属性 id：#示例1：#header → <div id="header"></div>
示例2：form#search.wide → <form id="search" class="wide"></form>
类属性 class：.示例1：.title → <div class="title"></div>
示例2：p.class1.class2.class3 → <p class="class1 class2 class3"></p>
属性值 attribute：[]示例1：p[title="Hello world"] → <p title="Hello world"></p>
示例2：td[rowspan=2 colspan=3 title] → <td rowspan="2" colspan="3" title=""></td>
文本 text：{}a{click me} → <a href="">click me</a>
子元素 child：>nav>ul>li → <nav><ul><li></li></ul></nav>
兄弟元素 sibling：+div+p+bq → <div></div><p></p><blockquote></blockquote>
父级 Climb-up：^div+div>p>span+em^bq → 第二个 div 内含 p(含 span、em) 与并列出现的 bq
对照表

语法4-9 Emmet 多重性和项目编号语法

* 负责重复，$ 负责编号，两者合用才真正提速

定义语法示例
多重性 multiplication：*ul>li*5 → ul 内生成 5 个 li
项目编号 item numbering：$示例1：ul>li.item$*5 → <li class="item1"> … <li class="item5">
示例2：h$[title=item$]{Header $}*3 → <h1 title="item1">Header 1</h1>、<h2 title="item2">Header 2</h2>、<h3 title="item3">Header 3</h3>
示例3：ul>li.item$$$*5 → <li class="item001"> … <li class="item005">
知识要点

$ 的三条使用要点

教材关键说明 + @ 修饰符

  • $ 可以用在 HTML 标签名、属性值、元素内容中，见示例2 的 h$[title=item$]{Header $}。
  • 多个 $ 表示数值占位：$$ 两位、$$$ 三位，不足补零。
  • 可用 @ 指定开始序号：li.item$@3*5 从 3 开始编号。
  • 用 @- 表示倒序：li.item$@-*5 得到 5、4、3、2、1。
  • 记忆：* 决定「生成几个」，$ 决定「怎么编号」。
效果演示

效果演示｜输入一行缩写，按 Tab 生成一棵 DOM 树

缩写：ul>li.item$*5 —— > 表示父子，* 表示重复，$ 表示自动编号

  • 第 1 步：在编辑器里逐字输入缩写，注意 >、*、$ 三个符号的位置。
  • 第 2 步：按 Tab 键执行缩写（部分编辑器为 Enter 键）。
  • 第 3 步：观察输出——5 个 li 被自动生成，class 依次编号为 item1～item5。
  • 第 4 步：把 $ 换成 $$$ 再看一次，编号变成 item001 形式的三位补零。
动手试试：课后自己试一式：div.wrap>(header>h1{标题})+ul>li*4>a{link$}^footer>p{页脚}

任务目标掌握 @- 倒序与 @n 指定起始序号两种写法

4.5

使用 LESS、SASS 和 SCSS

CSS 可通过预处理技术编译生成样式规则——它们是「写 CSS 的高级语言」。

知识要点

为什么需要 CSS 预处理器

教材类比：CSS 像机器语言，LESS / SASS / SCSS 像高级语言

  • 作为一种样式表高级语言，允许使用变量、嵌套规则、混合（mixins）、函数等高阶语法。
  • 编写完成后，通过命令或图形化工具编译为 CSS 文件，再交给浏览器执行。
  • 适用场景：需要组织大量样式表文件的项目，或需要分享设计的多项目合作。
  • 常见 3 种预编译技术：LESS、SASS 和 SCSS；CSS 预处理器通常分为 LESS 和 SASS 两大类。
对照表

SASS 的两种语法实现

同属 Sass 家族，缩进风格却完全不同

名称特点文件扩展名
Sass（syntactically awesome stylesheets）采用类似 Python 的缩排语法，用缩进表达层次，省略花括号与分号.sass
SCSS（Sassy CSS）Sass 发展到 Sass3 时大量改良形成的独立版本，兼容原语法，采用类似 CSS 的花括号缩进.scss
代码与要点

变量号的差别：LESS 用 @，SCSS 用 $

教材图4-21 的核心结论

  • SASS 利用缩进快速编写具有上下文层次的样式代码。
  • SCSS 使用花括号表示缩进层次，并要求每个样式定义语句以分号结尾，整体风格类似 CSS 规则。
  • 变量定义符号：LESS 使用 @，SCSS 使用 $。
  • 两者都可通过引用变量，并使用 * 进行数学运算。
  • 除数学运算、函数引用外，还可以进行样式的分解和组合。
TEXT LESS 与 SCSS 对照（教材要点）
/* LESS */
@base-width: 100px;
.box{
    width: @base-width * 2;
}

/* SCSS */
$base-width: 100px;
.box{
    width: $base-width * 2;
}

/* 编译后的 CSS 完全一致 */
.box{ width: 200px; }
对比辨析

原生 CSS 还是预处理器？

先把 CSS 写扎实，再谈工具

原生 CSS 更合适的场合
  • 初学阶段：必须先建立「选择器—属性—值」的正确心智模型
  • 小型页面、一次性活动页
  • 要求零构建、直接双击打开的交付场景
  • 现代原生 CSS 已支持自定义属性（CSS 变量），很多需求不必上预处理器
上预处理器的信号
  • 样式表文件数量多、需要按模块组织
  • 同一套配色、间距在多项目间复用
  • 团队多人协作，需要统一的变量与混合约定
  • 已有构建工具链（如 Vite、webpack）可自动编译
AI 前沿

AI 前沿：从「写缩写」到「说人话就出结构」

Emmet 是人类的缩写革命，AI 正在开启下一次

AI

Emmet 的本质是「用一行符号描述 DOM 树」；而今天的大模型可以直接把自然语言翻译成同样的结构——你说「一个三列卡片区」，它就给出 HTML + CSS。工具在变，「先想清楚结构，再写代码」这一条没有变。

  • GitHub Copilot、通义灵码、文心快码可根据注释或上下文生成整段 HTML/CSS，效果类似「自然语言版 Emmet」。
  • DeepSeek、通义千问等国产大模型可直接回答「这段 Emmet 缩写展开成什么」，适合课前自测与课上核对答案。
  • 预处理方向：AI 更擅长把设计稿中的配色、间距抽成变量，生成 LESS/SCSS 的主题文件。
  • 提醒：AI 生成的结构常常嵌套冗余；能读懂 Emmet 的人，才改得动 AI 生成的代码。

本课小结

  • Emmet 前身是 Zen Coding，用类 CSS 选择器的语法描述文档树，主流编辑器均已支持。
  • 基础符号：# id、. class、[] 属性、{} 文本、> 子、+ 兄弟、^ 父级。
  • 提速要点：* 控制重复次数，$ 自动编号，@n 定起始、@- 倒序，() 分组。
  • 常用快捷写法：! 或 html:5 生成 HTML5 框架，link 生成外部样式链接。
  • 预处理器：LESS 用 @ 定义变量、SCSS 用 $ 定义变量；Sass 用缩进、SCSS 用花括号，最终都编译为 CSS。
