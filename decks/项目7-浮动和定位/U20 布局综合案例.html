知识要点

三列布局到底难在哪

既要左右固定、中间自适应，又要让主要内容优先渲染

  • 需求：左列固定 150px、右列固定 200px，中间列宽度自适应（图7-29）。
  • 难点一：三列都要在一行里，靠浮动解决。
  • 难点二：中间列要自适应填满剩余空间，靠 width:100% 加父容器留白解决。
  • 难点三：中间列往往是页面主要内容，HTML 结构上要让它排在最前面以优先渲染——于是不能按顺序 float。
  • 解法：margin 负值把左右两列「拉」回中间列所在的那一行。

任务7-8｜圣杯布局

教材背景：圣杯布局源于一篇文章「In Search of the Holy Grail」，「圣杯」在西方文字中是「渴求之物」的意思

任务目标实现左列固定 150px、右列固定 200px、中间列宽度自适应的三列布局（图7-29）。
  1. 第 1 步：HTML 结构上把 .main 放在最前——优先渲染中间列，它往往是页面主要部分。
  2. 第 2 步：三列全部 float:left，.main 设置 width:100% 自适应填满父容器（图7-30）。
  3. 第 3 步：用 margin 负值把左右两列拉上来：.left{margin-left:-100%;}、.right{margin-left:-202px;}（图7-31）。
    易错点：-202px 的原因是除自身宽度 200px 外，还需加上两侧边线宽度各 1px。
  4. 第 4 步：给 .outer 设置 padding-left:150px; padding-right:200px 腾出位置（图7-32）。
  5. 第 5 步：再用相对定位把左右列推到位：.left{position:relative; left:-150px;}、.right{position:relative; right:-200px;}（图7-33）。
  6. 第 6 步：可将 3 列高度都设为 height:100% 填满满屏，得到更完整的圣杯布局（图7-34）。
html{ height:100%;}
body{ margin:0; /*去除默认外边距*/ height:100%;}
.outer{ margin:0 auto; /*居中*/ height:100%;
        padding-left:150px; padding-right:200px;}
.main{ float:left; width:100%; /*自适应填满父容器的宽度*/
       height:100%; background-color:#FFE4C4;}
.left{ float:left; width:150px; height:100%; background-color:#01FFFF;
       border:1px dashed #518F93; margin-left:-100%;
       position:relative; left:-150px;}
.right{ float:left; width:200px; height:100%; background-color:#01FFFF;
        border:1px dashed #518F93; margin-left:-202px;
        position:relative; right:-200px;}
效果演示

效果演示｜圣杯布局：拖动看中间列如何自适应

左右两列宽度锁死，中间列随容器宽度自动伸缩——这就是「自适应」

  • 外层 .outer 用 padding-left:150px; padding-right:200px 为左右列腾出位置。
  • .main 设置 width:100% 并浮动，自适应填满中间区域。
  • 左右列靠 margin-left 负值被拉到同一行，再用相对定位推到各自的留白里。
  • 下方宽度条循环变化，注意观察：左右两列始终不变，只有中间列在伸缩。
动手试试：把注意力放在中间列：容器变窄时它先收缩，容器变宽时它先撑开——这就是「左右固定、中间自适应」。

任务7-9｜双飞翼布局

教材背景：双飞翼布局源于淘宝的 UED，将左右两列比喻成小鸟的两个翅膀

任务目标实现左 150px、右 200px、中间自适应的三列效果（图7-35），并理解它与圣杯布局的差异。
  1. 背景：双飞翼布局源于淘宝的 UED，灵感来自页面渲染，将左、右两列的固定列宽比喻成小鸟的两个翅膀，是对页面的形象表示。
  2. 通常认为它是圣杯布局的改进版。
  3. 关键差异：在 main 元素上再添加一层 div（.main-wrap）并给它设置 margin 值。
  4. 由于左右两列的 margin 负值都是相对于 main-wrap 元素的，main 元素的 margin 值变化不会影响它们，因此省略了对左右两列设置相对定位的步骤。
  5. 代价：HTML 结构多了一层 .main-wrap 包裹。
html,body{ height:100%; margin:0;}
.main-wrap { float:left; width:100%; background-color:#FFE4C4; height:100%;}
.left      { float:left; width:150px; margin-left:-100%;
             background-color:#01FFFF; height:100%;}
.right     { float:left; width:200px; margin-left:-200px;
             background-color:#01FFFF; height:100%;}
.main      { margin:0 200px 0 150px;}

对比辨析

圣杯 vs 双飞翼：同源不同路

教材对比总结：两种布局原理基本一样，关键在于 margin 负值技巧与元素浮动的相对定位技巧

圣杯布局
  • HTML 结构：.main 在前，.left、.right 紧随，共三层
  • 用父容器的 padding 腾出左右位置：padding-left:150px; padding-right:200px
  • 左右列需再用相对定位推到位：position:relative; left:-150px
  • 右边 margin 负值要算边框：-202px = 200px 宽 + 左右各 1px 边线
双飞翼布局
  • HTML 结构：.main-wrap 内部再包一层 .main，多一层 div
  • 用 .main 自身的 margin 腾位置：margin:0 200px 0 150px
  • 省略相对定位步骤——margin 负值相对于 main-wrap，不受 main 影响
  • 右边 margin 负值直接写 -200px，无需叠加边线宽度

任务7-10｜绝对居中布局

案例图：图7-36 淘宝 App、图7-37 美团 App；假设对话框宽 300px、高 400px

任务目标让元素的中心与父元素的中心重合，模拟弹窗 / 对话框的绝对居中效果。
  1. 关键思路：让元素水平或垂直居中，就要使元素的中心与父元素的中心重合。
  2. 由于父容器尺寸不固定（如不同手机尺寸），不能用相对父容器的具体数值定位，可以考虑使用百分比。
  3. 第一步（代码7-17）：给 .dialog 设置 position:absolute; top:50%; left:50%，并铺一层半透明遮罩 .mask。
  4. 易错点（重点）：此时对话框并没有真正居中（图7-38），原因是对话框是相对于左上角进行偏移定位的（图7-39）。
  5. 第二步（代码7-18）：再补上 margin-top:-200px; margin-left:-150px，即 margin 负值取自身宽高的一半。
  6. 对话框也会受遮罩影响，可通过 z-index:999 调整两者的层叠顺序（图7-41）。
html,body{ margin:0; height:100%;}
.outer{ background-color:#FFE4C4; height:100%;}
div.mask{ position:absolute; left:0; top:0; width:100%; height:100%;
          opacity:0.3; background-color:#000;}      /* 半透明遮罩 */

/* 第一步：绝对定位 + 百分比（尚未真正居中） */
.dialog{ width:300px; height:400px; position:absolute; top:50%; left:50%;}

/* 第二步：margin 负值取自身宽高的一半 + z-index 提层 */
.dialog{ width:300px; height:400px; position:absolute; top:50%; left:50%;
         margin-top:-200px; margin-left:-150px; z-index:999;}
.dialog img{ width:100%;}
知识要点

绝对居中的两个关键点

百分位定「心」，margin 负值回「半」——记住这个组合

  • 为什么用 50%？因为父容器尺寸不固定，无法给出具体像素值；top:50%; left:50% 先把元素左上角送到父容器中心。
  • 为什么还要 margin 负值？因为偏移是相对于左上角进行的，此时元素整体偏向了右下方——需要往回挪自身宽高的一半。
  • 计算公式：margin-top: -(高度/2)、margin-left: -(宽度/2)；本例为 -200px 与 -150px。
  • z-index：对话框需盖在遮罩之上，给它一个足够大的 z-index（如 999）。
  • 举一反三：这个「50% + 负一半」的思路，在项目8 的 Flex 布局与新版的 translate(-50%,-50%) 中都会再次遇到。

知识要点

模块里的两个高频实战技巧

教材模块参数里藏着两个面试常考点：单行省略号与雪碧图

  • 单行文本省略号三件套：white-space:nowrap（不换行）+ overflow:hidden（溢出隐藏）+ text-overflow:ellipsis（省略号）。
  • 三个属性缺一不可，且必须同时给出限定的宽度（本例 width:160px），否则省略号不会出现。
  • 雪碧图（精灵图）定位：用 background-image 引入大图，再用 background-position 的负值坐标把需要的那一个小图标「移」到可视区域。
  • 本例 .ms .icon 的容器尺寸是 20px×33px，坐标是 -35px -25px——容器尺寸必须与图标尺寸一致，否则会露出相邻图标。
  • 呼应项目5 的任务5-9：雪碧图把多张小图合并成一张，减少 HTTP 请求次数，是经典的性能优化手段。

    答案A、C、D说反了：圣杯用父容器 padding 腾位、双飞翼用 .main 的 margin 腾位，故 B 错。

五个案例，五种把浮动与定位组合起来的方式

  • 圣杯布局：main 在前优先渲染 → 三列全浮动 → margin 负值拉回同一行 → 父容器 padding 腾位 → 左右列相对定位推到位。
  • 双飞翼布局：在 main-wrap 内再包一层 main 并给它左右 margin，因此省去了相对定位；它是淘宝 UED 提出的圣杯改进版。
  • 两者同源：精髓都是 margin 负值；差异只在 HTML 结构与「谁来腾位置」——圣杯用父级 padding，双飞翼用 main 的 margin。
  • 绝对居中：top:50%; left:50% 把左上角送到中心，再用 margin 负值取自身宽高的一半拉回；弹窗要盖住遮罩，记得加 z-index。
  • 京东秒杀模块：overflow:hidden 一举两得（触发 BFC + 裁切）、浮动排商品、雪碧图定位取图标、单行省略号三件套截断长标题。
