1.1

Web 前端技术在做什么

搞清「结构、样式、行为」三者的分工，是学习一切前端技术的起点。

要点分解

网页前端的三项核心技术

教材原文：不管 Web 前端技术如何发展，其核心就在于 HTML、CSS、JavaScript 这 3 种技术

HTML5 — 结构
负责页面的内容与语义：标题、段落、图片、链接、表格、表单……回答「页面上有什么」。
CSS3 — 样式
负责页面的表现与排版：颜色、字体、盒子模型、背景、布局、过渡与动画。回答「页面长什么样」。
JavaScript — 行为
负责页面的交互与逻辑：响应点击、校验表单、请求数据。回答「页面能做什么」。本课程聚焦前两项。
知识要点

先学「原生语言」，再学框架

教材观点：框架层出不穷、更新又快，有些昙花一现只流行一时

  • 你可能会听到很多名词：jQuery、AJAX、React、Angular、Vue、Node.js——它们都是围绕三大核心技术的工具与框架。
  • 牢固掌握 HTML / CSS / JavaScript，才能顺利学习 React、Vue、Angular 这类前端框架。
  • 教材比喻：用 PPT 做一页不难，但要做成「艺术品」，还需要配色理论、审美修养与大量实践。网页制作同理。
  • 本课程定位：静态网页设计（HTML5 + CSS3），是 1+X 初级证书的核心能力，也是后续动态交互课程的地基。

什么是全栈工程师（full-stack engineer）

「栈」= 一系列子模块的集合，不是数据结构里的「栈」

  • 定义：掌握多种技能，对前端知识与后端架构都有深入了解，能利用多种技能解决问题、独立完成产品的人。
  • 前端侧需要熟悉：HTML、CSS、JavaScript、H5，以及 Bootstrap、EasyUI 等框架。
  • 后端侧需要熟悉：Java、ASP.NET、PHP、Node.js 或 Go 等。
  • 教材判定标准：既能开发前端又能开发后端，并能独立完成一个简单的电子商务网站。
  • 一句话：全栈工程师就是可以独立开发产品的人——思维方式更开阔、更新颖、更综合。

知识要点

W3C 组织与 W3C 标准

没有标准，就没有「一次编写、处处显示」的 Web

  • W3C = 万维网联盟（World Wide Web Consortium），创建于 1994 年，是国际上最著名的标准化组织之一。
  • 宗旨：解决不同平台、技术和开发者带来的不兼容问题，保障 Web 信息的顺利和完整流通。
  • 标准内容包括：使用语言的规范、开发中使用的导则、解释引擎的行为等。
  • 影响深远的成果：HTML、XML、CSS 等众多标准规范，对互联网技术起到了基础性与根本性的支撑作用。
1.2

认识网页：网页、网站与主页

网页是「一页」，网站是「一整套」，主页是「进门第一眼」。

对比辨析

网页 / 网站 / 主页，别再混用

网页 web page
  • 用户通过浏览器看到的页面
  • 包含文字、图片、链接，有时还有动画、音频、视频
  • 是一个「单个文件」级别的概念
网站 website / 主页 homepage
  • 网站：各种网页及其相关资源的集合，由多个基本网页构成
  • 例如门户网站（腾讯、网易）与小型公司产品网站
  • 主页：输入域名后看到的第一个网页，通常也叫「首页」
  • 因为它是起始页，所以常被用作整个网站的代称
要点分解

网页的五个构成要素

形态千差万别，构成要素大体相同（教材图 1-1）

文字和图片
网页的基本构成要素。早期的网页主要通过文字或图片来表达内容。
链接
分为「文字链接」和「图片链接」。点击即可跳转，让无数网页交错相连，这正是网页的魅力所在。
动画
常见有 Flash 动画、GIF 动画、CSS3 动画和 JS 脚本动画。运动的内容更容易吸引注意。
表单
能在浏览者与服务器之间进行数据「交互」的控件集合体，实现信息搜索、数据提交等功能。
音 / 视频
网页不再局限于播放单调的 MIDI 音乐，已成为能展示视频、直播和游戏的新兴平台。
本课程与之的关系
我们把文字、图片、链接、表格、表单用 HTML 搭好，再用 CSS 美化，动画则交给 CSS3 过渡与动画。
1.3

网站工作原理

你按下 Enter 的那一刻，浏览器与服务器之间发生了什么？

原理图解

一次「请求—响应」的完整旅行

从输入网址到页面呈现，全过程通常只需毫秒级

① 客户端发起请求
用户在浏览器地址栏输入网址并回车，客户端（client）向互联网发出请求（request）。
② 路由转发
请求经互联网上不同设备的路由，被转发到目标 Web 服务器。
③ 服务器处理
Web 服务器是驻留在互联网上的计算机程序，处理请求并返回响应。
④ 浏览器渲染
服务器把网站文件提供给用户浏览，浏览器解析并呈现出可直观查看的页面。
后台技术处理了所有复杂细节；对前台用户而言，只需打开浏览器、输入网址、查看页面。
效果演示

任务 1-1｜用浏览器访问教育部网站

在地址栏输入 www.moe.gov.cn 后回车，注意观察地址栏的变化

  • 推荐使用 Google Chrome 浏览器。
  • 在地址栏输入 www.moe.gov.cn，按 Enter 键。
  • 观察地址栏：浏览器自动补全了 http:// 前缀。
  • 这个前缀就是「协议名」，它告诉浏览器该用哪种方式与服务器通信。
动手试试：把地址换成任意网站，观察协议前缀是 http:// 还是 https://，并记录你看到的差异。
对比辨析

HTTP 与 HTTPS 的区别

初学者最容易混淆的两个协议

HTTP · 超文本传输协议
  • 全名 hypertext transfer protocol
  • 用于分布式、协作式和超媒体信息系统的应用层协议
  • 是一种发布和接收 HTML 页面的方法
  • 默认工作在 TCP 的 80 端口
  • 数据明文传输，可被窃听与篡改
HTTPS · 超文本传输安全协议
  • 全名 hypertext transfer protocol secure
  • 经由 HTTP 通信，但利用 SSL/TLS 加密数据包
  • 主要目的：对网站服务器做身份认证
  • 确保交换数据的私密性与完整性
  • 默认工作在 TCP 的 443 端口

端口就像「出入服务器这间房子的门」，默认端口可以省略不写

代码与要点

任务 1-2｜读懂一个网址（域名）

理解域名要从右往左读：越靠右，级别越高

  • 以 www.moe.gov.cn 为例，从右往左读：.cn → .gov → moe → www。
  • gov.cn 是一级域名：.gov 是政府机构顶级域名，.cn 是中国国家顶级域名。
  • 位于一级域名前的 moe 是二级域名，表示特定机构——这里是教育部（Ministry of Education）。
  • 最前面的 www 与它们共同构成三级域名。
  • 因此输入 moe.gov.cn 与 www.moe.gov.cn 访问结果一样——可以省略 www。
  • 为什么需要域名？IPv4 地址（如 223.252.199.73）难记易变，域名提供了人类可理解的网络地址。
TEXT 域名层级
www . moe . gov . cn
 │      │     │    └── 顶级域名：国家/地区 (.cn 中国)
 │      │     └────── 顶级域名：机构类型 (.gov 政府)
 │      └─────────── 二级域名：具体机构 (moe 教育部)
 └────────────────── 三级域名：主机名 (www)

读法：从右往左，级别由高到低
等价：moe.gov.cn  ==  www.moe.gov.cn
AI 前沿

AI 前沿：当「网页」开始由 AI 生成

教材讲原理，行业在演进——这些变化正在重塑前端岗位

AI

大语言模型（LLM）已经能直接读懂自然语言并生成 HTML / CSS 代码，甚至根据一张设计稿输出可运行的页面。这并不意味着「不用学 HTML 和 CSS」——恰恰相反：只有懂结构与样式，你才能审查、调试并驾驭 AI 的输出。AI 负责「写得快」，你负责「写对、写稳、写安全」。

  • AI 辅助编码：GitHub Copilot、通义灵码、文心快码等，可在编辑器中实时补全 HTML/CSS 代码。
  • 设计稿转代码：多模态模型可根据截图/设计稿生成前端代码，前端工程师转向「评审 + 优化 + 组件化」。
  • 国产大模型：DeepSeek、通义千问、文心一言等，均已具备较强的代码理解与生成能力。
  • 职业提醒：AI 生成的代码需人工校核语义是否规范、无障碍是否达标、安全是否可靠——这正是本课程要训练的基本功。

本课小结

抓住这四句话，整个 Web 前端就有了地图

  • 三大核心：HTML 结构、CSS 样式、JavaScript 行为——先把原生语言学扎实，再谈框架。
  • 标准体系：1+X 职业技能等级标准分初中高三级，本课程对标初级（静态网页设计开发）；W3C 负责制定 Web 技术标准。
  • 概念厘清：网页是一页，网站是集合，主页是访问网站看到的第一页。
  • 工作原理：浏览器发出请求 → 经路由抵达 Web 服务器 → 返回响应 → 浏览器渲染呈现，全过程毫秒级完成。
