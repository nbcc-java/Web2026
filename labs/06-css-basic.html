em 认父元素字号，rem 只认 html 根字号，% 认父容器宽度（左边那个虚线框），vw 认视口宽度（右边那个小窗口）。四条各自只认一个参照物，所以永远只有一条跟着动。

权重怎么算：把选择器变成 (a, b, c)

a = ID 数量，b = 类 / 属性 / 伪类数量，c = 元素标签 / 伪元素数量。三项从左到右逐位比较，不进位：11 个类也压不过 1 个 ID。

#hero .desc → (1,1,0)；.card2 p → (0,1,2)；p → (0,0,1)。

权重相同时，后写的赢（后来居上）。行内 style 直接算 (1,0,0,0)，比任何选择器都高；!important 凌驾一切。

写 CSS 的习惯 尽量用低权重选择器（类），别为了"保证生效"堆 ID —— 权重越平，后面越好改。

颜色与单位的实战建议

#3B82F6十六进制，最常用，可省略重复位写成 #38f
rgb(59 130 246)十进制，配合透明度用 rgb(59 130 246 / .5)
hsl(217 91% 60%)色相/饱和度/亮度，调深浅最直观
px固定像素，边框、圆角常用
rem相对根字号，做间距与整体缩放的首选
em相对父字号，会「层层放大」，慎用于深层嵌套
% / vw相对父容器 / 视口，做流式布局

还在用 font-size: 12px 写正文？浏览器设置里用户调大字号时它不会跟着变 —— 这就是无障碍问题。
