4.2

应用样式的常用方式

共有 3 种方式可以将 CSS 应用到 HTML 中，相应的样式表分别称为行内式、内嵌式和外部样式表。

要点分解

三种样式表，一眼看清差别

教材原文：行内式（也称内联式，inline）、内嵌式（embeded）、链接式（external）

行内式 inline
样式语句以 style 属性值的形式写在标签内部，不需要选择器，仅对该标签起作用。
内嵌式 embeded
把样式代码放进 <head> 里的 <style> 标签，实现同一个页面内的样式复用，也叫内部样式表。
链接式 external
用 <link> 引入独立的 .css 文件，实现多个页面复用同一套样式，保证整站风格统一。
代码与要点

4.2.1 行内式

没有选择器，样式规则只对这一个标签生效

  • 语法：<标签名 style="属性1:属性值1;属性2:属性值2;">。
  • 教材示例：只有「费俊龙」带了 font:italic 18px 与 color:#f6f，其余段落保持默认。
  • 优点：直观、优先级最高，调试时偶尔用来临时验证。
  • 缺点：样式与结构混写，无法复用，改一处要改多处，工程项目中应避免。
HTML 代码4-7 关键片段
<h2>中国航天员</h2>
<p>杨利伟</p>
<p style="font:italic 18px ;color :#f6f">费俊龙</p>
<p>聂海胜</p>
代码与要点

4.2.2 内嵌式（内部样式表）

常见编程错误：样式没写进 style 标签、或 style 标签没放进 head 里

  • 把「费俊龙」的样式抽象成 .highlight 类，三个段落共用一份声明——这就是复用。
  • 位置要求：样式代码必须嵌入 <style> 标签，且 <style> 标签置于 <head> 标签内部。
  • 技巧：type="text/css" 用于定义文件类型为样式文件；在 HTML5 中该属性可以省略，简写为 <style>…</style>。
  • 局限：只对当前这一个页面有效，第二个页面要用，只能复制粘贴。
HTML 代码4-8 关键片段
<head>
<style>
.highlight{             /* #007-#010 */
    font:italic 18px ;
    color :#f6f;
}
</style>
</head>
<body>
<h2>中国航天员</h2>
<p class="highlight">杨利伟</p>
<p class="highlight">费俊龙</p>
<p class="highlight">聂海胜</p>
</body>
任务驱动

任务4-1｜将内嵌式改为链接式

目标：把 4.2.2 节的内嵌式改造成外部样式表

任务目标抽出独立的 style.css 并用 link 标签引入，效果与图4-10 保持一致
  1. 新建名为 css 的目录，便于管理站点中的样式表文件。
  2. 在 css 目录中创建样式表文件 style.css，把样式代码抽取进去。
  3. 用链接语法把样式表引入 HTML：<link rel="stylesheet" href="css/style.css">。
  4. 技巧：省略 type 属性是常用简化做法——rel 为 stylesheet 时，浏览器会推测 type 为 text/css。
  5. 路径要点：当前文件到 style.css 的相对路径是 css/style.css。
  6. 良好的编程习惯：整站项目优先使用外部样式表——提高复用率、提升可维护性，且文件可被浏览器缓存。
<head>
    <meta charset="utf-8">
    <title>链接式</title>
    <link rel="stylesheet" href="css/style.css">   <!-- #006 -->;
</head>
<body>
    <h2>中国航天员</h2>
    <p class="highlight">杨利伟</p>
    <p class="highlight">费俊龙</p>
    <p class="highlight">聂海胜</p>
</body>
效果演示

效果演示｜同一段文字，三种引入方式的叠加结果

左侧三种来源同时作用于「费俊龙」，右侧是优先级阶梯——谁高谁说话

  • 三个来源同时对同一个 <p> 声明了不同的 color 值，冲突就此产生。
  • 裁决顺序：行内式 > 内嵌式 ≈ 链接式，后者之间再看书写顺序。
  • 右侧阶梯是教材表4-2 的权重模型：style="" 为千位级，直接 1000。
  • 别忘了最后一条：!important 甚至可以高过行内式，请慎用。
动手试试：把演示里的 !important 开关打开，看看最终颜色会不会再次翻转。
4.3

解决 CSS 冲突的问题

CSS 根据①优先级原则、②就近原则、③覆盖原则、④!important 原则解决 CSS 冲突的问题。

代码示例

冲突示例：代码4-10

四条规则同时命中「杨利伟」这一段，浏览器到底听谁的？

HTML 代码4-10 关键片段
<style>
p{color:red;}               /* #007 */
.highlight{color:yellow;}   /* #008 */
#p1{color: blue;}           /* #009 */
p#p1{color:green;}          /* #010 */
</style>

<h2>中国航天员</h2>
<p id="p1" class="highlight">杨利伟</p>
<p class="highlight">费俊龙</p>
<p class="highlight">聂海胜</p>

知识要点

1. 优先级原则：三条结论

样式类型权重 + 选择器优先级，两条线索一起看

  • 冲突发生时，以优先级高的样式作为最终显示效果。
  • 样式类型权重：行内式（A）＞ 内嵌式 / 链接式。
  • 选择器优先级：id 选择器 ＞ 类/伪类/属性选择器 ＞ 标签/伪元素选择器 ＞ 通用/子元素/相邻兄弟选择器。
  • 注：教材把子元素选择器、相邻兄弟选择器并入最低一级；实际比较时，组合器本身不计权重，只看两侧选择器的 id、class、标签数。
  • 快速验算：p .color div #news 含 1 个 id、1 个类、2 个标签 → 112；* 的三类计数均为 0 → 0。
代码与要点

2. 就近原则：越靠近内容，优先级越高

就近原则主要是针对继承关系的

  • 示例里 ul、li、a 三个选择器优先级完全相同（都是单个标签，权重 1）。
  • li 是 ul 的子元素，a 又是 li 的子元素，层层继承。
  • 此时靠就近原则裁决：a 距离显示内容最近，覆盖父元素的 color。
  • 最终三个名字显示蓝色。
HTML 代码4-11 关键片段
<style>
a{color:blue;}      /* #007 */
ul{color:green;}    /* #008 */
li{color:yellow;}   /* #009 */
</style>

<ul>
    <li><a href="#">杨利伟</a></li>
    <li><a href="#">费俊龙</a></li>
    <li><a href="#">聂海胜</a></li>
</ul>
代码与要点

3. 覆盖原则：后来者居上

优先级相同、继承层级也相同时，后面定义的样式覆盖前面的

  • 在代码4-11 基础上新增一行 a{color: red;}。
  • 它与第 007 行的 a{color:blue;} 优先级相同，都是 1。
  • 按覆盖原则：后者覆盖前者，最终显示红色。
  • 这条原则也是「CSS 层叠（Cascade）」一词的由来——同权重比先后。
CSS 代码4-12 关键片段
a{color:blue;}      /* #007 */
ul{color:green;}    /* #008 */
li{color:yellow;}   /* #009 */
a{color: red;}      /* #010 新增：与 007 同权重，后者胜 */
代码与要点

4. !important 原则：压过一切的最高优先级

语法：样式规则 !important;

  • 添加 !important 后，该声明的优先级被设为最高级，甚至高过行内式。
  • 教材示例：a{color:blue !important;}，即使 <a> 上写了 style="color:yellow;"，最终仍显示蓝色。
  • 工程建议：!important 会打断正常的层叠推理，让后续维护者难以预判结果，非必要不使用。
  • 替代思路：提高选择器精度、调整书写顺序，或改用 MDN 推荐的级联层 @layer 管理优先级。
HTML 代码4-13 关键片段
<style>
a{color:blue !important;}   /* #007 */
ul{color:green;}            /* #008 */
li{color:yellow;}           /* #009 */
a{color: red;}              /* #010 */
</style>

<li><a href="#" style="color:yellow;">杨利伟</a></li>   <!-- #016 行内式也无效 -->;
原理图解

四条原则的判定顺序

遇到「样式写了却不生效」，按这个顺序排查

① 先看有没有 !important
带 !important 的声明优先级最高，直接胜出（尽量改写，别依赖它）。
② 再看样式来源
行内式（1000）高于内嵌式与链接式；作者样式高于浏览器默认样式。
③ 再算选择器权重
按 A/B/C/D 四级统计 id、class、标签数目，组合值大者胜。
④ 最后看书写顺序
权重相同、继承层级也相同时，后定义的覆盖先定义的（覆盖原则）。
就近原则用于「继承链」上的仲裁：同一条继承链上，离内容越近的选择器越优先。
AI 前沿

AI 前沿：让 AI 帮你算出「为什么它不生效」

层叠与优先级，是最适合交给 AI 排查的一类问题

AI

「样式写了却不生效」是初学者最高频的问题，而这个错误的成因是可以被机器枚举的：选择器没命中、权重被压过、被后面的规则覆盖、被 !important 打断、属性名拼错……AI 工具能沿着这套清单逐条排查，几秒钟给出定位。

  • 排错用法：把 HTML 与 CSS 一起贴给 DeepSeek、通义千问、文心一言，直接问「这条规则为什么不生效」。
  • 规范用法：GitHub Copilot、通义灵码会在补全时优先生成低权重、易覆盖的类选择器，避免 !important 滥用。
  • 进阶方向：现代 CSS 提供级联层 @layer，可为 reset、组件、工具类分层管理优先级，比互相加权重更可控。
  • 提醒：AI 给出的修改往往「能用但不一定优雅」——你要能判断它是在提权重，还是在真正解决问题。

本课小结

  • 三种引入方式：行内式写在 style 属性、内嵌式写在 head 的 style 标签、链接式用 link 引入外部 css。
  • 整站项目优先使用外部样式表：复用率高、可维护性高、还能被浏览器缓存。
  • 优先级原则：行内式 1000 ＞ id 100 ＞ class/伪类/属性 10 ＞ 标签/伪元素 1 ＞ 通用 0。
  • 就近仲裁继承链，覆盖仲裁同权重先后，!important 兜底但慎用。
  • 排查口诀：先看 !important → 再看来源 → 再算权重 → 最后看顺序。
