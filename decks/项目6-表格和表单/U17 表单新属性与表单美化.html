6.5.5

表单新属性

HTML5 把过去要靠脚本才能做的事，收进了标签属性里。

要点分解

HTML5 表单五大新属性速览

教材原文：这些新属性提供了数据验证、非空校验、自动聚焦和信息提示等功能

form
为所有表单标签定义与某个表单之间的从属关系，让控件可以写在 form 之外，布局更灵活。
formaction
一个表单里有两个以上提交按钮时，用它为每个按钮指定不同的后台处理程序，取代过去用脚本动态修改 action 的做法。
required
实现非空校验，取代「判断内容是否为空 / 字符长度是否为零」的实现脚本，简化页面开发步骤。
autofocus
页面加载完成后让该标签自动获得焦点。属性值是一个布尔值，默认 false；一个页面中最多只能对一个标签设置。
pattern
input 的验证属性，属性值是一个正则表达式，用于验证输入内容的有效性；配合 title 给出错误提示。
代码与要点

form 属性：让控件跳出 form 的「围墙」

教材原文：HTML5 之前，一个表单的标签必须放在 form 标签内

  • HTML5 为所有表单标签添加了 form 属性，用于定义表单标签和某个表单之间的从属关系。
  • 它允许把 input 放在 form 标签之外，但需通过 form 属性指定它所属的表单。
  • form 属性的值对应表单标签的 id 属性值——不是 name，别搞混。
  • 意义：可以更灵活地实现表单的布局，比如把提交按钮放在页面任意角落，而数据仍随该表单提交。
HTML form 属性示例（教材原文）
<form id="login_form">
…
</form>
<input type="text" form="login_form">

formaction 属性：一个表单，多个去向

教材场景：学工系统的学生管理模块，一个表单里包含新增、修改、删除三个按钮

HTML 代码6-11（教材原文）
<form action="">
    <p>姓名:张三</p>
    <p>学号:031102</p>
    <p>
        <input type="submit" value="新增" formaction="add.do">
        <input type="submit" value="修改" formaction="update.do">
        <input type="submit" value="删除" formaction="delete.do">
    </p>
</form>
适用标签：input type='submit'、input type='image'、button type='submit'。HTML5 之前只能通过 JavaScript 动态修改 form 的 action 属性，现在只需在每个提交按钮上写 formaction。

required 属性：一句代码实现非空校验

适用标签：input、textarea、select 等表单中需要提交内容的标签

HTML 代码6-12（教材原文）
<form action="">
    <p>姓名:<input type="text" id="name" required /></p>
    <p>学号:<input type="text" name="id" id="id" required /></p>
    <p><input type="submit" value="确定提交">
    </p>
</form>
两种写法等价：required 与 required='true'。它的作用是取代「判断内容是否为空、字符长度是否为零」的实现脚本，从而简化页面开发步骤。

autofocus 与 pattern：会聚焦，也会挑错

autofocus 自动获得焦点；pattern 用正则表达式验证输入内容的有效性

  • HTML5 表单的 textarea 和所有 input 标签都具有 autofocus 属性，属性值是一个布尔值，默认值是 false。
  • 一旦设置，页面加载完成后该标签将自动获得焦点。
  • 注意：在一个页面中，最多只能对一个表单标签设置该属性，否则该功能将失效；教材建议对第一个 input 标签设置。
  • pattern 的属性值是一个正则表达式；配合 title 属性，可在用户输入不符合规则时显示 title 的内容作为错误提示。
HTML 代码6-13（教材原文）
<form action="">
    学号: <input type="text" name="id" id="id" required pattern="\d{8}"
        title="请输入8 位学号"/>
    用户名:<input type="text" name="username" id="username" required
        pattern="^[a-zA-Z]\w{2,7}" title="请输入用户名，必须以字母开始，字母与数字的组合，长度为3~8 位"/>
    <button type="submit">提交</button>
</form>
代码与要点

读得懂的正则表达式

教材讲解要点：把 \d{8} 与 ^[a-zA-Z]\w{2,7} 拆开看

  • 正则表达式是一种高效的、用于匹配字符串中字符组合的模式，广泛用于 Word、Excel 以及 JavaScript、Python 等程序语言中。
  • 8 位学号 \d{8}：\d 表示所有数字符号，{8} 表示多重性，即出现 8 次数字符号——只有输入 8 位数字才符合要求。
  • 用户名 ^[a-zA-Z]\w{2,7}：^[a-zA-Z] 表示以大写或小写字母开始。
  • \w 表示字母和数字的组合；{2,7} 表示最少 2 个、最多 7 个。
  • 合起来：用户名最少 3 位、最多 8 位，且必须是以字母开始的字母与数字的组合。
  • 教材问答：title 属性是用来显示错误提示的吧？——没错，当用户输入不符合正则表达式时，将显示 title 属性值。
TEXT 正则拆解
学号   \d{8}
         │   └── {8}  出现 8 次
         └────── \d   任意数字

用户名 ^[a-zA-Z]\w{2,7}
        │  │       │   └── {2,7} 最少 2 个、最多 7 个
        │  │       └────── \w    字母与数字的组合
        │  └────────────── [a-zA-Z] 大写或小写字母
        └───────────────── ^  以……开始

合计长度：1 + (2~7) = 3~8 位

先重置、再定制——这是所有 UI 组件美化的通用套路。

知识要点

为什么要重置表单默认样式

教材原文：不同浏览器渲染默认表单标签的效果是不一样的

  • 在默认情况下，表单标签都具有一些自带样式；使用不同的浏览器调试可以发现，它们渲染默认表单标签的效果也是不一样的。
  • 这些默认样式的差异会导致显示效果不一致，严重时还会对网页布局造成影响，从而影响用户的浏览体验。
  • 通常的做法是：先重置表单标签的默认样式，确保各浏览器起点一致，然后再添加自定义样式。
  • 如何查看默认样式：利用浏览器自带的开发者工具找到要查看的表单标签，即可查看对应的样式及盒子模型信息（呼应项目5 的任务5-1）。
  • outline 小知识：它是描述控件范围的一圈轮廓线，通常位于元素的边缘；按 Tab 键切换表单控件时，当前控件会被一圈轮廓线围绕。
  • outline 与 border 的区别：① outline 在 border 的外围，不会占据元素空间，也不会影响布局；② border 应用于几乎所有 HTML 元素，而 outline 仅针对链接、表单控件等少量元素；③ outline 随焦点 focus 自动出现、失去焦点 blur 自动消失。

任务6-4｜个性化表单控件美化

目标：使用表单控件美化和重置语法，配合素材实现图6-37 的表单控件美化效果

任务目标学会了表单控件的重置，再添加一些自定义样式，就可以个性化地设计出表单元素。
  1. 先重置：用属性选择器 input[type=text] 清掉边框、内填充与 outline。
  2. 再定制文本框：重新给出 width、height、border、border-radius、padding-left。
  3. 把单选/复选框隐藏（display:none），改用后面 span 包裹的文字来显示可点击的样式。
  4. 用 :checked 伪类配合相邻兄弟选择器 +改变选中态：.frm_radio:checked+span。
  5. 复选框用背景图片：.frm_chkbox+span 与 .frm_chkbox:checked+span 分别指定未选中与选中的图标，并用 background-size 控制大小。
  6. 上传文件控件：用 a 标签包裹 input[type=file]，再用绝对定位 + opacity:0把原生控件覆盖在超链接之上。
.frm_txt{
    width: 150px;  height: 30px;
    outline: none;  border: 1px solid #ccc;
    padding-left: 8px;  border-radius: 5px;  margin-left: 6px;}
.frm_radio, .frm_chkbox{ display: none;}
.frm_radio+span, .frm_chkbox+span {
    width: 50px;  height: 30px;
    display: inline-block;
    background-color: #ccc;
    border-radius: 5px;
    font: 16px/30px ";微软雅黑";;
    text-align: center;}
.frm_radio:checked+span{ color:#fff; background-color: darkblue;}
.frm_chkbox+span{ background: url(";image/unchecked.png";) no-repeat;
    background-size: 30px 30px; padding-left: 35px;}
.frm_chkbox:checked+span{ background: url(";image/checked.png";) no-repeat;
    background-size: 30px 30px;}
.file{ position: relative; display: inline-block;}
.frm_file{ position: absolute; right:0; top:0;
    opacity: 0; width: 100%; height: 100%;}

效果演示｜会发光、会渐变的登录表单

把重置、定制、:checked、:focus、transition 串成一条完整的美化流水线

  • 先看聚焦发光：用 input:focus 配合 box-shadow 与 transition，让光标所在处「亮起来」。
  • 再看按钮渐变过渡：linear-gradient 打底，transition 让背景与阴影的变化平滑发生。
  • 自定义单选/复选：原生控件 display:none，用 :checked+span 切换选中态样式。
  • 这些效果全部建立在「先重置默认样式，再添加自定义样式」的基础上。
动手试试：把鼠标点进用户名输入框再点出来，观察 outline 被 box-shadow 取代后的差别——这就是「重置 + 定制」的价值。

AI 前沿：让 AI 写出「既聪明又好看」的表单

校验规则与美化样式，是大模型最擅长的两类确定性输出

AI

表单美化与校验规则属于「模式清晰、规则明确」的任务，恰好落在 DeepSeek、通义千问、文心一言 等国产大模型的能力甜区。你可以直接描述需求：「做一个聚焦时发光、按钮渐变过渡的登录表单」，几秒钟就能拿到可用的 HTML 与 CSS。但 AI 常犯的错也很典型：忘记重置默认样式、把 outline 一删了之而不给替代的焦点提示——后者会直接损害键盘用户与视障用户的可用性。

  • AI 生成校验规则：让 AI 为手机号、身份证号、学号生成 pattern 正则表达式，并同时给出友好的 title 提示文案。

  • AI 一致性检查：让 AI 审查不同浏览器下的默认样式差异，并生成对应的重置代码。
  • 职业提醒：删除 outline 而不给替代方案，是无障碍设计的红线。AI 不会主动提醒你这一点，但专业课必须讲、工程师必须守。

    答案C教材原文：outline 在 border 的外围，不会占据元素空间，也不会影响布局；它随焦点 focus 出现、blur 消失。

    答案B这是项目4 4.1.6 节讲过的属性选择器，教材表6-10 中正是用它来选择复杂多变的 input 标签。
  5. 05 多选关于 HTML5 表单新属性与表单美化，下列说法正确的有（　　）。
    答案A、B、D一个页面最多只能对一个标签设置 autofocus；outline 随 focus 出现、blur 消失，且不占空间。

本课小结

五句话，串起「变聪明」与「变好看」两条线

  • HTML5 五大新属性：form 定从属、formaction 定去向、required 做非空、autofocus 自动聚焦、pattern 正则校验——它们共同替代了早期的实现脚本。
  • pattern 的属性值是正则表达式：\d{8} 表示 8 位数字，^[a-zA-Z]\w{2,7} 表示以字母开头、共 3～8 位的字母数字组合；title 负责显示错误提示。
  • 美化的第一步是重置：不同浏览器对表单标签的默认渲染不同，统一起点才能保证布局与观感一致。
  • outline 是位于 border 外围的轮廓线，不占空间、不影响布局；它随 focus 出现、blur 消失，删除它必须给出替代的焦点提示。
  • 个性化控件的通用套路：隐藏原生控件 + :checked 伪类 + 相邻兄弟选择器 + 定制 span；上传文件则用 a 包裹 + 绝对定位 + opacity:0。
