# 课件总览 · 《网页制作（HTML5+CSS3）》26 个教学单元

每个教学单元（40 分钟）都有两个版本：

| 版本 | 用途 | 特点 |
|---|---|---|
| **HTML 版** | 课堂授课（大屏投影） | 动画特效、可交互的**实时效果演示**（iframe 内嵌真实渲染页面）、键盘翻页、目录导航、可一键打印导出 PDF |
| **PPTX 版** | 平台上传 / 学生复习 | 与 HTML 版同源同配色，演示页内嵌真实渲染截图，检测页答案与解析写入演讲者备注 |

## 课堂导航（2026-11-09 新增）

- **总目录页 `课件/index.html`**：26 个单元按 10 个项目分组展示，含搜索（快捷键 `/`）、项目筛选、「继续上次」（自动记住上次打开的课件并高亮）。上课时直接打开这一页即可导航。
- **结束页「下一讲」**：每个 HTML 课件最后一页新增「下一讲」按钮（直达下一单元课件）与「← 返回总目录」链接；最后一讲显示课程结束祝语。跨项目跳转链接已全部校验有效。

## HTML 版课堂操作

| 操作 | 方式 |
|---|---|
| 下一页 / 上一页 | `→` `↓` `空格` / `←` `↑`；也可点击屏幕右半 / 左半 |
| **点击翻页开关** | 右下角「点击翻页 开/关」按钮或快捷键 `C`；关闭后点击鼠标不翻页（键盘、触摸滑动仍可翻），状态自动记忆，对全部 26 个课件生效 |
| 圈选页面文字 | 直接拖动鼠标圈选，页面保持静止不翻页；圈选完成后可继续翻页 |
| 打开目录跳转 | `O` 或右下角「目录」按钮 |
| 全屏放映 | `F` 或右下角「全屏」按钮 |
| 打印 / 导出 PDF | `P`（自动切换为逐页排版，每页一张幻灯片） |
| 直达某页 | 地址栏加 `#页码`，如 `U01 ….html#16` |
| 手机 / 平板观看 | 竖握时自动变为纵向流式阅读，上下滑动即可；横握恢复放映模式 |
| 随堂检测作答 | 学生点选选项后点「查看答案」判分；看错答案想改，直接再点选项即自动收起答案重新作答 |
| **检测重做** | 每题「重做」按钮清空该题作答；顶部「全部重做」一键重置整页；「显示全部答案」可再点一次隐藏 |

## 二次修改（可选）

课件由 `生成器/` 目录下的脚本生成，内容与样式分离：

- 改内容：编辑 `生成器/content/UXX.json` → 运行 `build.py` 重新生成
- 改配色/字体/版式：编辑 `生成器/deck_core.py` 顶部的 `THEME` 与 CSS
- 重新生成全部：`python 生成器/build.py`；只生成某几个：`python 生成器/build.py U03 U04`

这样所有 26 个单元的风格可以一键统一调整。
