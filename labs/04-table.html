表格的层级：table → thead/tbody → tr → th/td

    
table 是容器，thead / tbody / tfoot 分三段（可选但推荐），tr 是一行，th 是表头单元格（加粗居中），td 是数据单元格。

    
caption 写表格标题，是表格的无障碍名称，必须紧跟 <table>。

    
scope="col" / "row" 告诉屏读器这个表头管的是整列还是整行 —— 合并单元格时尤其重要。

    
表格不是布局工具 2005 年之前用 table 排版，现在一律用 CSS 布局（项目 8）。表格只用来表达"行列对应的二维数据"。

  


  

    
合并：span 的四个坑

    

      
规则说明

      
colspan横向占几列，被占的格子要从代码里删掉，不是留空

      
rowspan纵向占几行，下面几行的对应 td 都要删

      
删除 ≠ 留空多写一个空 td，整行就会多出一格，右边全部错位

      
合并方向交叉合并（同时 colspan + rowspan）时，四个角只留左上角那个 td

    

    
左右拖动试试：先把 2×2 合并，再在旁边合并一格，看代码里 td 数量的变化。
