3.1

CSS 简介

一门只做一件事的语言：告诉浏览器，这些内容究竟该怎么显示。

要点分解

认识 CSS：它是什么，又为什么会出现

教材 3.1：CSS 全称 cascading style sheet，中文译为层叠样式表

CSS 是什么
一门为结构化文档（如 HTML 或 XML 文档）添加样式、实现美化效果的计算机语言，文件扩展名为 .css。
核心分工
HTML 定义了网页中要显示哪些内容，CSS 定义了这些内容如何显示。内容与样式分离，大大提高了开发的协同性和代码复用性。
为什么要有 CSS
早期靠 <font>、<b> 等标签和显示属性做表现，甚至用 <table> 布局，导致显示与内容混杂、无法阅读、难以维护；W3C 因此在 Web 标准中引入了 CSS 规范。
知识要点

CSS 的四大优点（教材 3.1.3）

理解了这四个优点，就理解了为什么要「样式分离」

  • ① 实现格式和结构分离：CSS 和 HTML 各司其职、分工合作，有利于格式的复用及网页的修改与维护。
  • ② 精确控制页面布局：扩展了 HTML 的功能，能对布局、字体、颜色、背景等图文效果实现更加精确的控制。
  • ③ 体积更小、加载更快：可在同一网页中重用样式信息，也减少了表格布局标签、表现标签和格式属性的使用次数。
  • ④ 多个网页同时更新：站点上的多个网页指向同一个 CSS 文件，更新该文件即可实现多页同时更新。

CSS 的基本语法

一条样式规则 = 选择器 + 样式声明。写对这条规则，CSS 就入门了一半。

代码与要点

一条 CSS 样式规则的结构（教材图3-1）

完整含义：将当前文档中所有 h1 标签的前景色（文本颜色）设置为红色

  • ① 选择器（selector）：由它决定样式应用的对象。
  • ② 样式声明（declaration）：被包裹在一对大括号中，可以由多条样式声明语句构成。
  • ③ 每条样式声明语句：属性和值使用冒号分隔，语句以分号结尾，即 属性名:属性值;。
  • 易错点：这里的属性必须是 W3C 规定的样式属性，值必须是规范中定义的常用取值，误用会导致不可预期的结果。
  • 选择器分类：按构成可分为基本选择器和复合选择器；本项目先学基本选择器。
CSS 图3-1 示例
h1 {
  color: red;      /* 属性名:属性值; */
}

/* 选择器 */  /* 样式声明 */  /* 声明语句 */
3.3

基本选择器

基本选择器是指结构单一的选择器，主要包括标签选择器、id 选择器、类选择器、伪类选择器和伪元素选择器。

代码与要点

3.3.1 标签选择器

利用 HTML 固有标签进行选择，样式作用于页面中所有该标签出现的地方

  • 标签选择器也被称为元素选择器（element selectors）。
  • 示例含义：一级标题 <h1>、二级标题 <h2> 的文本颜色设为紫色。
  • 在 CSS 中，使用 color 属性指定文本颜色；purple、black、white、red 等都是 CSS 的预设颜色值。
  • 读法提示：语法中的「|」表示属性值可取其中一种形式，可以理解成「或者」。
  • 常用颜色用预设颜色值；个性化颜色则用十六进制值或 RGB 值精准描述。
CSS 语法3-1
h1 {color: purple;}
h2 {color: purple;}

/* 定义语法 */
color:预设颜色值 |RGB 值 |十六进制值 | inherit;
/* 示例 */
color:red;
color:rgb(255,0,0);
color:#ff0000;

表3-1 color 属性值（教材表）

属性值描述
预设颜色值使用 CSS 预设的颜色的英文单词表示颜色，如 red 表示红色，white 表示白色
RGB 值使用 RGB 的十进制值表示颜色，如红色对应 rgb(255,0,0)

知识要点

RGB 值与十六进制值的写法要点

教材标注的两个「常见的编程错误」就在这里

  • RGB 值：rgb(num,num,num)，括号内被逗号分成 3 部分，分别对应 r 红、g 绿、b 蓝，每部分是 0～255 的整数；可用 Photoshop 拾色器拾取。
  • 十六进制值：是 RGB 值表示法的变形。两位十六进制恰好表示 256 种颜色，3 个通道共需 6 位，并加「#」作为标识符，格式是「#＋6 位数字或字母」（0～9 与 A～F）。
  • 简化表示法：把相同的两位十六进制值用一位简化——#ff0000 可简写为 #f00，#336699 可简写为 #369。
  • 反例：#ffbb23 中的 23 无法用 1 位表示，不能使用简化表示法。
  • 常见的编程错误：书写十六进制值时遗漏「#」标识符；此外大小写虽均可，但在项目中保持一致的风格才是好习惯。

3.3.2 id 选择器

为「唯一」的那个元素单独设定样式，分两步完成

  • 应用场景：为网页中某些唯一的元素应用特定样式——给导航区域一个固定的大小，给页面顶部区域一个特定的背景颜色。
  • 第 1 步：为该元素添加 id 属性，并赋予唯一的值，如 <h1 id="hd1">第1 个标题</h1>。
  • 第 2 步：使用 #id 名称 形式的 id 选择器选中该元素并设置样式。
  • 技巧：时刻保持复用思想，使用最小冲突原则应用 CSS 样式，是提升 CSS 应用能力的关键。
  • 反例：给 4 个标题各定义一个 id 分别控制，虽然可行，却无谓地增加了复杂性，并不优雅。
CSS 语法3-2
/* 定义语法 */
#id 选择器{
  属性1:属性值1;
  属性2:属性值2;
  …
}
/* 示例 */
#hd1{
  color:blue;}

代码3-2｜id 选择器与「样式冲突」实验

同一元素被两种选择器命中：第 1 个标题为蓝色，其余为红色

  • 007～012 行对同一个 <h1> 使用了两种不同的选择器：标签选择器设为红色，id 选择器设为蓝色。
  • 运行效果（图3-3）：第 1 个标题文本为蓝色，其余标题为红色。
  • 样式冲突实验：把 id 选择器与标签选择器的代码交换顺序，按「就近原则」你可能以为最后一次设定会生效（变红），但第 1 个标题仍为蓝色。
  • 结论：这就是典型的样式冲突问题，将在项目最后（优先级）详细讨论；时刻保持复用思想与最小冲突原则是关键。

对比辨析

3.3.3 类选择器 vs id 选择器

id 解决「某一个」，类解决「某一组」——别再混用

id 选择器 #id
  • 写法：#id 名称，以「#」为标识
  • 用于为某个特定元素设定样式
  • 同一页面中，元素的 id 属性值必须唯一
  • 一个元素只能有一个 id 值
类选择器 .class
  • 写法：.类名，以英文句点「.」为标识
  • 用于为某些元素设定样式，可跨标签类型共用
  • 没有唯一性限制，可重复使用，利于代码复用
  • 一个元素可以拥有多个类，多个类名用空格分隔
  • 类名区分大小写，且第一个字符不能使用数字

AI 前沿：AI 是怎么「看懂」DOM 并挑中选择器的

你给出的结构越清晰，AI 生成的选择器就越准

AI

本课小结

  • CSS = cascading style sheet（层叠样式表）：HTML 管内容，CSS 管显示，内容与样式分离带来了复用、提速与全站统一更新。
  • 基本语法：一条样式规则由选择器与样式声明构成，声明写在一对大括号内，每条语句属性与值用冒号分隔、以分号结尾。
  • 标签选择器：h1{…}，作用于页面中所有该标签；颜色可用预设值、RGB 值、十六进制值（#＋6 位，两两相同可简化）。
  • id 选择器：#hd1{…}，为唯一元素设定样式，交换书写顺序也不影响结果——这就是样式冲突。
  • 类选择器：.remark{…}，为一组元素复用样式，可跨标签、可多类并用（空格分隔），类名区分大小写且不能以数字开头。
