布局的四代方案

    
1. 文档流：块级上下堆、行内左右排。一切布局的起点。

    
2. 浮动 float：让元素靠左/靠右、文字环绕。做多栏布局要配 clear 或 BFC，否则父容器高度塌陷。

    
3. 定位 position：脱离文档流做层叠。absolute 找「最近的 position 不为 static 的祖先」当参照物，没有就找页面。

    
4. Flex / Grid：现代布局。一维用 Flex，二维用 Grid，几乎可以替代前三种方案做页面结构。

    
选型口诀 排列元素用 Flex，划分区域用 Grid；只有「徽标角标」「浮层弹窗」这类才用 position:absolute。

  


  

    
四个高频坑

    

      
高度塌陷子元素全浮动 → 父元素高度为 0。解法：overflow:hidden 或 clearfix

      
absolute 参照物祖先没写 position，盒子会跑到页面左上角

      
z-index 失效只对定位元素（或 flex 子项）生效，且受父级层叠上下文限制

      
sticky 不粘祖先有 overflow:hidden/auto 时会失效；必须设 top/bottom 阈值

    

    
另外：display:none 的元素不占位、不渲染；visibility:hidden 只是看不见，位置还在。
