# labs · 互动实验台（10 讲）

《网页制作（HTML5+CSS3）》配套的**可视化互动实验**：每个项目一个独立页面，学生通过拖拽、滑块、切换取值，直接看到「代码 → 效果」的因果，而不是看静态截图。

- 纯静态、**零依赖、零网络请求**：不发 CDN 请求，断网、双击本地文件都能用
- 深浅双主题（右上角 ☀ 切换，或网址加 `?theme=dark` / `?theme=light` 强制指定，方便投影）
- 每讲 4 道自测题，答对 ≥60% 记为完成；进度与成绩存在浏览器 `localStorage`
- 屏幕自适应，手机可单手操作

## 入口

直接打开 **[index.html](index.html)**（课堂导航总目录），或从仓库根目录 `index.html` 的「互动实验台」卡片进入。

## 每讲能动手做什么

| 实验 | 核心交互 |
|---|---|
| 01 标签语法 | 点标签的每个组成部分看含义；去掉 `DOCTYPE` 切怪异模式，同一盒子宽度实测变化；关掉 `charset` 看中文乱码 |
| 02 文本与列表 | 18 个文本标签即时渲染；列表类型 / 项目符号 / 1–3 层嵌套 / `start` 实时生成代码 |
| 03 图像与链接 | 点文件树自动算出相对 / 根相对 / 绝对三种路径；`object-fit` 五值配容器尺寸滑块；链接四态 |
| 04 表格 | **在单元格上拖拽框选即合并**（自动生成 `rowspan`/`colspan` 并删多余 `td`），单击合并块可拆分；`collapse`/`separate` 对比 |
| 05 表单 | 14 种控件图鉴 + 代码；真实原生校验，故意填错提交看拦截原因；`label` 关联开关 |
| 06 选择器 | 输入任意选择器实时高亮命中元素并算 (a,b,c) 权重，能捕获语法错误；三条规则按权重对决；字号 / 容器 / 视口三个滑块验证 `em`、`rem`、`%`、`vw` 各自的参照物 |
| 07 盒子模型 | **可拖拽旋转的 3D 爆炸视图**，四层随分离度拉开；`box-sizing` 切换看内容区被“吃掉” |
| 08 布局 | `display` 四值；浮动导致父容器塌陷并用 BFC 修复（实测父高）；定位五值与 `z-index` 层叠；Flex 六组控件实时排布 |
| 09 媒体 | 视频是 `canvas.captureStream()` 实时画面、音频是实时合成 WAV，都能真播；属性逐项开关；iframe 内嵌页拖宽触发真实断点切换 |
| 10 动画 | 过渡参数调节 + canvas 实时绘制 `cubic-bezier` 曲线；七条跑道同场比缓动；`@keyframes` 四预设与 3D 翻牌 |

## 课堂用法建议

- **讲完一个属性就切过来**：实验页与课件配色一致，投影时不刺眼；按 `?theme=light` 可切成浅色适配明亮教室。
- **让学生上台拖**：合并单元格、3D 盒模型、贝塞尔曲线三个最适合上台操作，60 秒能讲清一个概念。
- **当随堂检测用**：每讲末尾 4 题当场判分，错题卡标红并给解析，可单题重做。
- **课后复习**：学生自己保存整个目录，双击即用，不需要服务器。

## 技术说明

- 全部为单文件 HTML + 共用 `assets/`，无构建步骤、无 npm 依赖。
- 3D 盒模型与层叠演示使用原生 CSS 3D（`transform-style: preserve-3d`），**未引入 Three.js**——原因是要保证双击本地文件即可运行，不依赖 CDN 与本地服务器。
- iframe 演示使用 `srcdoc`（`file://` 下父子文档同源受限，不去读 `contentDocument`）。
- 若需修改样式，统一改 `assets/base.css` 的主题令牌即可影响全部 11 个页面。
