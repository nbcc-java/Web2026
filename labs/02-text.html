文本标签速查

    

      
标签语义 / 用途

      
strong重要内容（默认加粗）

      
b无强调的加粗（关键词、产品名）

      
em重音强调，语气加重（默认斜体）

      
i无强调的斜体（术语、外语、图标字体）

      
mark与当前上下文相关的标记，像荧光笔

      
del / ins删除线 / 下划线，表示文档修改痕迹

      
small附属细则：版权、免责声明

      
sub / sup下标 H2O / 上标 x2

      
code / kbd代码片段 / 键盘输入

      
blockquote引用段落（长引用）

      
br / hr换行 / 主题分隔线，都是空元素

    

  


  

    
列表的三条硬规则

    
1. 只能装 li。ul、ol 的直接子元素只能是 li（可以嵌 ul，但要放在 li 里面）。

    
2. 改项目符号用 CSS。list-style-type: disc | circle | square | none，有序列表还有 decimal / lower-alpha / upper-roman。

    
3. 定义列表是成对的。dt 是术语，dd 是解释，一个 dt 可以配多个 dd。

    
动手任务 用嵌套 ul 做一个"课程目录"：3 个一级模块，每个模块下 2 个课时，并把一级的项目符号换成方块。
