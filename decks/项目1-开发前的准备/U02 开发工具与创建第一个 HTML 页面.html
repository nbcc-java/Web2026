1.4

常用开发工具简介

工具只是手段——但选对工具，学习效率会成倍提升。

要点分解

三款主流前端开发工具

教材重点演示 Dreamweaver 与 HBuilderX，同时介绍了 VSCode

VSCode
微软开发的跨平台、免费开源编辑器。支持语法高亮、代码补全（IntelliSense）、重构、定义跳转；内置命令行与 Git；可通过扩展商店拼装出任意开发环境，专业用户最爱。
Dreamweaver
Adobe 的老牌商业软件，设计/开发/发布一体化 IDE，自带实时预览与大量模板，无需安装额外插件；与 Photoshop 等无缝对接。适合缺少代码经验的初学者。
HBuilderX
国内 DCloud 推出的 HTML5 开发 IDE，最大的特点是又轻又快；语法提示与代码块完善，基于 Eclipse、兼容其插件。1+X 考试要求使用国产软件 HBuilderX。

常用开发工具产品特性对照（教材表 1-2）

知识要点

工具怎么选？三条关键结论

教材给出的选型建议，请在笔记本上记下来

  • Dreamweaver 功能齐全、界面一致性高，适合没有代码编写经验的初学者，便于教学与演示。
  • 为对接 1+X Web 前端开发职业技能等级考试（考试要求选用国产软件 HBuilderX），本课程重点演示 Dreamweaver 与 HBuilderX。
  • 关键结论：页面的最终显示效果取决于 HTML 代码和 CSS 样式代码——只要代码相同，用哪款工具都能达到同样效果。
  • 补充提醒：Eclipse 与 VSCode 的插件各成体系、无法互相通用；HBuilderX 与 Eclipse 系出同门，插件可相互通用。
1.5

创建第一个 HTML 页面

先建站点，再建页面——这是良好编程习惯的第一步。

知识要点

为什么必须先创建「站点」

教材关键解释：站点 = 存放网站所有相关文档的本地或远程存储位置

  • 站点用于组织和管理所有页面文档与资源，让文件之间的关系一目了然。
  • 开发完成后，可把站点整体上传到 Web 服务器，确保页面之间的链接引用关系不变。
  • 良好的编程习惯：确保新建的每个页面文件都放置在指定的站点（或项目）中。
  • 在 Dreamweaver 中叫「站点」，在 HBuilderX 中叫「项目」——作用完全相同：管理该网站的所有资源。
操作步骤

任务 1-5｜用 Dreamweaver 创建第一个 HTML 页面

目标：创建站点 web，新建页面并显示文字「欢迎一起学习Web 前端技术」

1
新建站点
选择「站点 → 新建站点」，设置站点名称为 web，本地站点文件夹为 F:\website\。
2
新建文档
选择「文件 → 新建」，文档类型选择 HTML5，单击「创建」。
3
输入内容
把光标放在设计视图中，输入「欢迎一起学习Web 前端技术」（所见即所得）。
4
观察代码
切换到拆分视图，可看到代码视图第 9 行同步发生变化。
5
及时保存
默认文件名是 Untitled-x.html，务必「另存为」index.html，并确认保存在站点根目录。
6
浏览器预览
点击状态栏右下角图标，选择 Google Chrome 预览页面（Windows 快捷键 F12）。
操作步骤

任务 1-6｜用 HBuilderX 创建第一个 HTML 页面

HBuilderX 是纯绿色、免安装软件，站点以「项目」的形式呈现

1
新建项目
选择「文件 → 新建 → 项目」。
2
配置向导
① 项目类型选「普通项目」；② 命名为 web；③ 指定存放位置；④ 模板选「基本HTML 项目」；⑤ 创建。
3
认识自动生成的结构
HBuilderX 会自动创建 css、img、js 等常用文件夹以及 index.html。
4
编辑源代码
双击 index.html，以源代码方式编辑，在第 8 行输入「欢迎一起学习Web 前端技术」。
5
留意保存状态
文档未保存时，标签上会显示一个星号（*），提示该文档已被修改。
6
点击预览
单击文档工具栏右侧的「预览」按钮，用内置浏览器查看效果。
代码示例

你写下的第一个页面：index.html

只有 9 行代码，却是所有网页的起点

HTML index.html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  欢迎一起学习Web 前端技术
</body>
</html>
提示：index、default 常被服务器配置为网站的首页；html、htm 都是静态页面的默认扩展名。静态页面不需要服务器编译或解释，可直接发送给浏览器显示。

效果预览｜让第一个页面「好看一点」

同样的文字，加上一点点 CSS，感受「样式」的力量

  • 左侧是刚才的 index.html 在浏览器中的呈现效果。
  • 文字内容完全由 HTML 决定，结构 = 内容。
  • 文字的颜色、字号、居中、背景，全部由 CSS 样式决定。
  • 本课程的后续项目，就是系统学习如何用 CSS 让页面「既正确又好看」。

对比辨析

两种预览模式，别搞混

Dreamweaver 的首选项 → 实时预览 中可以切换

服务器模式（默认）
  • Dreamweaver 自带 Node.js 服务器，以服务器模式提供页面显示
  • 地址栏内容以 127.0.0.1 开始
  • 目的是模拟 Web 服务器交付页面的真实效果
  • 页面中含服务端动态脚本时，该模式有正确的交互反馈
静态浏览器模式
  • 在「首选项 → 实时预览」中勾选「默认为静态浏览器中预览」
  • 地址栏内容类似文件资源管理器的文件路径
  • 与在本地文件夹直接双击打开文件的效果相同
  • 无法执行需要服务器执行的动态脚本
知识要点

小知识：127.0.0.1 与 localhost

为什么预览时地址栏长这样？

  • 127.0.0.1 是一个特殊的 IP 地址，称为「回送地址」（loopback address），指向本地主机，通常用于测试。
  • 它与系统保留的域名 localhost 对应——http://127.0.0.1/index.html 与 http://localhost/index.html 是等价的。
  • HBuilderX 预览时的地址形如 http://127.0.0.1:8848/web/index.html：127.0.0.1 表示本地主机，8848 是端口号，/web 是项目目录。
AI 前沿

AI 前沿：编辑器里的「结对编程伙伴」

学会用 AI 加速，但别丢掉「自己会写」的底气

AI

现代编辑器已经把大语言模型内置为「结对编程伙伴」：你写下 注释，它就能补全整段 HTML/CSS；你描述需求，它就能生成代码骨架。对初学者来说，这是极好的即时反馈与模仿范本——但前提是你具备判断代码对错的能力。

  • AI 补全：在 VSCode / HBuilderX 中安装 AI 插件（如通义灵码、文心快码、Copilot），边写边获得建议。
  • AI 解释：选中一段陌生代码，让 AI 逐行解释其含义——是最好的「随堂助教」。
  • AI 排错：把浏览器控制台的报错信息交给 AI，快速定位问题原因。
  • 学习建议：先用 AI 生成、再逐行读懂的代码，才真正属于你自己；抄来的代码不会长在你脑子里。

本课小结

  • 工具认知：VSCode 开源可扩展、Dreamweaver 一体化易上手、HBuilderX 轻快且为 1+X 考试指定软件。
  • 选型结论：页面的最终显示效果只取决于代码，换工具不换效果；初学推荐 Dreamweaver，考证推荐 HBuilderX。
  • 站点/项目：先把 index.html 放进站点（项目）里，才能保证链接引用关系在后续发布时保持不变。
  • 预览模式：服务器模式（127.0.0.1 开头，模拟真实服务器）与静态浏览器模式（文件路径，不能跑动态脚本）要分清。
  • 良好习惯：及时保存（注意星号 *）、规范命名（index.html）、文件归位。
